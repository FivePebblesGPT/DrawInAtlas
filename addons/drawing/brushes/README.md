# Bundled Hokusai brush definitions

These four unmodified `.myb` presets are from the MyPaint Brushes
[v2.0.2 release](https://github.com/mypaint/mypaint-brushes/tree/v2.0.2):
`ramon/Round.myb`, `experimental/soft.myb`, `classic/pen.myb`, and
`deevad/airbrush.myb`. The authoritative upstream `Licenses.dep5`
assigns the brush definitions **CC0-1.0**. No upstream artwork, PNG
previews, or brush-pack binary is included.

The native prototype overrides size and HSV brush color at stroke start,
so it is **not** pixel-identical to MyPaint or the legacy swept-circle
Brush; preset-specific settings still affect shape and opacity.
