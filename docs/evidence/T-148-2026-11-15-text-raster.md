# T-148 checkpoint — preserve native history across unowned text rasterization

**Date:** 2026-11-15 · **Branch:** `sprint/2026-11-15` · **Ticket:** T-148 **In Progress**. Builds on the eleven local sprint commits ending at `a4990ca6` relative to GitHub's `a83e5055` baseline. T-149 stays Blocked; T-095 hardware/owner acceptance is unchanged.

## Defect and bounded correction

`DrawingDocument.rasterize_text()` previously built the text glyph tile projection and then incremented only the GDScript `revision`. `_replay_text_tree` similarly skipped Rust's revision mirror when Undo/Redo changed a text layer into a raster layer or back. On the next Brush, Rust saw a stale revision, checked-rebased its entire source store, and discarded unrelated native Brush Undo/Redo history, even if the text layer had never been authorized in Rust.

The conversion still uses `DrawingTextRaster.bounds` / `.composite`, enforces the existing bounded source-pixel budget, and constructs detached `DrawingRasterTile` glyphs **before** changing the document. Once the glyph projection is prepared, it calls the already-tested `advance_unreferenced_layers_revision(expected, [layer_id], discard_redo=true)` bridge. If Rust can prove that no resident/authorized tile, active native edit, parked ID, or Undo/Redo token belongs to that layer, the native and Godot revisions advance exactly once and all unrelated canonical raster tiles/history remain intact. A subsequent Brush on the text-derived raster explicitly authorizes and imports those glyph bytes, without per-pixel FFI traffic.

Text/raster Undo/Redo follows the same Rust guard with `discard_redo=false` so unrelated native Redo entries can survive timeline replay. The Godot `text_tree` event and document serialization continue to retain detached text/raster source snapshots. A reused or previously painted layer ID **must not** take this shortcut: Rust rejects it, the Godot edit still completes with the native revision behind, and the next Brush performs the existing checked rebase and source reauthorization instead of mixing old RGBA8 into new glyph content. This change does **not** convert font rasterization to Rust or remove GDScript history fallbacks.
