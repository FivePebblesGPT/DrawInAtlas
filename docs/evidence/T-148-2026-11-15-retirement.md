# T-148 checkpoint — bounded native retirement for unrecorded raster subtrees

**Date:** 2026-11-15 · **Branch:** `sprint/2026-11-15` · **Ticket:** T-148 **In Progress**. Builds on local `23114cec` (12 earlier sprint commits ahead of verified GitHub baseline `a83e5055`). T-149 remains Blocked, and T-095 retains its independent physical/owner review.

## Defect and design boundary

`DrawingDocument.remove_subtree(node_id, record_history=false)` previously erased even native-owned raster rows while incrementing only the Godot document revision. Rust retained the now-unreachable layers' canonical RGBA8 tiles and Undo/Redo tokens until the **next** native gesture detected the revision discrepancy and reset *all* Rust source/history, including unrelated painted layers. External-history (Atlas-owned) structural removal could follow the same path. Recorded local subtree deletion was already supported by reversible native **parking**; reusing that mechanism for permanently unrecorded deletion would retain obsolete pixels/tombstones and could reject later independent ID reuse.

The new `DrawingNativeTiles.retire_layers_revision(expected, ids, discard_redo)` performs an atomic, irreversible **1–128-ID** native retirement. Rust checks the current revision, quiescence, bounded size, distinct nonempty IDs, and absence of parked identities before touching any data. On success it releases only the targeted layers' canonical tiles, authorizations, editability flags and history entries from both native stacks, frees their retained byte buffers, and advances the same document/native revision once. It preserves unrelated native source bytes, memory residency and history tokens. An inactive or stale bridge, malformed/over-limit batch, or parked ID rejects without partial modification.

The Godot removal path first gathers the complete nested subtree and verifies all known imported source-object identities and **full RGBA8 parity** against Rust without invoking lazy providers. After the native retirement succeeds, it clears the corresponding identity records, erases the tree deterministically and prunes only local content/tree history events that would reference permanently deleted nodes; surviving event order, cursor and content-state tokens are retained. The external/host timeline is not altered. `record_history=true` with local history continues using reversible **park/restore**, never retirement. Rejected retirement or a silently changed in-place source uses the pre-existing conservative checked rebase on the next native stroke.

This checkpoint does **not** provide universal native history ownership: detached/host history replay, previously native-owned text rasterization, unbridged raster producers, and integrated native-source Atlas/Object Save/Open history acceptance remain outstanding. An unrecorded deletion intentionally has no structural Undo; only unrelated surviving local events are replayable. No old Legacy compatibility/migration is introduced.

## Remaining T-148 acceptance

Persistent Rust Brush/Eraser canonical bytes and a bounded native history stack are used in production; non-painting operations now preserve that history across eligible subtree imports, structural park/restore and direct retirement. The remaining gaps are detached/global history replay without reliance on Godot's fallback snapshots, other raster producers that bypass the native transaction contract, previously native-owned text/raster conversion, and integrated **native-source** Atlas/Object Save/Open/history acceptance. Do not mark T-148 Done or unblock T-149 on these tests alone. T-095 physical/owner acceptance remains independent.
