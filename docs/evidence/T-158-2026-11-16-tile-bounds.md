# T-158 — safe signed lazy tile IDs before persistence

**Date:** 2026-11-16 · **Branch:** `sprint/2026-11-15` · **Ticket:** [T-158](../Tickets/T-158.md), locally Done. Parent [T-148](../Tickets/T-148.md) remains In Progress. Tested with bundled Godot 4.8 beta3, offline Rust 1.99.1/Hokusai, software X11/llvmpipe. No remote hosted CI or hardware owner acceptance is claimed.

## Failure mode and boundary

The Godot native tile projection bounds tile origins by `±floor(2^52 / storage_stride)`. Lazy registration previously accepted arbitrary `int64` tile coordinates, while manifest export also accepted injected resident tile keys outside that bound. Loading or serializing such a source could create a document tile Rust/Godot native publication would later reject, or overflow coordinate arithmetic in downstream consumers. The fix shares `SignedTiles.tile_coordinates_in_projection_range` across `DrawingDocument.register_lazy_chunk` and `export_manifest`; it compares signed bounds directly (safe for `INT64_MIN`, unlike `abs()`). Logical manifest opening invokes checked registration and portable `.drawing` decoding invokes logical manifest opening. There is no new backend or ABI and no change to Hokusai painting.

## Fail-first control and fixed result

The **same 24-check test** was run after a successful Godot editor import in a separate staging project with the unmodified pre-fix `document.gd` and `signed_tiles.gd` from commit `34ee22b8`. It exited **1** with **9/24 assertions failed**: unsafe positive/negative/min/max signed tile registration, changed pending/persistence metadata, logical manifest import, forged resident export, standalone decode and polluted-source roundtrip. The test against the fixed package exited **0** with `T158_TILE_BOUNDS_PASSED checks=24 failures=0` (also repeated after the final constant rename/re-stage). An initial test construction accidentally included an unsaved Ink chunk with no ref; a lazy-only isolated manifest removed that unrelated `MISSING_TILE` failure before final fail-first and positive evidence.

The fixed fixture first paints with the real Hokusai extension and retains its Rust tile history token. Unsafe registration is rejected before changing revision, display source epoch, pending/known references or the previously painted Ink. A legal large signed `(+limit,-limit)` lazy source materializes to exact zero-alpha hidden-RGB RGBA8, survives portable `.drawing` encode/decode, and leaves native Undo/Redo functional. A directly forged resident out-of-range key cannot be exported.
