## Implemented bound

The pinned Godot 4.8 PCK v4 index reader checks format/engine version, safe
pack flags, directory location, count and entry boundaries, UTF-8 POSIX paths,
duplicates, resource offsets, unsupported per-file flags, and the Godot PCK
MD5 payload fields for required resources. For Linux it requires
`project.binary`, the startup scene or remap, the smoke script or remap, and
the canonical native manifest with `gdext_rust_init` and both release/debug
Linux library mappings. A remap is rejected if its referenced compiled
resource is not indexed. Windows retains structural-only project/startup
requirements without pretending that the Linux `.so` certifies Windows.

Malformed or unrelated PCKs now fail the same preflight that checks ELF/native
bytes, *before* the publisher installs a `.so`. The dedicated packager test
asserts exact preservation of an invalid distribution and no leaked preflight
artifacts. This does not alter how Godot reads PCK files at runtime.
