## One bounded change and correctness witness

`scan_changed_pixels()` now compares each 64-pixel Hokusai tile row to its last published **fixed-point** pixels before visiting individual channels. **Equal rows skip all 64 per-pixel comparisons; changed rows still execute the original exact pixel equality test and sRGB byte quantizer**. The existing previous raw/native RGBA cache is retained, including hidden RGB and quantized same-bucket changes. There are no new allocations proportional to the stroke and no changes to tile authorization, rollback, history, editor mode, mask, sample count, or ABI. `DRAWING_T191_PIXEL_SCAN_COUNTERFACTUAL=1` forces the original pixel-by-pixel scan for same-native-binary comparisons; ordinary runs use row skipping.

The new native regression drives 24 changing/reverting frames, including transparent pixels and both row boundaries; optimized and per-pixel runs publish **identical ordered deltas, raw state and RGBA8 state**. It proves at least **63 of 64 rows are bypassed** on the sparse-row fixture, versus zero bypassed on the reference. An initial version of the regression failed due to an overly strict row-count assertion, not a byte mismatch; its console output was overwritten on rerun and cannot be supplied as a separate retained failure log. The **77/77 graphical T-191 same-binary comparison** covers signed tiles, partial alpha, hidden source RGB, a subtracted selection hole, queued/interpolated Brush and Eraser, exact committed source, cancellation, Undo/Redo, real standalone Save/Open, and native batch/input counts. All corresponding reference and optimized committed source snapshots match. The native `ExportedTile` cache remains bounded per touched 64px tile, and no new persistent cache is added.
