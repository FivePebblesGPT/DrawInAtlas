**Scope:** a further *engineering checkpoint* for the unresolved 60px Brush ticket,
not a new brush feature or a change in owner acceptance. Existing branch:
`sprint/2026-11-07`, PR #16. Ticket frontmatter remains `In Progress`,

## Implementation and invariant

The same `DrawingEditSession._blend` scalar RGBA8 source-over equation now
computes the three channels directly instead of allocating a typed three-item
`Array[int]`, looping over it and appending per pixel. Float expression order,
`roundi`, alpha treatment and straight-RGBA8 packed byte order are unchanged;
source alpha zero still retains any destination hidden RGB. This call is shared
by native Hokusai staging, ordinary hard Brush, and the display compositor.

For Hokusai's prevalidated native delta tiles, paint and deferred history
materialization also read the immutable `DrawingRasterTile._pixels` map by
already-checked integer local offset. This removes one GDScript
`get_rgba(x,y)` call *per pigment update* without allocating bulk tile
copies, bypassing source-validation gates or changing canonical document
storage. The tile map is **read only**; original source ownership, lazy tile
resolution and detached preview are unchanged.

A separate `drawing/tests/brush_blend_math_smoke.gd` contains the **old**
3-item-array expression as an independent oracle. It compares all **65,536**
source/destination alpha pairs with varying RGB, followed by **32,768**
deterministic high-entropy RGBA pairs (including negative signed int32 values) (98,304 total), plus a 16,384-pair
informational microbenchmark, asserting exact packed integer parity. Both
present- and absent-native delta tests still compare committed pixels and
previews against the original per-pixel transaction oracle, including alpha,
source reads, signed 64-bit anchors, selection holes and Undo/Redo.

## Same-machine pointer benchmark, not hardware UX acceptance

Environment: verified bundled Godot `4.8.beta2.official.cafc17a19`,
Linux Xvfb `1280×900×24`, Mesa llvmpipe 25.0.7 OpenGL compatibility,
Dummy audio, opt-in Hokusai 0.3.0/godot-rust 0.5.5 native extension.
`brush_latency_native.gd` exercises a **real Godot Brush input path** at
786% zoom and 60px width, 512×512 image, five successive strokes of
120 real `InputEventMouseMotion` samples each, four motions per engine frame;
first cold, remaining warm, held-preview framebuffer inspected and one
atomic transaction checked per gesture. This is not a fill benchmark.

For a paired control, **only** the staged standalone
`drawing/addons/drawing/edit_session.gd` was replaced with the previous
local committed revision (`10b64fa`) while the canonical source, native
binary and engine remained unchanged. The original staged file was restored
before the confirmation and all regressions. Run order was
**optimized → previous → optimized confirmation → optimized Legacy**, with a
fresh Xvfb Godot process per run. Every run passed all pointer and framebuffer
assertions. Values below are **nearest-rank p95**; stage/compose/commit are

~1.7× slower than the same-machine Legacy case, and display composition
remains a significant cost. The numeric result has only five strokes per
run and is not a confidence interval, physical device test or real user
acceptance.

- Independent original-array blend math: **3 checks**, all **98,304**
  RGBA8 pairs byte-identical; informational 16,384-pair microbenchmark
  **13.507 ms original → 7.589 ms scalar** on this run.
- Hokusai delta preview/commit/mixed API/rollback oracle: **101/101**.
- Hard-brush pixel/selection/Undo source oracle: **32/32**.
- Native-present and native-absent fallback smoke: **6/6** each.
- Native `.myb` integration: **30/30** (4 actual preset behaviors).
- Released-stroke navigation: **48/48**; pixel boundary PR #14:
  **17/17** (Godot post-exit GL/RID leak diagnostics retained);
  viewport-cache native: **153/153** after clean import.
- Renderer sparse-layer model: **74/74**; T-085 live-stroke model passed.
- Four native pointer benchmark runs: each `T095_NATIVE_PASSED`; no synthetic
  input dropped, preview visible while held and one commit per stroke.
- T-095's on-demand workflow now independently runs the original-array
  blend oracle and uploads its log. It has **not** been run in hosted CI.
