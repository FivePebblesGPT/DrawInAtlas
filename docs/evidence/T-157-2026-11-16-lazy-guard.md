# T-157 — reentrant lazy-source authority guard

**Date:** 2026-11-16 · **Branch:** `sprint/2026-11-15` · **Ticket:** [T-157](../Tickets/T-157.md), Done locally. The parent [T-148](../Tickets/T-148.md) stays In Progress. Tests used bundled Godot 4.8 beta3, the pinned offline Rust 1.99.1 toolchain, Hokusai/libmypaint native GDExtension, and software X11/llvmpipe.

## Failure and fix

`_resolve_chunk` invokes a caller-provided loader and formerly installed its result even after that callback changed the target layer's lock state/revision or replaced the same pending blob with another valid SHA-256/ref. It also permitted recursive reads of the same pending key. A direct read/renderer could therefore publish stale Godot bytes before a higher-level native transaction preflight, even though the original pending source was no longer authorized.

The new boundary records the revision, display-source epoch, original layer object, pending loader/ref/digest and deep-copied known persistence reference. A per-document in-flight key guard rejects same-key recursion with `SOURCE_BUSY`. After the callback returns, a revision mismatch returns `STALE_REVISION`; replaced/deleted pending and layer identities return `STALE_SOURCE`, preserving the new pending source for retry. Unchanged providers still pass the existing exact RGBA8 size/digest checks before a detached tile is materialized. No Rust ABI or Hokusai rasterization algorithm was changed.

## Fail-first control

The **identical** 23-check Godot fixture and native engine were executed with the original `addons/drawing/document.gd` from commit `0bfe4cef` staged in `drawing/addons/drawing/`. It exited **1** with `T157_LAZY_GUARD_RESULT checks=23 failures=7`, detecting all three defects (reentrant revision, stale pending replacement, recursive same-key fetch). After restoring the fixed document, the fixture exited **0** with `T157_LAZY_GUARD_PASSED checks=23 failures=0`. Both raw logs are included. The regression also preserves a prior real Hokusai Ink tile, alpha-zero hidden RGB, the same Rust history token and working Undo/Redo through metadata-only changes and retries.
