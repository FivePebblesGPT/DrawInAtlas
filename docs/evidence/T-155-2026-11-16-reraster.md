# T-155 — selective replacement of parked text-derived raster source

**Date:** 2026-11-16 · **Branch:** `sprint/2026-11-15` · **Ticket:** [T-155](../Tickets/T-155.md) **Done**. Independently testable child of **T-148 In Progress**. Baseline includes unpushed T-153 (`c77d9f77`) and T-154 (`6c31af81`) beyond the last verified remote `fa36c199`; the delivered mailbox must include all local commits until the remote actually advances.

## Defect and atomic fix

Text derived from a previously painted glyph layer can return to semantic text on Undo while its canonical bytes and history tokens stay parked in Rust (T-154). Editing the semantic text and rasterizing it a second time previously called the *unreferenced* bridge on that same **already-parked** ID. Rust rejected the false unreferenced assertion, Godot nevertheless advanced its own revision, and a later Hokusai stroke rebased and discarded unrelated Ink history.

`DrawingNativeTiles.replace_parked_layers_revision` now validates 1–128 **distinct, nonempty, parked** IDs, exact native revision and absence of an active transaction before one `r → r+1` revision. It then selectively drops the named source tiles, tile authorization, editable grants, stale native history and tombstones; branched Redo is cleared while unrelated native Undo and source RGBA8 remain. The test covers hidden-RGB source, duplicate/unparked/empty/oversized IDs, wrong revision, active edit, and fresh source import after replacement. Rust retains T-154's separate **reversible** park/unpark behavior for unchanged history snapshots.

`DrawingDocument.rasterize_text` completes the new glyph projection **before** any bridge; it chooses replacement only for an in-sync parked ID, the unreferenced bridge for a never-native-owned ID, and rejects current owned-unparked IDs and native-ahead stores before installing a changed tree. Rejected active transitions leave both revisions, parked source and semantic node unmodified and can retry. Old native-source object identities are erased only after success. `commit_text` additionally forbids reusing an absent ID still reserved by native parking. Behind-native stores retain the earlier checked rebase pathway; this does not universalize authority for other raster producers or replace Godot's semantic glyph rasterizer.
