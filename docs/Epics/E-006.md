# Milestone 6 — Artwork LOD and local canvas-object workflows

## Confirmed direction — 2026-10-30
- Automatic “layer zoom” means **artwork-layer LOD**, not automatically switching independent map documents. Enable it by default, with an optional disable control.
- World hexes share the continuous chunked board in [[E-002]]. Empty hexes are not blocked by missing document assignments.
- A battlemat is a bounded, movable/resizable **canvas object within a local map**, not a separate document per footprint.
- Battlemats are available in local-map contexts, not world/hex overview, and cannot contain nested battlemats.
- Transforming a canvas object must provide explicit control over whether its drawings move with it.

These are confirmed requirements. Exact LOD thresholds, object data structures, content association and how local detail contexts are represented remain design work.
