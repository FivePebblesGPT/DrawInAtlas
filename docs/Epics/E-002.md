# Milestone 2 — Continuous chunked board and grid selection masks

## Confirmed direction — 2026-10-30
The world hex grid overlays one giant, chunked drawing board. Higher zoom/detail reveals **separately authored artwork/detail groups in shared coordinates**. Hexes do **not** each own a separate canvas or automatically created document. The DM can paint across hex borders; “Restrict edits to current tile” is a selection mask.

This clarification supersedes earlier interpretations that zoom should enter/create one independent map per hex. Distinct maps may still exist for other purposes; their relationships require an explicit design decision, not a per-hex assumption.

## Acceptance
- Painting and saved artwork remain continuous across neighboring hexes and chunk seams.
- Empty hexes can be zoomed into without an assigned map or document creation.
- Enabling/disabling the selection mask changes edit eligibility, not coordinates or canvas identity.
- Automatic LOD changes presentation; the editing target stays explicit and cannot silently change during a gesture.
- Grid and native measurement settings do not silently rescale artwork.
