## Acceptance
Paint.net is the primary interaction reference. Tools have familiar, discoverable interactions, active-layer selection by default, coherent transforms, meaningful undo/redo and code the user can review without project-document context. The editable point-by-point path tool and persistent editable text are explicit requirements in [[E-TOOLS]].
