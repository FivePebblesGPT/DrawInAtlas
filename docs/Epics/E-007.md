# Milestone 7 — Local table and projector output

## Scope
Carry forward the current execution milestone: local GM/player presentation, tokens, fog, privacy-filtered output and a Web-compatible fallback. Schedule after acceptance of the core manual-review fixes; do not treat this epic as the immediate next implementation instruction.

## Confirmed projection object — 2026-10-30
A frame on the GM board matches the projector's aspect ratio. Moving it pans the player view. Enlarging it shows more board (zooms out); shrinking it shows less (zooms in). This changes view framing, not artwork coordinates, size or ownership. Output-window dimensions and physical projector/grid calibration are separate controls. It replaces the need for a battlemat presentation concept, not the privacy-filtering boundary.
