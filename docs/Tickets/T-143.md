# Reconcile clipped selection outlines after a sub-tile viewport pan

**Done — 2026-11-15; bounded software-renderer correctness only.** T-142
retained shared contours when a saturated selection cache moved to a different
64px focal tile. However, the cache could also contain 4096 contours while a
pan of less than one tile changed the *pixel-level clipped footprint* but not
its tile window or focal tile. In that case the newly eligible edge island was
never traced because the full cache still held the off-screen island.

## Acceptance

- [x] Recognize a changed clipped source footprint even if its selection tile
  window and camera focal tile do not change. At a saturated contour budget,
  evict only cached tiles outside the newly eligible candidate plan.
- [x] Keep shared contours, the 4096-entry cache and four-new-tiles-per-frame
  publication limit. Avoid reindexing the cache for identical clipped plans;
  preserve explicit sparse-mask, signed-coordinate, compound/inverted and
  different-window fallback behavior.
- [x] Reject invalidated selection caches after changing selection or document;
  preserve source pixels, mask authorization and Undo/Redo history.
- [x] Reproduce the original missing outline in a real X11 framebuffer at 25%
  zoom, with the 64px tile window and focal tile unchanged. Add a deterministic
  model for 4095 shared contour tiles, one old edge island and one new island.
- [x] Run neighboring T-139–T-142 model/native, T-088 selection and sparse
  clipboard, T-096 large-mask/Move, strict logs, independent Drawing consumer,
  explicit typing, Python contracts and ticket validation. Add to the existing
  T-088 fast-CI step and on-demand native workflow without a 47th check ID.

[Evidence, reproducible commands and raw log hashes](../evidence/T-143-2026-11-15-subtile-contour-clip.md).

## Scope and gates

This repairs the selection **overlay**, not canonical raster pixels, selection
semantics or a physical response-time regression. It does not guarantee
rendering every over-budget contour simultaneously. T-088 remains **In
Progress**, T-096 remains **Manual Review**; the T-086/T-095 physical-device,
T-106/T-107 hosted CI, and existing owner acceptance gates are unchanged.
