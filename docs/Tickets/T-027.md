# Editable text with screen-space culling

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 16.

## Acceptance
- Text remains editable after placement and after save/load; editability is confirmed rather than a pending alternative.
- Agree placement and font/size/style controls, using Paint.net as the primary interaction reference except where persistent editability requires an explicit extension.
- Cull text when its on-screen font size becomes unreadably small. Choose the screen-space threshold through a focused visual check; do not tie readability to a fixed world-space size.
- Culling changes rendering only: retain the text content, style, position and editability, and show it again at a readable zoom.
- Keep text editing distinct from global drawing shortcuts.
- Accepted text respects the layer/object model, selection and transforms.
- Verify undo, saving and readable display across relevant detail levels.

## Implementation candidate — 2026-10-30

- Implemented a dedicated Text (T) tool, in-editor multiline editing dialog, color/font/size/style controls, and persistent editable text objects using additive validated ink metadata. The complete interaction and storage proposal is in [[TEXT_WORKFLOW]].
- Rendering culls below **9 on-screen font pixels**, based on an initial native framebuffer comparison of 8 px (hidden) versus 10 px (visible). This is a presentation-only rule; text survives zoom, detail switching, undo, clipboard, and native saves. Final device usability tuning remains for acceptance.
- Added `tests/text_smoke.gd` and `tests/text_visual.gd` to CI. Locally confirmed pointer placement, editor keyboard isolation, selection, masked edits, whole-object erasure, rotation/movement, persistence, D0/D1, and compact-window display.
- This is a **review candidate**. The ticket remains unchecked until the owner agrees to the proposed controls, font-style/fallback policy and 9 px visibility threshold. Remote CI and hands-on usability acceptance remain unverified.
- Final local Godot `4.8.beta2` gates: **39 applicable headless suites**, **24 native framebuffer suites** (including re-runs after text/eraser changes), `text_smoke.gd` **47 assertions**, `text_visual.gd` **15 assertions**, explicit-type audit, parser/import, main-scene launch, Web release export, and all four source/exported-pack save interoperability checks pass. Browser-runtime and physical-display readability checks remain deferred.
