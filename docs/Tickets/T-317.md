# Bound pristine physical sparse source residency during rendering

## Scope
Permit quiescent renderer misses to release exact, reloadable physical
sources rather than exhaust the per-document Rust memory cap on read-only
browsing. Do not evict edited, parked, history-owned, changed or unresolved
sources; do not alter the physical format, document revision, display epoch,
savepoint or Undo/Redo. Bulk edit, transfer and history readers retain their
existing admission/failure semantics.

## Acceptance
- [x] Native same-revision release compares committed bytes and rejects active,
  parked, non-pristine or history-referenced sources.
- [x] Restore the original pending ref/digest/provider and remove the native and
  Godot resident identities; re-admit only after normal digest validation.
- [x] Real pressure witness exceeds the old 256 MiB working set; render all
  18 signed 2048px source tiles with 192 MiB high-water when all are eligible.
- [x] Preserve dirty/changed source fences, pending edits, structural replay,
  native Undo/Redo, complete subtree export and corrupt-source rejection.
- [x] Complete neighboring native/campaign regressions and integrate Make/CI.

[Execution evidence](../evidence/T-317-2026-11-25-sparse-eviction.md).
This is conservative renderer-driven FIFO, not universal native paging or
large-map latency acceptance. T-148 and T-149 remain open; T-250 stays Manual Review.
