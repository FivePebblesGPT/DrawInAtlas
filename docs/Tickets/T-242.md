# Make the external history owner a checked, read-only document property

**Bounded T-148 child.** T-241 added `set_external_history()` revision and
local-history guards but the public writable `external_history` Boolean still
allowed direct GDScript assignments, `Object.set`, and `set_indexed` to bypass
the guards. An Atlas-owned document could silently stop reporting host history,
or a local history could be disabled, orphaning native/host commands.

## Acceptance

- [x] Keep `external_history` readable to existing workspace and Atlas callers,
  but expose it through a getter-only property backed by a private field. Only
  the checked `set_external_history()` method may change the backing field.
- [x] Verify direct, reflected, and indexed property writes leave host and
  local modes unchanged before and after native raster commits, including
  exact hidden RGB, history tokens, and reversible Undo/Redo.
- [x] Verify the real Atlas campaign registry and chronological history across
  two Drawing edits and an interleaved Atlas grid command; preserve explicit
  pre-edit handoffs and idempotent checked calls.
- [x] Record fail-first evidence, run relevant native/local/Atlas regressions,
  and add exact-count required-native CI coverage without closing manual gates.

## Completion — 2026-11-22

The standalone test fails **10/25** and the Atlas integration test fails
**9/18** with the prior public field. Both pass **25/25** and **18/18** after
replacing that field with a getter-only projection. Native source and global
history never change on attempted property writes. Neighboring T-241/T-239,
native ABI, Atlas native-history and detached replay suites pass locally.

[Execution evidence](../evidence/T-242-2026-11-22-history-owner-property.md).

**Scope boundary:** T-242 closes the public-property bypass; it does not
synchronize arbitrary external commands into Rust or establish universal native
raster authority. T-148 remains In Progress, T-149 remains Blocked, and
hosted CI/physical owner acceptance remain outstanding.
