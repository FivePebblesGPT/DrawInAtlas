# Reclaim applied orphaned subtree sources on permanent ancestor removal

## Scope
A local permanent deletion of an ancestor makes applied child-removal history
unreplayable. Reclaim those parked native raster sources and prune obsolete
local commands, including transitively removed descendants, without deleting
unrelated history or invoking sparse providers. This is shared Drawing
infrastructure, not Atlas UX approval.

## Acceptance
- [x] Fail-first native witness with empty and raster-bearing ancestors and
  transitively absent descendants.
- [x] Validate retained snapshot hierarchy, complete source cardinality and
  canonical bytes; reject stale, busy, overlapping and malformed retirement
  batches before any revision, tree or history mutation.
- [x] Retire affected live and parked layers in one native revision; reclaim
  associated tokens and identities and preserve surviving Undo/Redo order.
- [x] Verify exact hidden RGB on reversible recorded removals, safe ID reuse,
  unrelated abandoned creation cleanup and no lazy source I/O.
- [x] Pinned native verification, adjacent regressions, documentation and CI.
