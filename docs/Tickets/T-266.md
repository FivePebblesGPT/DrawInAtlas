# Restore the required-native T-086 viewport-cache CI witness

## Problem

The on-demand T-086 workflow used to stage a standalone copy of Drawing and
import it **without building or preregistering the required Rust GDExtension**.
Even a warmed local native project exposed four stale T-086 X11 assertions:
two treated an idle pressed Hokusai input as a populated preview, one assumed
25% paint was immediate on mouse-down, and one assumed Undo could never refresh
an otherwise visible tile. The T-137 cold-preview test checked a newly redone
pixel before its intentionally deferred display population had settled.

The workflow additionally ran two archived cold-compositor comparison fixtures
that no longer compile against the current `DrawingRenderer` API. Their
historical SHA-256 checks are valid, but the old timing comparison must not be
presented as a current native performance measurement.

## Engineering acceptance — Done

- [x] Pin Rust 1.99.1, build the mandatory native extension and import Drawing
      **and** Atlas before every on-demand X11/model/benchmark step.
- [x] Exercise a genuine staged Hokusai preview from native pointer motion at
      100% and 25% zoom before testing display tile uploads, bounded indexes,
      cancellation and exact source/history invariants. Do not weaken the
      framebuffer parity or signed/transparent coverage checks.
- [x] Distinguish erasing the affected transparent tile from permitted uploads
      of another still-visible tile; retain hidden-RGB and Undo/Redo checks.
- [x] Require cold population to settle within a bounded frame budget after
      Redo, then assert canonical source bytes **and** displayed framebuffer.
- [x] Preserve the immutable historical renderer fixtures and pre-cache paired
      comparison; replace the broken cold-renderer *required CI* comparison
      with a real current-renderer 9-sample/3-case benchmark and exact RGBA8
      SHA-256 fingerprints under pinned Godot 4.8 beta 3.
- [x] Add strict fail-closed native and cold-renderer log verifiers, negative
      Python CI contracts, a repeatable `make test-viewport-cache` target,
      and actual software-X11/regression evidence.
