# Publish detached subtree raster sources atomically into native authority

## Scope
A detached raster subtree currently advances the native revision but does not
publish its tile bytes to Rust until a later gesture. Publish all newly imported
raster layers in one checked revision, including a first-use provisional native
store. Retain the existing untracked import and host Move/Copy history semantics.
Do not modify the Drawing UI or treat this as universal host-history authority.

## Acceptance
- [x] All imported raster tiles are native-owned immediately, preserving exact
  signed RGBA8 including hidden RGB, stable move IDs and fresh copy IDs.
- [x] Validate the full batch, bounded memory, new layer identities, tile
  coordinates/storage and revision; failed import changes neither tree nor
  canonical history, including pending edits and first-use bootstrap.
- [x] Retain unrelated native Undo/Redo; structural park/replay and retirement
  remain byte-exact. Standalone persistence and Atlas Move/Copy replay tested.
- [x] Document ABI and integrate required test coverage; keep T-148 open for
  remaining producers and host-owned history, and preserve owner review gates.
