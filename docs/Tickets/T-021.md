# Eraser tool with predictable removal semantics

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 16.

## Acceptance
- Agree whether each supported artwork representation erases pixels, geometry or selected objects; expose a coherent user interaction.
- Width/cursor feedback, masks, alpha handling and stroke grouping match the accepted editing model.
- Protected content and references cannot be erased.
- Undo restores exact intended content; verify boundaries, turns and saving.

Coordinate with [[T-028]] and [[T-036]].

## Implemented interaction contract and evidence (2026-10-30)

See [[ERASER_WORKFLOW]] for the interaction contract. The existing representation remains authoritative: **ink erases round-swept vector geometry**, preserving original RGBA and stroke width on surviving pieces; **raster clears selected pixels to transparent black RGBA zero** rather than painting with the board background. The Eraser does not delete selected objects, terrain, documents or link references. Neither representation uses brush-color alpha to partially erase. Any representation or geometry refactor stays separately scoped to [[T-028]] and [[T-036]].

- Eraser now displays its real board-unit diameter at any zoom using a coral high-contrast ring, and the inspector explains the removal targets. It hides irrelevant color/opacity controls; it restores them when switching back to Brush. The E shortcut, width wheel behavior, existing history grouping and saved-data schema remain unchanged.
- `tests/eraser_smoke.gd`: **51/51** assertions covering round sweeps, turns, vector dots, original stroke alpha, edit masks, hidden/locked detail, signed raster chunk seams, transparent pixels, no allocations on empty erase, exact undo/redo for ink and raster, protected map links and native-save roundtrips.
- `tests/eraser_visual.gd`: **14/14** native framebuffer assertions for real mouse events, 1×/2× cursor size, visual transparency gap, undo/redo, Inspector controls, and 800×600 compact layout. Snapshot: `user://validation/eraser-native.png`.
- Complete Godot 4.8 beta2 local checks: **34/34** applicable headless suites and **18/18** native framebuffer suites, final reference suite run separately after an aggregate timeout. Parser/import, explicit typing, main-scene launch, Web release export and **4/4** source/exported-pack save interoperability checks passed. Both new tests are in `.github/workflows/godot-check.yml`.
- Remote CI, browser runtime, pen-pressure variants and manual owner usability acceptance have **not** been verified. No legacy artwork or save representation was migrated.
