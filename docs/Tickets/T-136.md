# Enumerate complete detached preview occupancy alongside committed sparse tiles

**Done — 2026-11-15, narrow T-086 throughput improvement, not physical UX acceptance.**
T-135 skipped empty display cells only on committed redraws. A detached
Brush/Move preview forced the old viewport-wide scan even when the existing
bounded preview-stamp index accounted for every changed display tile. The
120,701-cell synthetic 1% view spent about 108ms traversing empty cells on
every preview frame.

## Bounded engineering acceptance

- [x] Union the complete bounded preview display-stamp keys with canonical
  committed occupancy, without drawing duplicates. Preserve signed row-major
  order and independently updated preview generations.
- [x] Require the preview index's explicit `indexed` result. Unknown committed
  occupancy, missing/partial/invalid preview generations, malformed or
  noncanonical coordinate keys, excessive index sizes and dense views **must
  revert to the complete original traversal**, never hide staged pixels.
- [x] Avoid copying large occupancy dictionaries on ordinary dense/normal
  zoom frames when the union cannot qualify; retain the 144-tile GPU cache
  budget, cold-path and canonical straight RGBA8/Undo behavior unchanged.
- [x] Test a real detached preview with committed and preview-only signed
  pixels under native X11, exact framebuffer readback, draft cancellation,
  additional generations, conservative fallback, Undo/Redo and zoom changes.
- [x] Prove the original regression with the identical new witness on T-135;
  record three repeated paired seven-frame CPU `draw()` sample sets, raw logs,
  source hashes and honest workload limitations.
- [x] Pass headless model (18/18), native X11 (26/26), neighboring viewport,
  preview and renderer tests, explicit typing, independent native-absent
  consumer (42/42), and ticket-store validation. Add model to the existing
  46-check fast-CI step and native witness to the existing on-demand workflow.
