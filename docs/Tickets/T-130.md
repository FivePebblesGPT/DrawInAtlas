# Refuse selection/frame context edits while Brush source is unpublished

**Done — bounded engineering input-integrity correction (2026-11-15).**
T-124–T-129 protect queued Brush history, Save/Open, tab, layer and content
mutations while a detached Brush/Eraser stroke still drains. However,
`DrawingWorkspace._deselect()` could clear the selected source mask while
unpublished Brush pixels were pending. `DrawingCanvas.set_selection_mask()`
then cancelled the paint transaction. Similarly, the standalone image-frame
handler changed clipping bounds while Canvas still owned a paint session,
triggering cancellation. Object Editor frame/origin metadata could change
under the same source context without being deferred.

## Independent acceptance

- [x] Reject **Clear Selection** when an enabled mask would be removed under
      an unpublished Brush/Eraser stroke, before invoking Canvas selection
      mutation. Preserve the mask, queued successor and their Undo boundaries.
- [x] Refuse changed standalone image-frame bounds while the stroke is
      unpublished, before updating the tab's saved/dirty frame fields or
      setting `Canvas.image_bounds`; permit a no-op same-frame operation.
- [x] Refuse Object source origin/bounds changes during the same pending
      stroke; do not change authoring guides, source metadata or history.
      Preserve equivalent metadata requests and unrelated presentation views.
- [x] Prove a negative control on the exact pre-change T-129 workspace:
      **16/34** new Godot assertions fail. Candidate passes **34/34** with a
      strict model log, two ordered Brush commits, exact saved pixel and
      frame metadata, plus post-commit operations.
- [x] Re-run neighboring Brush/selection/frame/Object suites, native X11
      image frame, selection and queued Brush tests, and an independent
      native-absent Drawing consumer. Add strict source/CI contracts to the
      existing T-085 required step, with no extra check ID.
