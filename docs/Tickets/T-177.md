# Fail closed on rejected native raster-bearing structural Undo/Redo

**Split from T-148.** T-176 checked semantic-only local Undo/Redo, but
`DrawingDocument._replay_structure()` still removed/restored **raster-bearing**
nodes before trying the Rust parked-layer or never-authorized-layer revision
bridge. A busy/stale native store could reject the bridge after Godot had
already advanced the tree/history, or a rejected unpark could fall through to
an unchecked local-only revision. This ticket repairs that atomicity boundary;
it does not turn GDScript's full structural timeline into native history.

## Acceptance

- [x] Before mutating a recorded raster create/removal/restore, check exact
  attached native revision; acquire `advance_unreferenced_layers_revision` for
  never-authorized IDs or `advance_parked_layers_revision` for previously
  Rust-owned, parked descendant layers. Rejected bridges return typed
  `STALE_REVISION` or `NATIVE_STRUCTURE` without publishing a partial tree.
- [x] Keep `discard_redo=false` for local Undo/Redo and increment the Godot
  and native revisions exactly once on acceptance. Preserve the existing
  native-absent historical path and valid semantic-only replay.
- [x] Reject busy and native-ahead raster Undo/Redo without moving the local
  history cursor, changing dirty state or full RGBA8 (including hidden RGB),
  dropping native tokens, or detaching the Rust store; successful retry must
  restore the exact tree and leave later Hokusai Undo/Redo and Save/Open valid.
- [x] Preserve parked source/snapshot validation and refuse a formerly
  authorized raster-create Undo that cannot pass the unreferenced Rust bridge.
- [x] Run the real-native regression, pre-fix negative control, pinned offline
  Rust checks, Drawing/Atlas/Object neighbors and graphical 96px witnesses;
  wire required-native CI, evidence with verified SHA-256, and Index/ABI sync.

## Boundaries

Local recorded raster-bearing structural replay only. This does not add a
history-aware mechanism for undoing creation of an already-native-authorized
raster with retained Rust tokens; such a replay **fails closed** rather than
silently discarding the source. Host-owned detached history, other raster
producers, and universal native authority remain T-148 work. No T-095 hardware
signoff or T-149 unblocking is implied.
