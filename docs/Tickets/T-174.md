# Fail closed on rejected native semantic and density revisions

**Split from T-148.** Four public semantic/density mutation paths —
`DrawingDocument.add_object`, `move_object`, `commit_text` (both text creation
and edit), and `set_density` — previously changed Godot's document **before**
calling `_advance_nonraster_revision()`. If Rust had an active transaction or
its revision was ahead, that post-mutation bridge detached Rust's canonical
tile store despite the caller reporting success, invalidating native history.

## Acceptance

- [x] Call the checked native metadata revision bridge only after validating
  and preparing the semantic change but before changing any live document
  state, including text-tree membership, text Undo entries, object values,
  density, and dirty state. Reject `STALE_REVISION` and `NATIVE_METADATA`
  without detaching a rejected Rust store.
- [x] Preserve same-value text/density no-ops, native-absent behavior pending
  T-150, and successful retries after the held transaction is released.
  Keep canonical straight RGBA8, the original Brush Undo tokens and shared
  revision through subsequent Hokusai strokes, text Undo/Redo and Save/Open.
- [x] Use a real Rust/Hokusai 48-check positive fixture and the identical
  pre-fix fail-first control (25/48 assertions fail before the fix; 48/48 pass
  after), including both busy and native-ahead rejection, and empty-store
  density edit transactions.
- [x] Run pinned offline Rust unit tests, formatting, strict Clippy and
  release build; Godot Drawing and root Atlas/Object native-history tests;
  software-X11 graphical Canvas and full 96px/512² Hokusai witness.
- [x] Add required-native CI, native ABI note, parent/Index updates,
  checksummed raw logs and ticket-store validation.

## Scope boundary

This ticket protects **four public entry points** for non-raster document
changes. Internal structural-history replay, semantic-only detached imports,
other host-owned history and remaining raster producers are still T-148 work.
No T-149 completion, hosted CI green, T-095 hardware result or manual review
is implied by these local tests.
