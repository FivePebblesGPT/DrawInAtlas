# Use consistent icon-only panel tabs inside minimized dock flyouts

## Owner reproduction — 2026-11-22

The owner sees **text tab/buttons** in panel flyouts while the expanded dock and floating hosts use icons. The new screenshot `image(1).png` and the concept `DrawInAtlasColorPanelConcept.png` are referenced in [the owner review](../DRAWING_UX_REVIEW_2026-11-22.md).

## Acceptance

- [ ] Flyout header/tab controls share the canonical panel icon assets, sizing, pressed/focus and tooltip/accessible labels with docked and floating tabs. Remove visible tab-name/text buttons; unknown registered panels use the same icon fallback.
- [ ] LMB selects/toggles the appropriate flyout group; RMB/Shift+F10 opens a context menu scoped to the clicked panel without activating it. Do not mutate persistent collapsed bits from transient flyout actions.
- [ ] Moving an individual icon versus whole group remains unambiguous; Escape, redock, hide/reopen, scrolling and one-group floating ownership preserve panel view identity and layout.
- [ ] Verify mouse and keyboard interaction plus real X11 screenshots across narrow, 100/150/200% scaling, standalone and Atlas embedding.
