## Acceptance

- [x] Flyout header/tab controls share the canonical panel icon assets, sizing, pressed/focus and tooltip/accessible labels with docked and floating tabs. Remove visible tab-name/text buttons; unknown registered panels use the same icon fallback.
- [x] LMB selects/toggles the appropriate flyout group; RMB/Shift+F10 opens a context menu scoped to the clicked panel without activating it. Do not mutate persistent collapsed bits from transient flyout actions.
- [x] Moving an individual icon versus whole group remains unambiguous; Escape, redock, hide/reopen, scrolling and one-group floating ownership preserve panel view identity and layout.
- [x] Verify mouse and keyboard interaction plus real X11 screenshots across narrow, 100/150/200% scaling, standalone and Atlas embedding.

**Boundary:** T-225's floating tabs remain historically Done. New flyout presentation still requires T-250's owner acceptance.

## Engineering completion — 2026-11-22

The flyout tab strip now uses the same `DrawingDockIcons.for_panel()` textures,
42×42 centered icon-only buttons, pressed state, focus mode, named tooltips and
accessibility labels as docked and floating tabs. A repeated click on the active
tab keeps it selected and open. Drag suppression restores the model's pressed
state rather than letting a canceled drag toggle the icon. `Shift+F10`/Menu
now routes focused *flyout* tabs through the same clicked-panel context menu
as dock/rail tabs; its commands do not change active tabs while opening.

[Native, Atlas, fail-first and screenshot evidence](../evidence/T-254-2026-11-22-flyout-icons.md)
records a prior-code failure (81 assertions), corrected **183/183** X11 checks
including screenshot capture and **12/12** Atlas checks, native 100/150/200%
and narrow layouts, save/restart, Escape rollback, floating hide/reopen and
redock, plus neighboring dock regressions. This is a software-engineering
completion only: **T-250 owner hands-on UX approval remains open**, including
a real-device Selection Delete recheck; T-083/T-059 retain their own gates.
