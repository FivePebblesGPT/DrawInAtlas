# Responsive workspace, menu semantics, document tabs, brush wheel and icons

**Status: Ready (2026-11-05).** Newly scoped corrective work from the owner's first hands-on standalone Drawing review. Source observations are in [the owner review](../DRAWING_USABILITY_REVIEW_2026-11-05.md). Existing earlier "Done" tickets retain their original, narrower acceptance; this ticket does **not** inherit their UX approval.

## Problem / scope
At nondefault resolutions the app shows side black bars; menus mix object/file actions into Window; document tabs have detached global +/× controls; brush-size wheel scrolling is swallowed by tool-option navigation. Custom tool SVGs exist despite a bundled icon addon, but their authorship is unknown.

## Engineering tasks
1. Correct Godot window stretch/aspect and sizing for resizable desktop widths, heights, UI scales and minimum limits; keep the canvas in the remaining client area.
2. Preserve one menu+context-options row but organize File/Edit/View/Image/Layers/Select/Window/Help by real command semantics; Object file actions under File/Object where appropriate, Window only workspace controls.
3. Close directly from each document tab with the current dirty/unsaved guard; drop the global + control while keeping File > New/Ctrl+N.
4. Revisit `editor_top_bar.consume_option_wheel`: wheel on brush size must adjust its numeric value; reserve Shift+wheel/other cues for scrolling crowded tool options. Document keyboard brush-size controls.
5. Audit `addons/at-icons/` and existing `addons/drawing/icons/` for an appropriate consistent icon family and license; avoid assuming custom SVG generation provenance.

## Acceptance / verification
- [ ] No pillarboxing/black bars or clipped document controls on resized desktop; test 800×600, 1280×760, large and 150–200% UI scale.
- [ ] Menus place commands logically with discoverable shortcuts; tab close/dirty prompt and Ctrl+N work.
- [ ] Mouse wheel on Brush px changes value reliably; options overflow still works without stealing field input.
- [ ] Tool icons are a cohesive, legible, licensed set and consistent in pressed/disabled/focus states; native screenshots and pointer validation.

## Boundaries
- Preserve the one canonical Drawing package shared with Atlas, byte-exact saved RGBA8, source identity, one undoable content transaction per gesture and signed sparse coordinates.
- Add headless model tests and **actual native pointer/framebuffer tests** where interaction or visible pixels are involved; source/README checks alone are insufficient.
- Do not mark complete merely because earlier T-053/T-063/Docking smoke tests pass. Report hardware, Godot version, viewport, zoom, timing and limitations for applicable evidence.
