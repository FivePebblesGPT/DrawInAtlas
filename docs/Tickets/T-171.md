# Reject unauthorized native-owned raster bytes in detached subtree exports

**Split from T-148.** `DrawingDocument.export_subtree()` previously resolved
lazy tiles and returned detached Godot raster projections without verifying
their revision or full source bytes against an already-attached Rust tile
store. Unlike the protected T-166/T-167 save paths, this allowed standalone
`transfer_subtree(move=false)` and Atlas Copy to export changed hidden RGB
without native authorization. T-170 checked source retirement only for Move;
Copy does not retire the source and must independently verify its export.

## Acceptance

- [x] Before resolving lazy sources, validate the attached Rust revision and
  canonical full RGBA8 for each selected subtree resident/authorized tile.
  Reject a divergence without returning a detached snapshot or mutating a
  destination, including hidden RGB under zero alpha.
- [x] Recheck after lazy source callbacks and before detaching, so a provider
  cannot silently mutate another selected native source at the same revision.
  Reject mid-export revision drift. The checked scope is the exported subtree,
  not unrelated layers; native-absent historical exports remain available
  until T-150.
- [x] Prove direct export, standalone Copy and Atlas Copy fail closed and
  preserve both documents' revisions, native bytes/history and destination
  membership after rejection. Verify byte-exact correction/retry, a valid
  copied subtree and native-ahead rejection.
- [x] Run the new real Hokusai/Rust regression against the old exporter as a
  fail-first control, then run Rust/unit/build, native tile/history, transfer,
  Atlas/Object and 96px software-X11 witnesses; check process exits and
  success markers.
- [x] Add native CI coverage, update ABI contract, parent T-148 and Kanban,
  validate ticket dependencies, and retain checksummed raw execution logs.

## Evidence and remaining boundary

[Execution evidence](../evidence/T-171-2026-11-16-native-export-fence.md)
includes a 33-check positive native export/Copy witness, a 32-check original
exporter negative control with 11 failures, and a 25-invocation green Rust,
Godot, Atlas/Object and graphical matrix. This protects checked detached
**exports**, not general two-document atomicity with arbitrary host callbacks,
or host-owned detached history snapshots. T-148 remains In Progress; T-149
stays Blocked; T-095 requires physical owner/hardware acceptance.
