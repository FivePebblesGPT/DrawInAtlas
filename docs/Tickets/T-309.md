# Restore individual hidden panels from Window menu

## Owner finding — 2026-11-25
Closing a floating window hides its panels; only Show hidden floating panels restores them all. Window > Float selected dock group is unwanted convenience chrome.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
List individually named available panels under Window (with visible/hidden state), restore one specific panel without unintentionally restoring peers, and remove Float selected dock group menu command. Preserve existing pointer-based floating/docking, groups, placement and layout persistence. Existing bulk restore may remain only if useful and not a substitute for individual access.
