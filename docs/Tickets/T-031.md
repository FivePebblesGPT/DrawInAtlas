# Align tile-layer naming and choose one type authority

## Source
[[ManualReview_2026-10-30#Code review|Code review]], item 4: `terrain_layer.gd` declares `AtlasTileLayer`, attaches grid data and also stores a hardcoded `kind`.

## Acceptance
- Explain the current class/file naming, geometry ownership and discriminator uses.
- Decide the authoritative type mechanism and remove redundant mutable authority as approved.
- Align names with the chosen model without breaking references, cloning, native saving or legacy data policy.
- Coordinate conversion/discriminator cleanup with [[T-029]] rather than removing a still-required field blindly.

## Outcome — 2026-10-30

**Chosen type authority:** The *concrete Godot `Resource` script class* is authoritative in memory. `AtlasInkLayer`, `AtlasTerrainLayer`, and `AtlasRasterLayer` each derive their immutable-in-practice `kind` discriminator (`INK`, historical `TILES`, and `RASTER`) from `layer_kind()`. A native save's exported `kind` property remains for compatibility, but its setter only checks the loaded value; a mismatch invalidates the resource for cloning, collections, native packing and unpacking. Dictionary/clipboard boundaries still use `kind` to select a concrete class, and now reject contradictory type-specific payload fields rather than silently interpreting data as another type. Thus neither serialization mechanism can retype a live resource.

**Naming and geometry ownership:** The old `AtlasTileLayer` name meant palette-indexed **terrain cells**, not Godot TileMap tiles or a separate tile canvas. The runtime class is now `AtlasTerrainLayer`, and project code uses that name. The original `scripts/artwork/terrain_layer.gd` path and script UID remain untouched because historical native `.scn`/`.tscn` files reference them. `AtlasTileLayer` survives only as a source-level compatibility alias. A terrain layer's `grid` is the basis for its stored cell keys; the board/view grid is independent, and ink/raster layers remain in shared document coordinates. There is no new authority for coordinate transforms.

**Persistence decision:** Preserve the current native-save format, version, legacy `TILES` wire marker and dictionary adapters audited in [[T-029]]. Do not rename native resource paths, rewrite user saves, or migrate old palettes. The new tests include pre-change `.scn` and `.tscn` native save fixtures and reject intentionally corrupted type markers. All changes are schema-preserving and confined to type validation and naming.

**Verification (Godot 4.8 beta2):** T-031 class/legacy-fixture regression **36/36**; **43/43 applicable headless regression suites**; **24/24 native framebuffer suites** using Xvfb/Mesa Compatibility and Dummy audio; explicit-type audit; resource import/parser and main-scene launch; non-threaded Web release export; and four source/exported-pack native-save portability checks. Added `tests/tile_layer_type_smoke.gd` and both legacy fixtures to CI. Remote CI and manual user acceptance have not been verified.
