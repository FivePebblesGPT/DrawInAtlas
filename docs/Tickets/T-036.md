## Implementation — 2026-10-30

- Kept the public `AtlasStrokeEraser.erase()` contract and validation intact:
  gesture points and eraser width are finite document/board units, invalid
  gestures return detached no-op copies, and collision radius is half the sum
  of the stroke and eraser diameters. Source strokes are already validated at
  the editor/ink-layer boundary, not silently changed by this service.
- Made the **whole-object versus centerline** decision explicit. Text is
  touched by an eraser-radius-expanded glyph bounds/segment test; editable
  walls by rendered (not handle) segments; filled polygons by boundary
  proximity or sweep vertices inside the shape. A hit removes these semantic
  objects wholly, while misses copy all metadata. The dedicated
  `_touches_whole_object()` helper does not convert them into plain strokes.
- Extracted `_retained_centerline_parts()` as the cohesive sequential clip
  stage for ordinary strokes. It duplicates source vertices; for each sweep
  segment it subtracts every round capsule from the current remaining parts,
  checking single-point fragments for containment. Each nonempty retained
  part becomes an independent stroke with its **original RGBA and width**.
  The order of eraser segments and returned fragments is unchanged.
- Documented `_touches()`'s inclusive squared-distance boundary, degenerate
  dot tests, the 32-sided stationary capsule approximation, and the text
  rectangle-crossing case. Kept Godot's existing polygon operations and
  boundary semantics; no geometry algorithm, representation, persistent
  schema, public API, mask behavior or command-history change was introduced.
- Extended `tests/eraser_smoke.gd` with two separated cuts, copy ownership,
  whole-object fill/wall/text hits and misses, invalid gesture and width
  no-ops, and post-result mutation isolation. Existing tests retain the
  actual editor undo/redo and native save/load exactness assertions.
