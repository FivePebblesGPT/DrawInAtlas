# Restore the T-068 stationary-dab Geometry2D oracle under native tile history

## Failure

`tests/drawing_dab_geometry_smoke.gd` fails 75 of 125 assertions on the
required Rust-backed Godot 4.8 beta4 build. Its `>2^53` brush anchor cannot
be published by the signed native tile projection, and it expects the retired
`DrawingDelta.after` per-pixel history map. This failure does not demonstrate
that the current dab raster has different geometry.

## Acceptance

- [x] Reproduce the full failure before changing the fixture.
- [x] Retain every original brush size, fractional position, exact
      Geometry2D circle membership predicate, full RGBA8, and hidden-RGB
      zero-alpha/no-op assertion; do not alter production raster code.
- [x] Relocate to a fixed native-publishable large signed anchor with
      nonzero low bits, prove native commit advances one revision, and
      compare staged touched-pixel count to an **independent** Geometry2D
      coverage oracle rather than `DrawingDelta.after`.
- [x] Verify exact document pixels across the entire computed region at
      commit, after Undo (blank), and after Redo (the original dab).
- [x] Explicitly reject an out-of-projection `>2^53` publication with
      no document revision/pixel mutation.
- [x] Run neighboring native history, signed-boundary and immutable Skia
      oracle tests; report unrelated red cases honestly.
- [x] Update T-068, the index and retained evidence without treating this
      independent fixture correction as complete T-068/hosted CI acceptance.

## Evidence and gate

The original **125-check / 75-failure** fixture reproduces under the actual
native extension. Relocating just the anchor reduces failures to **15**;
the remaining 15 are the obsolete delta assertions. The final enhanced
fixture passes **112/112**, comparing independent Geometry2D coverage and
complete committed/Undo/Redo RGBA8 regions for all 15 cases, plus a rejected
unsafe publication. [Commands and raw logs](../evidence/T-279-2026-11-23-dab-native-geometry.md).
