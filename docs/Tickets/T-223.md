# Replace named group headers with half-width triangle markers

## Owner design (2026-11-20)

Show **no visible group names**. Adjacent panel icons communicate grouping. Each group uses a narrow **marker approximately half a panel icon wide** with triangle indicating collapsed/expanded state, replacing the current full-width group title, oversized chevron, separate `↕` handle and always-visible `⋮` button.

- **LMB marker:** collapse/expand just its group. This is the explicit group-level toggle; T-222's active-panel click offers the same collapsed result in an expanded dock, not an additional independent state.
- **Drag marker:** move the **whole group** (distinct from dragging any panel icon). Floating hosts retain T-091's whole-host grip rather than adding another title row.
- **RMB marker:** open the group context menu with float/merge/split/reorder where valid.
- Retain tooltips/accessible group identification; marker width need not imply an unusably small clickable hit target.

## Acceptance

- [ ] No redundant group heading row or text label; triangle is visually tied to its group and state.
- [ ] Marker drag vs LMB vs RMB is unambiguous and transaction-safe; active tab and collapsed status persist through redock/restart.
- [ ] One-group floating-host invariant, keyboard/focus, scrolling, 150–200% DPI and native screenshot/pointer checks pass.

Requires T-222's stable icon actions. T-083 retains owner UX signoff.
