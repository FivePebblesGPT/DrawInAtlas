# Extract a campaign-independent Drawing core and surface contract

## Status
**PLANNED / BLOCKED by T-051.** Class names and persistent ownership below are provisional until approved.

## Scope
Separate ordinary board-space artwork from the containing campaign/map/floor. Reuse the existing sparse `AtlasRasterLayer`, `AtlasObjectsLayer`, raster chunk, shape, text, selection, fill and brush implementations wherever possible; avoid algorithm rewrites or serialized Resource renames.

## Implementation plan
1. Inventory Drawing types and dependencies from `scripts/artwork/`, `scripts/editing/` and `scripts/interface/artwork_editor.gd`; document current `AtlasCampaign`, `AtlasFloor`, `AtlasGrid` and `AtlasCanvas` references.
2. Introduce a typed, runtime-only Drawing surface/document facade exposing ordered layers, detail groups, IDs and board-space geometry. Initially adapt existing `AtlasFloor.layers` rather than adding a new stored Resource property.
3. Move tool routing, edit-target resolution, brush/fill/shape/semantic-object operations and clipboard-related logic behind a Drawing service that accepts an explicit surface and session context. Atlas-specific cell masks are passed as board-space geometry or an abstract policy, not as `AtlasGrid` instances.
4. Preserve sparse first-stroke allocation, 4 px/board-unit authoring defaults, signed chunk coordinates, raster/Objects semantics, active-layer protections, and full gesture atomicity.
5. Add `tests/drawing_core_smoke.gd` that instantiates a drawing surface directly without any campaign, map or scene; include brush, erase, fill, object edits, masks, locks, invalid snapshots and D-level isolation.

## Acceptance
- Headless Drawing core tests run with no `AtlasCampaign`, `AtlasMapDocument`, `AtlasFloor` or `AtlasCanvas` instance.
- No Drawing core imports or references Atlas domain/navigation/UI types after extraction; any transitional adapters live outside Drawing.
- Existing painting/clipboard/storage suites still pass. No persistent schema or Resource script path changes.
- A failed/stale drawing edit leaves the source image/layers unchanged, including alpha and negative coordinates.

## Not included
No visual shell rewrite, Atlas link/navigation changes, new tools or save-format migration.
