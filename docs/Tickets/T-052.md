# Extract a physically independent Drawing document, tools and snapping

**Status: PLANNED, blocked by T-051.**

## Plan
1. Create a self-contained Drawing source/package root that has no Atlas dependency; establish standalone tests and public API for document, layer, render request, input intent and edit transaction.
2. Define DrawingDocument with ordinary raster, semantic object and text layers/groups; no Atlas floor, grid, map or campaign types. Preserve sparse signed raster chunks, alpha and editable-layer selection.
3. Reuse or extract existing brush, eraser, fill, shapes, object selection, clipboard and renderer-relevant artwork services without rewriting algorithms unnecessarily.
4. Implement Drawing-owned snapping (Aseprite-like pixel/grid/guides/object anchors), accepting optional primitive snap candidates or generic constraint policy from Atlas.
5. Keep tool selection non-mutating. Layer creation occurs on successful content commits where appropriate; text follows T-058. Validate locked/hidden layers and selected target consistently.
6. Separate editable canonical artwork from derived preview/mipmap texture caches. Do not impose Atlas's authored LOD structure on Drawing's core.
7. Add no-Atlas headless suites for independent documents, negative chunks, first paint, cancellation, masks, snapping, locks and object edits.

## Acceptance
Building/running tests with Atlas files absent works; Drawing type dependencies exclude AtlasCampaign, AtlasFloor, AtlasGrid, AtlasCanvas, links and projector; an independent document can be edited/undone without a campaign. No historical save migration.
