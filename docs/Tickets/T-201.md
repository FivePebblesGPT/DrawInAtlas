# Package and verify required-native standalone Linux exports

## Bounded delivery — 2026-11-19

The T-068 Linux release gate and T-105 Linux process sampler still expected
**native-absent** ELF/PCK files after T-153 made Rust Hokusai mandatory.
The PCK actually contains the `drawing_brush.gdextension` manifest but **not**
the referenced `libdrawing_brush.so`; the old release gate forbade the binary
and copied only two files into its isolated runtime. This test contract could
never validate the alpha Drawing executable.

- [x] Add a separate fail-closed `tools/package_linux_export.py` step, which
  installs only the canonical Linux x86_64 shared library into the exported
  directory; verify stage manifest, entry symbol, Linux mapping, ELF identity
  and SHA-256. Refuse missing, mismatched, extra or symlinked native inputs,
  destinations and distribution artifacts; never silently overwrite a
  mismatched existing ELF.
- [x] Make `t068_release_gate.py` **require** that library on Linux, inspect
  it alongside the ELF/PCK, then run the actual packed native ABI smoke and
  a separate app launch from a clean profile, unrelated working directory,
  and **copied** output (with `--path` to resolve the native library).
  Keep Windows-only legacy PE/PCK inspection clearly *structural and
  non-native-certified*, not a false Windows release approval.
- [x] Make the T-105 Linux memory sampler copy/launch the same native
  distribution and validate its library digest. Update fast desktop and
  on-demand Linux CI export stages and Drawing README. Preserve the historical
  native-absent T-105 evidence as historical, not a valid current replay.
- [x] Fail-first/new negative controls, local pack + real Godot beta3 ABI,
  clean isolated app boot, two live CPU/RSS samples, Rust and native Drawing
  regressions, Python and offline Ruff/ty. Preserve failures and exact limits.

## Verification and open integration gates

See [T-201 execution report](../evidence/T-201-2026-11-19-linux-native-export.md)
and [byte-preserved raw evidence](../evidence/T-201-2026-11-19-linux-native-export-raw/).
The new checks exercise a real exported PCK **paired with the exact Godot
beta3 executable as a temporary surrogate**. This container has no official
Godot beta3 export templates: `--export-release Linux` fails before writing
an executable. Consequently **no official export-template runtime, hosted CI,
Windows native DLL/export or physical release acceptance is claimed here**.
These remain under T-180/T-105/T-106/T-150. This Done ticket covers the
independent packaging, inspection, and runtime-verification code, not those
parents' remaining release gates. No painting, history, renderer, native ABI,
canonical pixels, or owner/manual acceptance was changed.

## 2026-11-19 — atomic packaging follow-up (T-212 Done)

[T-212](T-212.md) closes a remaining packaging side effect: invalid
exports previously retained a copied native `.so` despite `PackageError`.
A separately validated temporary ELF/PCK/native candidate now rejects those
inputs before publication; a late inspection refusal removes only newly
installed bytes. A real Godot beta3 PCK/native-ABI/runtime check passes.
This does not retroactively certify hosted official export templates, Windows
or owner/device review.

## 2026-11-23 — repeated beta4 export normalization (T-285)

[T-285](T-285.md) closes a post-beta4 repeat-export corner case: when the
canonical native library already exists and the engine emits another matching
root-level copy, normalize only after validating both against the staged
SHA-256 and the exact final PCK/ELF/native projection. Roll back the extra
copy on late inspection failure; reject foreign bytes unchanged. This does
**not** certify hosted export templates, Windows builds or owner acceptance.
