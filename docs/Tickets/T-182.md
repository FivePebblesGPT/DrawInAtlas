# Expose native brush presets in the Drawing tool options

Owner could not select presets for the 96px hard-round fill benchmark. Canvas
already supported four Hokusai presets, but the shared workspace exposed only
width and snap controls.

## Scope and acceptance

- [x] Expose Hard Round, Soft, Ink and Airbrush for Brush and Eraser.
- [x] Keep the width control capable of selecting 96 Drawing pixels.
- [x] Preserve settings when switching tools, without editing document history.
- [x] Own inactive option controls, including the never-selected selection
      dropdown, so workspace teardown does not leak its popup viewport.
- [x] Keep narrow-window options on one scrollable row; verify focus/wheel and
      ordinary Save/Open/dirty-state contracts with a swept native stroke.
- [ ] Observe the actual selector and 96px setting in the graphical application.
- [ ] Record evidence and hosted native preset-control results.

This adds preset selection, not a renderer/backend switch or a Legacy fallback.
The 96px native full-512-square benchmark reaches 262,144 covered pixels with no
holes, but its measured virtual-run latency does not satisfy T-095 acceptance.
