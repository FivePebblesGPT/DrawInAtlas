# Replace application preference JSON files with native configuration

**Owner direction, 2026-11-27:** binary-only application persistence; no historical save migration.

Replace application-owned dock layout, workspace preferences, recent colors and recent Object root JSON files with versioned Godot native configuration (`ConfigFile` or bounded typed binary as appropriate). No JSON migration or duplicate writer; preserve validated defaults and atomic updates. Treat external MyPaint `.myb` preset interchange as a separate protocol, not a save format.

## Acceptance
- [ ] Restore layouts and preferences on close/reopen, including floating/hidden panel groups, recent colors and source roots. Preserve bounds/schema validation, safe recovery from malformed/unsupported files and no-op/failed-write behavior.
- [ ] Update path consumers and tests together; exercise standalone and hosted persistence, focus/state transitions and real application behavior. If visible changes occur, follow AGENTS.md visual inspection. Do not infer owner acceptance.
