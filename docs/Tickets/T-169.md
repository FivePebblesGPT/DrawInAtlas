# Fail closed on rejected native-attached raster subtree import

**Split from T-148.** `DrawingDocument.import_subtree()` prebuilt detached
raster tiles but passed them to the void `_advance_raster_structure_revision()`
bridge, which incremented the Godot revision even if Rust rejected the edit.
An active native transaction, native-ahead revision or more than 128 raster
IDs could leave new Godot nodes published while Rust remained at the old
revision, forcing a subsequent history-clearing rebase.

## Acceptance

- [x] Prepare the complete detached subtree before any native or Godot
  publication. For raster-bearing imports with an attached Rust store,
  reject divergent native revisions and refuse an unsuccessful bounded
  `advance_unreferenced_layers_revision` call without adding nodes,
  dirty tiles, changing revision or touching local history.
- [x] Preserve unrelated canonical Rust bytes and Undo/Redo tokens on valid
  new-ID imports, with one shared revision. Preserve hidden RGB and
  independent donor source; native-absent imports retain their preexisting
  behavior (Legacy retirement remains T-150).
- [x] Cover busy, native-ahead and over-128-ID rejection with a real
  Hokusai/Rust-native test and a fail-first control; update the older T-148
  over-limit regression, which formerly expected a Godot-only fallback.
- [x] Run Rust and Godot integration, Atlas/Object/history and graphical
  witnesses; record raw exit statuses and strict markers, update CI, ABI and
  `docs/Index.md` without closing T-148 or T-095's owner gate.

## Evidence and remaining boundary

[T-169 execution evidence](../evidence/T-169-2026-11-16-native-import-fence.md)
records the native-attached test, negative control, neighboring suites,
raw logs and SHA-256 checksums. This closes **new raster subtree imports**;
it does not complete universal native authority, the general host-owned
history timeline, or cross-document move atomicity. T-148 is In Progress;
T-149 remains Blocked and T-095 is owner/hardware-gated.
