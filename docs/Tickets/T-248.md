# Preserve Atlas active-map target during reserved history callbacks

**Bounded T-148 child.** T-245–T-247 prevent history methods from mutating
an Atlas command timeline reentrantly. However `AtlasEditHistory.active_map_id`
remained publicly writable. Synchronous context providers, command apply
callbacks, history notifications, and Undo/Redo restorers could reassign the
active edit target while a command was executing or replaying. This breaks the
assumption that the command and editor navigation remain associated with the
same active map throughout a reserved history operation.

## Acceptance

- [x] Reject direct and reflective `active_map_id` reassignment during a
  reserved history transaction or Undo/Redo replay, including synchronous
  `changed` and reset notifications.
- [x] Continue to allow ordinary idle navigation, including after rejected
  operations and between a pending gesture and its eventual commit.
- [x] Preserve the original command, chronological Undo/Redo, reset behavior,
  context capture and the editor's active-map read contract.
- [x] Reproduce the behavior before the fix; pin the exact-count regression
  to required fast CI and execute neighboring host-history regressions.

## Completion — 2026-11-22

The 70-check Atlas fixture reproduced **14/70 failures** on the previous
implementation, including direct and reflective writes during command apply,
context capture, native Drawing publication, changed notification, Undo/Redo
restoration, and reset.
The guarded property passes **70/70**. The neighboring T-245/T-246/T-247,
Atlas global history and editor history suites pass. The ticket-store
validator and required-CI source-contract checks pass. See
[execution evidence](../evidence/T-248-2026-11-22-active-map-reservation.md).

**Scope:** This guards public active-map navigation through the normal property
interface during synchronous history operations. It does not stop arbitrary
direct mutation of campaign objects, complete universal native authority,
or supply hosted CI/owner-hardware approval. T-148 remains In Progress and
T-149 remains Blocked.
