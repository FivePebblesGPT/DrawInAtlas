# Authorize portable file raster sources immediately on Open

## Scope
Portable Drawing decode already checks every referenced tile and resolves it
into a Godot projection. Make those validated bytes native-owned before
returning the document, at the saved revision (not an edit). Apply the same
boundary to binary and legacy JSON files and portable Object sources. Keep the
Atlas sparse campaign loader lazy and its persisted format unchanged.

## Acceptance
- [x] All validated resident raster sources enter one provisional Rust owner,
  including signed coordinates, hidden RGB and invisible/locked layers.
- [x] Publish the attachment only after every import succeeds. Reject unresolved,
  non-pristine, malformed or over-budget initialization without installing a
  partial owner. Preserve published revision, dirty state and empty history.
- [x] Save/Copy fences work before first paint; exact correction retries.
  Subsequent edits, Undo/Redo and structural parking retain the same owner.
- [x] Binary, legacy and portable Object Open tested; Object Save produces an
  independent owner without copying the old native history. Sparse logical
  manifests remain lazy; historical unsupported-stride model fixtures remain
  readable.
- [x] Run required-native and adjacent persistence tests; update the file/ABI
  contract, evidence, Kanban and CI. Leave T-148 and review gates open.

[Execution evidence](../evidence/T-315-2026-11-25-native-file-sources.md).

source admission or native ownership of host-history snapshots. Existing
