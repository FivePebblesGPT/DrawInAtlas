# Compact the Brushes selector and expose verified libmypaint parameters

## Owner design (2026-11-20)

Keep the visual native Hokusai preset tiles from completed T-184, but greatly **reduce persistent descriptive text**; use hints/tooltips, readable compact controls and keyboard accessibility. T-182 owns the historical preset dropdown and keyboard accessibility; T-184 owns the already-delivered initial native-backed panel. This ticket owns **only the additional densification and extra verified controls**, not reimplementing those completed features. Width, opacity and hardness already exist. The owner requests **more meaningful libmypaint brush parameters**.

## Scope

1. Inventory actual bundled `.myb` settings and Rust Hokusai/libmypaint support. Define per-preset capabilities, units/ranges/defaults and pressure/speed dynamics; do not expose unsupported knobs or pretend they work.
2. Add a bounded set of genuinely engine-mapped parameters (for example spacing/dab density or flow **only if confirmed**). Where a preset does not support a parameter, hide or disable it with an explanatory hint.
3. Maintain the one canonical settings authority for Brush/Eraser, compact top bar, panel and persistence. Freeze the *entire* effective native preset for queued/in-flight gestures; invalid values fail closed.
4. Native before/after stroke tests must establish observable effects, retained preset defaults, correct alpha/pixel/Undo, cancel, Save/Open and 96px semantics.

## Acceptance

- [x] Preset-first selector shows previews/active state with minimal persistent text, helpful tooltips and accessible labels.
- [x] Every newly exposed parameter has a documented, tested native mapping and effect; no inactive decorative sliders.
- [x] Narrow/floating/HiDPI UI, reset and per-preset persistence, queued gesture freezing, native Rust/graphical regression and performance sanity pass.
- [x] T-184 remains Done for its narrower initial visual-panel deliverable; hardware UX signoff remains elsewhere.

## Completion — 2026-11-22

The dock now has a two-column native preview grid, compact labeled inputs and
tooltips/accessibility. **Dab density** (1–8 dabs/actual radius) is the sole
additional control: all four `.myb` presets have a verified non-dynamic
`dabs_per_actual_radius` base (4.02 / 3.14 / 2.20 / 5.75). Hokusai uses it for
actual stroke dab spacing; native output and exact Undo/Redo/Save/Open verify
an observable effect. Pressure/speed curves are retained, and unknown knobs
are not shown. V3 preferences validate the per-preset overrides and read older
v1/v2 settings. Live and pending gestures retain frozen effective values.
