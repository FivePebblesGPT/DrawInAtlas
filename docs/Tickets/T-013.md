# Frame the projector viewport with a GM-board object

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], items 10 and 12, superseded by the user's later projection-object decision in [[E-007]]. This ticket retains its ID but replaces the retired battlemat move/resize work.

## Acceptance
- Display a selectable framing object on the GM board matching the active projector output's aspect ratio.
- Moving it pans the player camera; enlarging/shrinking it zooms out/in by showing more/less board.
- Its manipulation does not move, resize, resample or reassign artwork.
- Keep framing separate from output-window dimensions and physical projector/grid calibration.
- Respect the player privacy contract and agree persistence, cancellation, follow/freeze and history semantics before implementation.
- Demonstrate framing controls through real native input.

## Interactive GM-only candidate — 2026-11-01 (acceptance pending)

See [[PROJECTOR_FRAME_WORKFLOW]]. The toolbar now offers a session-only cyan
framing rectangle with selected output **aspect**, left-drag pan and lower-right
handle resize (top-left anchor). Changes do not move/resample artwork, mutate
the campaign, use native undo history, or affect the independent GM camera.
Esc/right-click can cancel a draft; switching artwork tools or boards exits
frame mode. These controls are exercised through actual native pointer input.

**Not a completed projector:** T-039's publication and freeze policy remains
unapproved. Frame size is not projector physical calibration; there is no
player output window, live follow/freeze, persisted framing policy or
privacy-filtered player render connected to these inputs. Current defaults are
proposals; owner acceptance of UX, cancellation, camera behavior, save/history
and output behavior is still needed. Thus T-013 remains **unchecked**.

### Local verification (Godot 4.8 beta 2, Xvfb/Mesa)

Focused geometry/session test: **18/18 assertions**; native pointer and
framebuffer test: **14/14 assertions**, with `projector-frame-960.png` and
`projector-frame-800.png` witnesses. Full regression sweeps passed **48/48
headless** and **28/28 native** suites, including T-039's privacy proof.
Godot launch, Web release export and four source↔export-pack portable save
checks passed. Explicit typing, Git diff and Git LFS integrity checks passed.
No remote CI, real second-screen output or owner interaction acceptance has
been performed; the frame is deliberately not connected to player rendering.
