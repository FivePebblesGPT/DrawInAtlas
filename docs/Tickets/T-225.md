# Use dock-style panel icons instead of text in floating tabs

## Owner design (2026-11-20)

Floating panel tabs currently use labels where docked tabs use icons. This changes **tab chrome only**: T-091 remains owner of floating-host geometry, one-group ownership and width recovery. T-222 governs expanded-dock icon collapse; clicking an active icon **in a floating host must not collapse or close its window**. Render the **same recognisable icon** and active/focus states in floating tabs, with names shown by tooltip/accessibility rather than persistent text.

## Scope and acceptance

- [x] Preserve T-091's compact **one tabbed group per in-app floating host**, move grip, close action and edge/corner resizing; do not reintroduce group-name rows.
- [x] Floating Colors, Brushes, Layers, History and future registered panels share icon identity/fallback/pressed state with dock rail and flyouts.
- [x] Dragging an icon moves one tab; dragging host grip moves/redocks the group. Click, keyboard tab switching, close/reopen and Escape cancellation remain correct.
- [x] Native screenshots at compact width/HiDPI show consistent icons; teardown, docking persistence, layout migration, Atlas embedding pass.

T-091 and T-083 physical/manual gates remain separate. See [owner design](../DRAWING_UX_REVIEW_2026-11-20.md).

## Engineering completion — 2026-11-22

**Done (engineering scope only).** `DrawingDockIcons.for_panel()` now resolves the identical named SVG/fallback texture for the expanded dock, minimized rail, flyout and floating tabs. Floating host tabs are centered, icon-only 42×42 buttons with pressed-active state, stable IDs, name tooltips and accessibility labels. A focused tab retains keyboard focus across the host's render/reparent cycle; activating its already-active icon cannot collapse/hide the host. The original one-group grip/close, pointer drag threshold, model transactions and settings serialization are unchanged.

[Native and embedded-Atlas acceptance evidence](../evidence/T-225-2026-11-22-floating-icons.md) includes pointer and keyboard activation, Escape rollback, individual tab versus grip drag, four/five icons (including future-panel fallback), host hide/reopen, restart, 150%/200% scaling, shared view ownership, and existing docking regressions. Local virtual-X11 validation is **not physical hardware UX approval**; T-091 and T-083 remain In Progress, and hosted CI has not been rerun on this local commit.
