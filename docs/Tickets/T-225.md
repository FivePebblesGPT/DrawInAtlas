# Use dock-style panel icons instead of text in floating tabs

## Owner design (2026-11-20)

Floating panel tabs currently use labels where docked tabs use icons. Render the **same recognisable icon** and active/focus states in floating tabs, with names shown by tooltip/accessibility rather than persistent text.

## Scope and acceptance

- [ ] Preserve T-091's compact **one tabbed group per in-app floating host**, move grip, close action and edge/corner resizing; do not reintroduce group-name rows.
- [ ] Floating Colors, Brushes, Layers, History and future registered panels share icon identity/fallback/pressed state with dock rail and flyouts.
- [ ] Dragging an icon moves one tab; dragging host grip moves/redocks the group. Click, keyboard tab switching, close/reopen and Escape cancellation remain correct.
- [ ] Native screenshots at compact width/HiDPI show consistent icons; teardown, docking persistence, layout migration, Atlas embedding pass.

T-091 and T-083 physical/manual gates remain separate. See [owner design](../DRAWING_UX_REVIEW_2026-11-20.md).
