# Preflight detached native tile-history payloads before lazy sources

**Bounded T-148 child.** `_replay_native_tile_delta` validated each tile
key and buffer *during* lazy resolution, so an invalid later descriptor
could execute an earlier source callback. More importantly, a source callback
could modify a not-yet-snapshotted later `DrawingDelta` tile or its metadata;
replay might then publish bytes that the host did not originally request.

## Acceptance

- [x] Preserve the existing stride-sensitive 128-tile/256 MiB budget, but
  validate **all** keys, before/after correspondence, projected signed
  coordinates and full/empty straight RGBA8 buffers before any lazy callback.
- [x] Freeze the complete expected/replacement tile set, then detect reentrant
  changes to keys, buffers, layer ID, tile stride or native token before Rust
  history replay; preserve source identity/byte and revision checks.
- [x] Rejected replay does not publish any requested delta, advance revision,
  attach a new native store or consume an existing Rust token. Preserve
  valid detached Undo/Redo, hidden RGB, signed tiles, host history and Save/Open.
- [x] Reproduce against the unchanged document source, add a required-native
  CI assertion, and run standalone/Atlas replay regression suites.

## Completion — 2026-11-22

The final 40-check fixture fails **24/40** against the unchanged source and
passes **40/40** with the guard. Malformed later descriptors cause zero
source callbacks; mutation during callbacks rejects before native commit.
The existing reentrant/detached/Atlas native-history suites pass locally.
[Execution evidence](../evidence/T-237-2026-11-22-detached-history-preflight.md).

**Scope boundary:** The host still owns its external Undo/Redo timeline.
This is a descriptor-and-publication safety improvement, not completion of
T-148's universal Rust raster/history ownership. Callback-induced changes
to the provider's *own* source objects are not rolled back. T-148 remains
In Progress and T-149 Blocked; hosted CI and physical owner acceptance
remain unverified.
