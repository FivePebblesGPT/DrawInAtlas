# Cancel interrupted ColorPicker pointer previews on focus loss or missing mouse-up

## Defect — 2026-11-22

T-252 separates native picker **live preview** from **settled color** changes.
Its Escape cancellation did not extend to an OS/window focus loss or to a
mouse-up event dropped without focus loss. The previous ColorPicker pointer
session could remain pending, and the next click or late native signal could
turn a transient color into a recent entry and brush pigment.

## Engineering acceptance — Done

- [x] On window or application focus loss, an in-progress **pointer** color
  gesture restores its previous exact RGBA8 foreground/background; it does
  not append a recent entry, flush preferences or change document/host history.
- [x] If a motion event has no left-button mask while a picker/SpinBox pointer
  gesture is still held, treat the mouse-up as lost and cancel its preview.
- [x] Discard late native `color_changed` signals and stray releases from the
  interrupted gesture; permit the **next real left press** to start a clean
  gesture, with one recent previous color on intentional release.
- [x] Keyboard and typed edits without a held pointer **settle**, rather than
  disappear, on window focus loss; preserve hidden RGB at zero alpha.
- [x] Demonstrate a fail-first case on previous code and post-fix standalone
  native X11 and Atlas-hosted exact-raster/history checks; verify neighboring
  color and docking regressions.

**Implementation:** [`workspace.gd`](../../addons/drawing/workspace.gd)
adds a shared pointer-interruption rollback and a one-press recovery fence.
This is a Drawing-only canonical UI correction: Atlas embeds the unchanged
workspace. `make test-color-interruption` and
[on-demand CI](../../.github/workflows/godot-native-t261-color-interruption.yml)
build and import both required-native consumers before native X11 testing.

**Evidence:** [T-261 test report](../evidence/T-261-2026-11-22-color-interruption.md).

**Review boundary:** Synthetic focus-loss notification and missed-release
mouse motion under software X11 are not physical Windows/Linux window-manager
acceptance. **T-250 is still Manual Review; T-059 is not signed off.**
