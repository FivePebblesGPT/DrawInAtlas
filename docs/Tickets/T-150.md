# Remove Legacy Brush backend and compatibility paths

**Owner-approved alpha policy (2026-11-15):** Retire the Legacy GDScript hard Brush. **No compatibility layer, save migration, automatic fallback, duplicate backend or retained dead code is required.** Git history preserves the removed implementation. Native painting may become a mandatory app component; temporary alpha build breakage is acceptable during the refactor.

## Deliverable

- Remove the `Legacy` Brush selector and old GDScript swept coverage, `_stage_brush_tile`/per-pixel blending paths, legacy-only preview/history compatibility branches and now-obsolete backend tests/docs. Do **not** delete shared generic editing functionality needed for selection, Fill, clipboard, text or other non-Brush tools.
- Present one required Hokusai/libmypaint native engine with `hard_round.myb` and other presets; NativeHard removal is T-153, not a separate mode retained here. Route Brush/Eraser through native tiled transactions; a missing/incompatible native binary must produce an **explicit unsupported/build error**, never silently invoke legacy painting.
- Update standalone app staging/export, native build scripts and Linux test workflow to require/copy the extension as needed. Document Windows/Linux build support and outstanding T-105 portability work; do not mislabel an untested Windows release as passing. Retire tests that assert `native=false` fallback; replace with required-native, wrong-version, failure and correct-binary assertions.
- Update developer docs and fixtures to reflect the new architecture, including removal of migration instructions, old runtime backend flags and obsolete direct GDScript Brush references. Old benchmarks remain historical evidence with clearly labelled source revisions.

## Acceptance

- [ ] Repo-wide search finds no reachable Legacy Brush implementation or compatibility switch; no GDScript per-pixel Brush blending or staging remains on the active path.
- [ ] Built native-present standalone app and independent consumer pass real pointer/input/framebuffer, Save/Open, source/cancel, document-safety, Undo/Redo and alpha smoke suites on tested platform(s); report unsupported platforms explicitly.
- [ ] Build failure/native ABI mismatch is actionable and fail-closed. Document alpha breaking changes without migration code.

## Boundaries

Breaking alpha internals is permitted; never claim release/Windows portability without evidence. T-095 owner performance approval remains open even after Legacy deletion. T-151 will measure the new baseline.
