# Admit mixed raster sources during recorded subtree removal and history

## Scope
A local recorded removal with an attached Rust owner can contain both
native-authorized and older unowned materialized tiles, even in one layer.
Adopt the missing coordinates and park the complete subtree in one revision.
Repair previously mixed retained removal events during replay without replacing
existing canonical bytes or consuming unrelated native history.

## Acceptance
- [x] Admit unowned siblings and coordinates in a partially owned layer;
  preserve already-authorized bytes, blank tiles and generations.
- [x] Validate the whole source set, ownership flags, hierarchy, coordinates,
  memory budget, parked lifecycle and active/stale revision before mutation.
- [x] Restore older mixed history in an owner with a subset of parked IDs;
  preserve unrelated Undo/Redo and reject missing or divergent native sources.
- [x] Preserve unresolved pending descriptors without I/O; reject altered or
  unexpected pending sources before subsequent checked Redo.
- [x] Exact RGBA8 through repeated structural history and Save/Copy fences;
  pinned Godot/Rust tests, ordinary Make and fast desktop CI witness.
