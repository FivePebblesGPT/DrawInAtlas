# Restore Object Editor background and standalone asset drag/drop

## Owner finding — 2026-11-25
Asset Browser lists contents, but Object Editor lacks a background and objects cannot be dragged onto the canvas.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
Reproduce on actual standalone Drawing/Object Editor; restore the visible transparency/canvas background consistent with ordinary documents, not an opaque paint mutation. Support Asset Browser drag/drop into an eligible Drawing canvas with valid source identity, placement coordinates, visible preview and canonical reusable-object semantics. Reuse existing safe source authorization, cycle checks and link/copy rules; never invent implicit copy or bypass Atlas registry. Keep Atlas-specific acceptance under T-065/T-064/T-108.
