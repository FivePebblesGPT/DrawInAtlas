# Preserve pending Brush when bulk edits are excluded by selection

## Defect

The four bulk raster APIs (`fill_rect`, `apply_region`, `paint_polygon`,
`clear_rect`) validated their arguments but unconditionally materialized a
previously accepted tile-local deferred Brush **before** discovering that a
non-inverted selection excludes the whole requested region. The no-op changed
preview representation and epoch, needlessly rebuilding pixel maps. This is
especially undesirable with an unavailable lazy source and a pending gesture.

## Completed acceptance

- [x] For a non-inverted enabled selection whose conservative `bounds` do not
      intersect a valid bulk area, all four APIs return a successful no-op
      without lazy-source resolution, Brush/Hokusai materialization, epoch
      change, revision change or lost staged pixels.
- [x] Active-empty masks deny edits. Unrestricted or **inverted** selections
      are not mistaken for disjoint; inverted selection can still load a real
      source, retry after an unavailable lazy provider, commit and Undo/Redo.
- [x] Existing valid Brush commits byte-exactly after multiple excluded bulk
      commands; hidden source RGB survives and Undo/Redo remains atomic.
- [x] Fail-first real Rust-backed Godot beta4 fixture: 8 failures of 40.
      Corrected: 40/40 with nine neighboring native suites 480/480 green.
      Required T-068 fast desktop CI witness and 46-step inventory preserved.

[Fail-first, passing, and neighboring test logs](../evidence/T-299-2026-11-24-masked-bulk.md).

**Boundary:** This is a conservative-bounds fast path: a selection whose bounds
intersect the area but whose interior mask contains no eligible pixels still
uses existing per-pixel selection checks. It does not grant T-068 throughput,
T-148 native integration, hosted CI, physical hardware or T-250 owner UX
acceptance; those separate gates remain open.
