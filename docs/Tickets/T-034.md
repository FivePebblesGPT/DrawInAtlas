# Simplify raster brush and separate paint steps

## Source
[[ManualReview_2026-10-30#Code review|Code review]], items 7–9, especially the `paint()` example; target: `scripts/editing/raster_brush.gd`.

## Acceptance
- Separate coordinate conversion, brush coverage, mask checks, chunk access, pixel changes and result construction into understandable phases.
- Explain relevant fields and step boundaries without hiding logic behind excessive one-line helpers.
- Preserve exact paint/erase, alpha, chunk-edge, transform, undo and cancellation behavior during cleanup.
- Verify native interactions and have an unfamiliar code-only reader assess the result.

## Implementation — 2026-10-30

- Kept `AtlasRasterBrush.paint()` responsible for upfront layer/gesture guards,
  document-sweep bounds, inverse-transform corner mapping to raster pixel
  coordinates, candidate-work rejection, and final detached snapshot creation.
  Its public signature and all failure messages remain unchanged.
- Extracted `_stage_pixel_changes()` as one cohesive scan of a **half-open**
  global-pixel rectangle. It checks the original sparse chunk first (erasing
  cannot invent data), tests transformed pixel-center coverage, requires whole
  transformed pixel quads inside the optional scope, then reads and composites
  source RGBA **once per covered pixel**. The output dictionary stages only
  actual changes; errors discard it without allocating a snapshot.
- Preserved source-over quantization, negative chunk addressing, partial-chunk
  growth in the shared writer, candidate limits before edits, and the calling
  editor's preview/commit, cancellation, and command-history contracts. No
  persistence formats, edit commands, or public APIs changed.
- Extended permanent brush smoke coverage for rotated partial chunks, immutable
  originals, and transformed limit overflow. Extended the native framebuffer
  suite with actual pointer-painted raster chunk seams, undo/redo, and a
  cancelled in-progress gesture that leaves the committed image unchanged.
