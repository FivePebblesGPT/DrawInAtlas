# Preserve deferred Brush when a polygon covers no selected pixels

## Reproduced defect

T-300 proves bounded selection-mask overlap with a bulk edit's **rectangle**.
`paint_polygon()` could still find allowed selection pixels within its candidate
bounding box that lie **outside** the filled polygon. Such a no-op materialized
an accepted deferred Brush and could resolve an unavailable lazy source,
returning failure despite no eligible polygon pixels.

## Completed acceptance

- [x] Prove a non-inverted enabled selection has **no pixel-center intersection
      with the actual polygon**, not just its bounding rectangle, before any
      lazy-source read or Brush/Hokusai materialization. Cover plain
      rectangle, sparse mask, and boolean subtraction selections.
- [x] Limit the exact polygon/selection proof to 4,096 candidate pixels using
      the existing shared bound, and cap raster candidates multiplied by
      polygon vertices at 65,536 geometry checks. For large or uncertain
      regions, disabled selection, and inversion, preserve the normal staging
      path; **never**
      infer exclusion from an incomplete scan.
- [x] A genuinely selected pixel inside the polygon still resolves the lazy
      source, rejects an unavailable provider, succeeds on retry, and commits
      exact RGBA8 with transparent hidden RGB through Undo and Redo.
- [x] A queued native Brush remains deferred after excluded polygons; its
      epoch, canonical delta maps, lazy-source count and document revision
      remain unchanged until the actual accepted commit.
- [x] Fail-first real Godot 4.8 beta4/Rust: **3 failures / 39 checks** with
      the new preflight intentionally absent. Corrected: **39/39**, and eight
      neighboring tests pass **573/573**. Required T-068 CI retains the
      46-check inventory and strict success marker.

[Fail-first, passing and neighboring evidence](../evidence/T-301-2026-11-24-polygon-selection.md).
