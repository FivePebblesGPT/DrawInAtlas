# Restore required-native T-089 Layers CI and Atlas layer/history witness

## Problem

standalone Drawing, but never compiled or registered the mandatory Hokusai
Rust GDExtension. A clean runner does not carry the `.so`, so it can fail
at native startup before any layer interaction is exercised. The workflow
also omitted the existing structural model and embedded Atlas consumer.

Atlas features, a reopen of T-089's completed standalone feature scope,
