# Bootstrap native raster authority on first direct pixel-map edit

**Split from T-148.** T-232 acquired Rust ownership on the first tile-local
edit, but the ordinary global-pixel `_publish_edit` still emitted a Godot-only
per-pixel Undo payload until another native gesture or historical replay. This
also affected mixed public `DrawingEditSession` operations before any Brush.

## Acceptance

- [x] On a supported Rust tile stride (16–2048), preflight canonical signed
  coordinates, the 128-tile cap and stride-aware transfer budget before any
  lazy source callback, even before an attached native store exists.
- [x] Prepare detached projected tiles, create a provisional Rust store,
  import exact originals and adopt recorded or untracked edits atomically.
  Attach only after Rust accepts the transaction. Preserve hidden RGB, signed
  tiles, revision alignment, unrelated source and failure/retry semantics.
- [x] Emit a reversible native tile delta for local and Atlas-owned history,
  with no fabricated local step for untracked or externally held edits;
  validate Undo/Redo, Save/Open and a direct mixed EditSession fill.
- [x] Preserve out-of-ABI synthetic stride test coverage, and continue to
  replay **genuine pre-cutover pixel-map history** without weakening the native
  recovery guard. Update obsolete fixture assumptions to construct historical
  payloads explicitly rather than expecting new publications to emit them.
- [x] Record fail-first, headless Godot and native-X11, Rust, Atlas and
  neighboring regression results; wire a strict required-native CI marker;
  synchronize Index and parent scope.

## Completion — 2026-11-22

The ordinary direct pixel publisher now uses the same bounded provisional
native adoption as tile-local edits, including the `record_history=false`
path. A native owner is exposed only after exact-source validation and the
native transaction succeed. Old stored per-pixel Undo/Redo is still supported
as a deliberately constructed legacy fixture. Rust's 16–2048 tile-stride ABI
is unchanged; out-of-range synthetic strides retain their historical local
behavior. [Evidence](../evidence/T-233-2026-11-22-pixel-bootstrap.md).

**Scope boundary:** This completes *direct pixel-map edit publication*, not
all raster producers, native-only rendering/serialization, complete Atlas host
command lifetime, or owner hardware approval. The broad T-148 milestone remains
In Progress, T-149 stays Blocked and hosted CI is not yet verified on this
local commit.
