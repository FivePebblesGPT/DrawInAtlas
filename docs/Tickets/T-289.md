# Reject invalid flood-fill seeds and RGBA8 before lazy-source resolution

## Reproduced defect

`DrawingEditSession.flood_fill()` called `_fill_source_pixel(seed)` before
validating that its *view-relative* seed could ever pass `_stage()`'s strict
`(-2^30, 2^30)` pixel bounds, or that its color was canonical unsigned RGBA8.
For a referenced tile at `x=2^30`, a rejected gesture could invoke an arbitrary
lazy-source loader and materialize the chunk first. For an absent out-of-range
seed it returned `BLANK_SEED` rather than the correct `COORD_RANGE`. An invalid
color likewise fetched a valid source before rejecting it.

## Acceptance — verified

- [x] Reproduce the bug with Godot 4.8 beta4 and the real Rust GDExtension;
      fail-first witness reports **13 failures among 23 assertions**.
- [x] Reject out-of-range positive/negative X/Y seeds and invalid unsigned
      RGBA8 **before** any lazy provider, preview materialization or staged
      raster mutation. Use the *same inclusive cutoffs* as `_stage()`.
- [x] Preserve `FILL_LIMIT`/closed-session checks and the distinction between
      valid empty seeds (`BLANK_SEED`) and invalid geometry (`COORD_RANGE`).
- [x] Retry a valid fill through the **same session**, retaining exactly one
      lazy source fetch, source immutability until commit, native revision,
      transparent hidden RGB and exact Undo/Redo bytes.
- [x] Gate the real 23-assertion witness in the **existing** required T-068
      fast-desktop CI step (no new check ID), with strict exit/marker/log checks.
- [x] Run neighboring native fill frontier/cache/verified-stage/publication
      regressions; keep T-068's performance, portability, hardware and hosted
      CI gates open.

## Result (2026-11-23)

The corrected source passes **23/23** native-backed checks; the neighboring
T-068 suites pass **56/39/36/30** checks. The real required-CI command and
its strict log verifier pass. One Python CI-inventory contract passes. This is
an input-validation/side-effect fix; it does not move the flood-fill raster
algorithm into Rust, establish performance targets, or satisfy owner approval.
