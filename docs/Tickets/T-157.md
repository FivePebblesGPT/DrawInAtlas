# Reject reentrant lazy chunk materialization from stale sources

**Split from T-148:** `DrawingDocument._resolve_chunk()` called an external
lazy provider and installed its returned RGBA8 regardless of whether that
callback had changed the document revision, the pending blob identity, or
its layer. A same-key callback could also recursively invoke itself. The
caller-level revalidation used by native Brush/history is necessary but not
sufficient for **direct read/display** materialization: a stale provider
response must never become a resident Godot raster projection.

## Acceptance

- [x] Capture the document revision, display-source epoch, layer object,
  pending loader/ref/digest and known persistence reference before calling a
  lazy provider. After it returns, reject changed authority before decoding
  or installing bytes. Preserve a replaced pending reference on rejection.
- [x] Bound recursive same-key provider loads with an explicit retryable
  `SOURCE_BUSY` error; clean up the guard on return, including failure paths.
  Other keys may still resolve independently.
- [x] Retain checksum and canonical RGBA8 validation; successful retries
  must preserve alpha-zero hidden RGB and signed tile coordinates.
- [x] Demonstrate an actual native Brush/history witness, fail-first control
  against the old document implementation, lazy-publication/edit/fill
  regressions, Rust strict checks, Atlas/Object and graphical Hokusai tests.
  Do not claim hardware acceptance or close parent T-148.

## Completed 2026-11-16

`DrawingDocument._resolve_chunk` now rejects a provider's stale revision,
source epoch, layer/pending identity and changed persistence reference before
accepting the fetched bytes. One per-document busy-key set prevents recursive
same-key resolution without penalizing different keys. A failure leaves a
valid pending source available for correction/retry; it never replaces another
provider's reference or commits an unrelated Rust revision. The native store
and prior Rust history token remain attached across metadata-only callbacks.

The Godot regression passes **23/23**, while the same fixture against the
original document fails **7/23** assertions. Root lazy-cache fixtures and the
existing Rust/Godot/X11 matrix pass. See [execution evidence](../evidence/T-157-2026-11-16-lazy-guard.md).

**Not resolved by this child:** universal native authority for other raster
producers, Atlas host-owned detached-history lifetime, native-only
persistence, and T-095's physical-device/owner signoff. [T-148](T-148.md)
remains In Progress; [T-149](T-149.md) remains Blocked.
