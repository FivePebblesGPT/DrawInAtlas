# Make queued Brush backlog CI reproducible on fast native runtimes

## Failure and scope

The squashed-main hosted Godot 4.8 beta3 `ci_t085_live_stroke_preview`
failed four T-124 pending-release assertions, then raised a script error by
injecting a stale revision into a null predecessor session. T-124's existing
headless fixture created only **210** path samples, fewer than the
**256-segment** synchronous release drain bound. If the predecessor commits
inside `finish_gesture`, the intended deferred-gesture regression is never
exercised. On the current local beta4 build the unchanged test already passed;
this ticket prevents the same timing-dependent loophole from recurring.
