# Establish the continuous chunked-canvas model

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 13, and the user's subsequent clarification recorded in [[E-002]].

## Work
Define an implementable coordinate, chunk-ownership and detail-level contract for one drawing board spanning all world hexes, then reconcile the current implementation with it. A hex is an overlay/selection region, not its own canvas/document.

## Acceptance
- Paint can cross hex and chunk borders without discontinuity or duplicated ownership.
- Zooming into an unassigned hex is possible and does not create/switch to a per-hex document.
- “Restrict edits to current tile” is a selection mask over the same artwork.
- Coordinate/detail relationships, native measurement semantics and persistence impact are documented and demonstrated with adjacent-hex artwork.
