# Establish the continuous chunked-canvas model

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 13, and the user's subsequent clarification recorded in [[E-002]].

## Work
Define an implementable coordinate, chunk-ownership and detail-level contract for one drawing board spanning all world hexes, then reconcile the current implementation with it. A hex is an overlay/selection region, not its own canvas/document.

## Acceptance
- Paint can cross hex and chunk borders without discontinuity or duplicated ownership.
- Zooming into an unassigned hex is possible and does not create/switch to a per-hex document.
- “Restrict edits to current tile” is a selection mask over the same artwork.
- Coordinate/detail relationships, native measurement semantics and persistence impact are documented and demonstrated with adjacent-hex artwork.
- Detail levels are separately authored in shared coordinates; automatic LOD presentation keeps the editing target explicit.

## Implementation and verification — 2026-10-30

- Established the current ownership/coordinates/persistence contract in
  [[MAPS_AND_GRIDS#Current shared-board coordinate and ownership contract — T-002 (2026-10-30)|MAPS_AND_GRIDS]].
  The existing `AtlasStroke` document-space representation and signed
  `AtlasRasterChunk` 256-pixel ownership already support cross-hex/cross-chunk
  editing without creating one document per cell; those paths were preserved.
- Added per-layer **authored detail level** `D0`–`D32` with legacy `D0` default,
  validation, undoable layer metadata, native `.scn` persistence, and a
  compatible old/new raster clipboard wire format. Independent layers at
  different levels retain identical document coordinates.
- Added the Layers panel's separate **presented artwork detail** and
  **selected layer's authored detail** controls. Presentation filters visible
  layers only, does not change the selected target, and is blocked mid-gesture.
  Drawing/copy/paste/transform into a target hidden by another presented level
  is refused; explicit layer selection brings its authored level into view.
  New ink/raster/terrain layers, raster imports, and raster pastes follow the
  intentionally presented authoring group.
- Added `tests/continuous_canvas_smoke.gd` with **71 assertions** for adjacent
  hexes, negative/positive raster ownership and exact seam pixels, eraser
  behavior, explicit scoped editing/undo, grid-native unit stability, blank
  hex zoom, target retention, invalid detail metadata, legacy decode, and
  native-save round-tripping. The real-renderer
  `tests/continuous_canvas_visual.gd` witnesses one uninterrupted stroke
  across neighboring hexes at D0 and D1 (separate rendered groups, identical
  board coordinates), and saves two native screenshots under
  `user://validation/`. Both suites are included in CI. The real Layers panel
  is also exercised by `tests/layer_ui_smoke.gd` and visually inspected at
  1280×720 (all detail controls and import action visible).
