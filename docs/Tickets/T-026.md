# Define and implement the Contour tool

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 16.

## Decisions to resolve
Agree what “Contour” means here and how it differs from a brush stroke, polygon or selection boundary. Do not silently choose an interpretation.

Reference interactions and output are accepted by the user, then the agreed tool is implemented with consistent preview/cancel, masking, protections, undo and saving.
