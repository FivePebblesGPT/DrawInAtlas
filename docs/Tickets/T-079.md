# Collapsible vertical dock, grouped icon rail and flyouts

**Status:** Ready following T-078 (2026-11-03). [Agreed design and test scenarios](../DRAWING_DOCKING_SPEC.md); no implementation yet.

## Scope

- Convert the T-063 stacked Colors/Layers/History display to separately collapsible, keyboard-reachable dock **groups** using a chevron/header. Preserve each group's active tab when collapsing, scrolling or minimizing.
- The expanded right dock retains vertically stacked groups in a scroll container; compact/short windows must not clip inaccessible group controls.
- Minimize the **whole dock** into a narrow vertical rail with a recognizable icon **per attached panel**, accessible tooltips/labels and **visible separators between groups**. No one-letter substitutes or unconditional fixed set of icons.
- Clicking an icon opens a single **in-app group flyout** anchored to the rail and activates that particular member's tab; clicking a different icon of the **same group** switches its tab in the same flyout. Selecting another group's icon switches to that group's shared flyout; clicking the active icon toggles it closed. Canvas clicks alone do not auto-dismiss the flyout.
- Flyouts overlay rather than resizing the canvas, and restore to the expanded dock without losing group collapse, active tab, selection or scroll/focus context. Icon placement on expanded group right edges should remain consistent with the minimized rail.
- Treat active group membership as provided by T-078. Interactive drag/reordering is **T-080**, floating containers are **T-081**, cross-container drop is **T-082**; layout saving remains T-083.

## Acceptance

1. Native pointer/keyboard witnesses show independent chevrons, an intact 420px and desktop layout, vertical dock scrolling and stable canvas size.
2. A test fixture with Color/Swatches in one group demonstrates adjacent icons **without a separator**, one tabbed flyout, correct active tab on each icon, and a separator before History. Default singleton groups also work.
3. Tooltips and keyboard focus identify each icon; screen reader/accessibility labeling is checked where the platform allows it. Small-size hit targets and focus ring are usable.
4. Repeated minimize/restore, flyout switch/hide, and canvas click do not mutate model ownership or document content; T-063/T-062 UI regressions pass.

No owner gate on normal engineering delivery; later [T-083](T-083.md) records hands-on UX approval.
