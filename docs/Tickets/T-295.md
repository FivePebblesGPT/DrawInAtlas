# Reject out-of-projection Brush pixels before lazy source reads

## Defect

T-294 validates whole rectangle, byte-region and polygon edits. The swept
Brush `_stage()` path remained independent: a view-relative pixel could be
legal but map to an unpublishable signed global pixel beyond ±2⁵². It could
resolve a registered lazy source, record tile-local changes and cover a
pixel before the native publisher ultimately rejected the gesture. An
invalid mixed `_stage()` call also flattened a previously valid deferred Brush.

## Completed acceptance

- [x] Real Rust-backed Godot 4.8 beta4 fail-first witness reproduces 30/50
      failed assertions across ±X/±Y native projection boundaries and mixed edits.
- [x] Early canonical signed-global preflight in `_stage()` precedes all
      source reads, coverage writes and deferred Brush/clear materialization.
      Selection exclusion, RGBA8 and view-relative validation still apply.
- [x] Cache the projection guard at gesture start, enabling per-pixel
      checks only for native sessions whose frozen anchor lies near the boundary.
      Preserve the wider historic non-native document addressing rules.
- [x] Rejected single-pixel Brush edits have no lazy tile reads or touched
      preview; valid retries commit exact RGBA8 with hidden-RGB Undo/Redo.
- [x] Rejected mixed pixel writes retain an accepted tile-local deferred Brush;
      that Brush commits and Undo/Redo reproduces the original exact pixels.
- [x] Real native witness passes 50/50, neighboring geometry and bulk
      projection suites pass 493/493, Atlas X11 Brush passes 13/13.
- [x] Strict witness included in existing required T-068 fast-desktop CI
      step without changing the 46-step inventory, ticket/review gates.
