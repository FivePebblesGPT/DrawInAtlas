# Revalidate T-068 source-tile-cache smoke under native tile publication

## Problem

The required fast-desktop `tests/drawing_edit_tile_cache_smoke.gd` on
Godot 4.8 beta4 failed three of 31 checks. The source-tile cache itself did
not lose pixels: the fixture asserted that native commit exposes an obsolete
`DrawingDelta.after` per-pixel map, and attempted to publish a historical
`>2^53` signed brush anchor outside the current ±2^52 native projection.
The neighboring T-277 corrected only the Skia oracle, not this required test.

## Acceptance (one independently testable validation slice)

- [x] Reproduce all three historical failures with the current compiled
      native extension; do not modify production raster or native history.
- [x] Replace the obsolete delta-size oracle with independent public
      `DrawingDocument.read_pixel()` snapshots before and after commit;
      match exact touched-pixel counts, full straight-RGBA8 (including hidden
      RGB), one revision increment, source-cache release and full Undo/Redo
      across four signed source tiles.
- [x] Preserve the public gesture's wider legacy-compatible signed input
      range, but prove native publication **rejects** an out-of-projection
      coordinate with no source/revision mutation.
- [x] Use an exact, high nonzero signed anchor inside the native projection;
      prove its pixel readback and Undo/Redo are bit-exact.
- [x] Preserve lazy-source failure/retry, corrupted-source rejection,
      no-op, source-cache reuse, stale-revision and cancellation regressions.
- [x] Run the required native fixture plus neighboring signed bounds,
      history and campaign tests, T-068 Skia oracle and comparator; update
      ticket evidence/index without claiming other T-068 groups are green.

## Result — 2026-11-23

The real compiled `DrawingNativeTiles`/Godot 4.8 beta4 fixture passes
**38/38** checks, versus **three failures in the original 31-check** fixture.
Pixel snapshots span an independent 16×16 readback grid across negative and
positive source tiles. The original `>2^53` anchor is still accepted at the
public gesture construction seam but its out-of-projection native publication
cannot mutate the document. A legal `±1125899906842625` anchor commits and
roundtrips through Rust-backed Undo/Redo.
