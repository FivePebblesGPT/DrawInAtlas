# Preserve native history through text-to-raster Undo/Redo

**Split from active T-148:** A previously Hokusai-painted text-derived raster
has canonical RGBA8 and history tokens in Rust. Undoing its rasterization used
the *unreferenced* structural bridge, which correctly refused to advance a
Rust-owned ID. The Godot revision still advanced and the next stroke cleared
unrelated Rust history during rebase. This independently testable issue must
be resolved before universal T-148 native revision authority is accepted.

## Acceptance

- [x] Undo text rasterization atomically parks the previously native-owned
  layer, retaining canonical bytes, source authorization, and native Undo/Redo
  tokens; other raster layers remain editable without source reimport.
- [x] Redo restores only a byte-identical snapshot and rebinds consumer tile
  identities. Wrong/altered snapshots fail without tree, cursor, document
  revision, Rust revision, or park-state mutation; a corrected retry succeeds.
- [x] Never-native-owned text conversion still uses the checked unreferenced
  bridge without allocating parked tombstones. Previously stale native stores
  retain their explicitly bounded rebase/reauthorization path; an ahead store
  fails closed instead of losing its newer revision.
- [x] Exact same-Hokusai-byte Undo/Redo, repeated park/unpark, Save/Open and
  Atlas/Object/native history neighbors are tested under Godot 4.8 beta3.
  No T-095 software-only hardware acceptance is claimed.

## Completed 2026-11-16

`DrawingDocument._replay_text_tree` now validates the currently owned source
or the detached target raster against canonical Rust bytes before calling
`advance_parked_layers_revision` (for authorized IDs), with a checked
`advance_unreferenced_layers_revision` fallback only for genuinely unowned
IDs. The bridge advances the shared revision once, before deterministic tree
mutation, and rebinds restored Godot snapshot object identities. Rust's
existing bounded park and shared revision implementation was unchanged;
there is no second GDScript rasterization or migration fallback.

[Execution evidence and fail-first control](../evidence/T-154-2026-11-16-text-raster-parking.md).
