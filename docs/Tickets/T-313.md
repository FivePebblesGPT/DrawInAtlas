# Publish rasterized text sources atomically into native tile authority

## Scope
T-148 integration: text rasterization previously advanced native revision without authorizing the derived glyph tiles until first paint. Replace that gap with one checked structural source publication, supporting both first-use native bootstrap and replacement of a parked glyph source. Godot retains semantic text shaping and the text-tree history event. Do not add a second pixel-history event or alter the Drawing UI.

## Acceptance
- [x] At conversion, Rust owns every derived nonempty RGBA8 tile at the shared next revision, including signed tiles. A first conversion attaches a provisional store only on success; preserve unrelated resident sources and Undo tokens.
- [x] Park/unpark unpainted glyphs on structural Undo/Redo; replacement retires obsolete parked tiles and tokens in the same transaction. Semantic Save/Copy while parked excludes the inactive raster.
- [x] Validate the entire descriptor set and bounds before publication; reject active/stale, duplicate, malformed, over-budget or live-owned replacement requests with no partial source/history/revision mutation. Zero-tile conversion does not manufacture a tombstone.
- [x] Real native standalone, Rust, text-model and hosted Object Editor regressions, including exact composite and Save/Open; updated native ABI and ticket evidence.
