# Native-owned tiled raster editing and atomic undo transactions

**Goal:** Make Rust authoritative for canonical raster tile contents **during painting and publication**. Current 256px sparse `DrawingRasterTile._pixels` dictionaries, `DrawingEditSession._stage_brush_tile()/paint_path_hokusai()` pixel loops and `DrawingDocument._publish_tile_edit()` per-pixel history-map construction must no longer sit on the interactive Brush hot path.

## Deliverable

- Implement an opaque native raster-document/tile store with bounded signed tile IDs, configurable storage stride, canonical straight RGBA8 and correct hidden RGB. Choose sparse/dense/copy-on-write representation based on source preservation and representative memory/CPU benchmarks; **do not assume the display-tile stride matches storage**.
- Make Rust perform hard/preset rasterization, blending, erasing, mask/selection checks, tile-local staging, rollback journals and changed-region detection. Have Rust batch/retain native tile buffers; **no full-pixel coordinate/color triple stream and no GDScript blending or per-pixel staging** in Brush/Eraser.
- One atomic native edit transaction records base document/source revision, layer authority, source tile generations/identities, affected dirty rectangles and compact reversible tile-before/after state. Revalidate at the transaction boundary before publishing anything; a failed/stale source read, locked/hidden layer or stale revision must commit **zero** tiles and be retryable. Use one authoritative revision protocol shared with Godot, not competing native and GDScript revision counters.
- Expose bounded native tile handles/packed RGBA8 spans and transaction IDs for preview, dirty tracking, history, serialization and display integration. Avoid copying canonical raster pixels back into `Dictionary[String,int]` or constructing one string-key per touched pixel merely to produce Undo history.
- Retain the non-raster layer tree and UI metadata in GDScript; document byte-stream contracts and bulk import/export needed by T-149. This ticket can test its native store independently before full Godot consumer conversion.

## Acceptance

- [ ] Native deterministic tests and Godot bridge tests for 512²/96px edits, large signed coordinates, tile seams, multiple layers, locked/hidden selection, masks, erasure, transparent hidden RGB, alpha, stale source, atomic cancellation/failure and exact **same-backend** preview/committed/save/Undo/Redo results.
- [ ] Per-tile correctness and lifecycle traces, bounded memory/overflow handling, dirty-region parity and source-unchanged guarantees; no cross-mode pixel parity requirement.
- [ ] Profile per-gesture GDExtension transfer bytes/calls and demonstrate GDScript no longer loops over painted pixels for Brush/Eraser. Full UI/display ownership transfer is gated by T-149.

## 2026-11-15 native store progress (acceptance still open)

The direct native pipeline now has a real, compiled `DrawingNativeTiles` object and an independently tested `DrawingNativeBrush.apply_tile_batch`→`commit_tiles` path. See [ABI contract](../NATIVE_RASTER_TILES_ABI_V1.md) and [execution evidence](../evidence/T-148-2026-11-15-native-store.md).

- [x] Rust canonical straight-RGBA8 dense byte storage in sparse signed tile map (configurable 16–2048px stride), explicit source authorization, full-tile hidden RGB preservation, masks and layer authority.
- [x] Native hard/preset/eraser blending and clipped signed source sampling, detached batch preflight/rollback, dirty tile rectangles and generations; pending brush batch is **acknowledged or rewound atomically** with tile staging.
- [x] Paired atomic brush+tile commit, native reversible full-tile Undo/Redo (one history event per gesture), no-op without revision, bounded 256MiB memory and 64 history events, canonical native revision with source stamps.
- [x] Bounded tile-level source discovery and up-to-128-item canonical export pagination; exact native byte Save/Open snapshot roundtrip; real 512² / 96px Godot bridge, large ±2^42 coordinates, masking/selection, hidden RGB, injected error and retry, wrong-layer/locked failure, source unchanged, erasure, Hokusai Undo/Redo.
- [x] Existing Godot Canvas and older stroke-contract tests remain green, including software-X11 integration and Hokusai 96px witness. Independent native path no longer sends per-pixel output to Godot.
- [x] **Live Brush/Eraser cutover (per-gesture):** Production `DrawingCanvas` opts into `DrawingEditSession`'s `DrawingNativeTiles` transaction and Rust `apply_tile_batch`. It uses only tile identity discovery, imported RGBA8 source/mask bytes, Rust dirty descriptors and packed preview/commit buffers. It no longer consumes `preview_changes` or creates GDScript per-pixel history maps on this path. Historical direct-session fixtures retain the old ABI until T-150.
- [x] **Real consumer contract:** Real NativeHard/Hokusai full 512² / 96px graphical witnesses pass; native preview equals committed source, undo/redo recover exact bytes, mask hole and hidden RGB survive, Eraser and Cancel work; actual `.drawing` Save/Open returns byte-identical image. Live lazy-source failure leaves zero edits, recovered source retries, and changed selection fails closed. `native_ffi_stats` reports tile calls/bytes and zero pixel-stream calls on the exercised production path. See [live consumer evidence](../evidence/T-148-2026-11-15-live-cutover.md).
- [x] **Persistent native Brush/Eraser owner (2026-11-15 checkpoint):** `DrawingDocument` retains one `DrawingNativeTiles` instance, canonical imported bytes and native 64-entry history stack across consecutive gestures. Import deduplication requires both an authorized Rust source and unchanged Godot tile-object identity; modified source without a revision is rejected. Native commit supplies a token matched by document Undo/Redo. The consumer projection is fully preflighted, with a final reentrant revision/source check, before Rust commit; installation uses the already detached preflight result without calling lazy providers again. 18 Rust tests, strict Clippy, 44 headless persistent-store checks and 46 live graphical Canvas checks pass; see [new evidence](../evidence/T-148-2026-11-15-persistent-store.md).
- [x] **Fail-closed mixed-history rebase (checkpoint):** External non-brush revisions require a monotonic, quiescent `rebase_external_revision` that evicts stale native tiles and native history and reauthorizes document source; older document history entries survive through verified detached tile snapshots. Mixed Undo/Redo + fresh stroke source parity and source identity substitution are regression-tested.
- [x] **Bounded external raster transaction bridge (2026-11-15 next checkpoint):** With a current persistent Rust store, ordinary `_publish_edit` and `_publish_tile_edit` operations now prevalidate all source-object identities and send at most 128 whole-tile before/after spans to a **single** `adopt_external_edit` call. Rust checks expected revision, layer authority, resident-source byte equality, unique signed coordinates, exact RGBA8 spans, memory budget and changed bytes **before** any native pixel/history mutation; success creates one native tokenized history entry shared with Brush/Eraser, with exactly one document revision. The document's detached projection and history envelope are prepared before that native call; after Rust accepts, it does not invoke lazy providers. Mixed native Brush → external raster → Brush, multi-layer edits, native Undo/Redo, hidden RGB, signed tiles and portable `.drawing` source bytes pass. Rust tests reject second-tile errors without partial changes; the Godot contract rejects stale revisions and object substitution. See [mixed raster evidence](../evidence/T-148-2026-11-15-mixed-raster.md).
- [x] **Metadata-only revision bridge (2026-11-15 checkpoint):** Checked `DrawingNativeTiles.advance_metadata_revision(expected, discard_redo)` mirrors a one-step non-raster document revision without touching canonical RGBA8, imports or native Undo. Godot uses it for creation/rename/visibility/lock/reorder, density (before content), semantic objects and text commits; property/reorder/text-only history replay preserves native redo tokens, whereas a new untracked edit invalidates redo in both timelines. Rust rejects stale, overflow or active transactions without mutation; a rejected bridge detaches the document's stale store rather than keeping a competing revision. Byte-changing subtree operations and text rasterization still take the conservative rebase path. The [metadata checkpoint](../evidence/T-148-2026-11-15-metadata-revisions.md) has 20 Rust tests, 24 dedicated Godot checks, the 44-check persistent regression and graphical witnesses; **this is not universal authority**.
- [x] **Semantic subtree revision preservation (2026-11-15 checkpoint):** `remove_subtree` now classifies the *entire* subtree before mutation: removing a group/text/object-only tree advances the same checked Rust metadata revision as rename/reorder; a subtree containing **any raster node** still increments Godot's revision without pretending Rust source is unchanged, requiring the next native edit to rebase. `_replay_structure` applies the same distinction to create/remove Undo/Redo, preserving Rust raster tokens and Redo through semantic-tree history jumps. The 35-check real-native regression covers flat and nested groups/text/objects, structural Undo/Redo, source import counts, subsequent Brush, and conservative nested raster deletion. See [semantic subtree evidence](../evidence/T-148-2026-11-15-semantic-subtrees.md).
- [ ] **Canonical lifetime / universal revision authority:** Across native gestures Rust now owns the actual brush tiles and history, but some raster mutations bypass these two publisher paths and metadata/tree edits still mutate the serialized document revision and can invalidate native history. Migrate *all* raster source and history mutations to one persistent native authority, or establish an explicit atomic external-edit import/history protocol, without relying on a shadow snapshot timeline for prior raster events. Godot remains the display/save projection and layer metadata owner.
- [ ] **Final acceptance:** Validate Atlas/Object save consumers, native source/history behavior across mixed edit tools and reentrant source invalidation using one universal revision protocol. Do not unblock T-149 or claim final native-store ownership from this checkpoint.

**Status remains In Progress.** Brush/Eraser and eligible external raster publisher edits reuse a persistent per-document Rust store and native history, but raster-bearing subtree operations, detached replay and other raster producers can still trigger a history-clearing rebase; metadata-only operations, including semantic-only subtree removal and structural replay, no longer do so on a quiescent current store. The native store is not yet universally authoritative across the mixed document timeline. No manual-review gate is needed for this engineering work; T-095 hardware/owner acceptance is unrelated and remains open.
