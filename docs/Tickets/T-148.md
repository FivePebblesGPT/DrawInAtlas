# Native-owned tiled raster editing and atomic undo transactions

**Goal:** Make Rust authoritative for canonical raster tile contents **during painting and publication**. Current 256px sparse `DrawingRasterTile._pixels` dictionaries, `DrawingEditSession._stage_brush_tile()/paint_path_hokusai()` pixel loops and `DrawingDocument._publish_tile_edit()` per-pixel history-map construction must no longer sit on the interactive Brush hot path.

**T-153 dependency update (2026-11-16):** NativeHard is retired; the current Canvas Brush/Eraser path, persistent tile-store consumer and regression fixtures use Hokusai presets only. T-148 remains In Progress for **universal** authority across remaining raster producers and history paths; T-153 did not close that broader gate. See [T-153 evidence](../evidence/T-153-2026-11-16-hokusai-only.md).

## Deliverable

- Implement an opaque native raster-document/tile store with bounded signed tile IDs, configurable storage stride, canonical straight RGBA8 and correct hidden RGB. Choose sparse/dense/copy-on-write representation based on source preservation and representative memory/CPU benchmarks; **do not assume the display-tile stride matches storage**.
- Make Rust perform hard/preset rasterization, blending, erasing, mask/selection checks, tile-local staging, rollback journals and changed-region detection. Have Rust batch/retain native tile buffers; **no full-pixel coordinate/color triple stream and no GDScript blending or per-pixel staging** in Brush/Eraser.
- One atomic native edit transaction records base document/source revision, layer authority, source tile generations/identities, affected dirty rectangles and compact reversible tile-before/after state. Revalidate at the transaction boundary before publishing anything; a failed/stale source read, locked/hidden layer or stale revision must commit **zero** tiles and be retryable. Use one authoritative revision protocol shared with Godot, not competing native and GDScript revision counters.
- Expose bounded native tile handles/packed RGBA8 spans and transaction IDs for preview, dirty tracking, history, serialization and display integration. Avoid copying canonical raster pixels back into `Dictionary[String,int]` or constructing one string-key per touched pixel merely to produce Undo history.
- Retain the non-raster layer tree and UI metadata in GDScript; document byte-stream contracts and bulk import/export needed by T-149. This ticket can test its native store independently before full Godot consumer conversion.

## Acceptance

- [ ] Native deterministic tests and Godot bridge tests for 512²/96px edits, large signed coordinates, tile seams, multiple layers, locked/hidden selection, masks, erasure, transparent hidden RGB, alpha, stale source, atomic cancellation/failure and exact **same-backend** preview/committed/save/Undo/Redo results.
- [ ] Per-tile correctness and lifecycle traces, bounded memory/overflow handling, dirty-region parity and source-unchanged guarantees; no cross-mode pixel parity requirement.
- [ ] Profile per-gesture GDExtension transfer bytes/calls and demonstrate GDScript no longer loops over painted pixels for Brush/Eraser. Full UI/display ownership transfer is gated by T-149.

Import deduplication requires both an authorized Rust source and unchanged Godot tile-object identity; modified source without a revision is rejected. - [x] **Reentrant native-history replay preflight (2026-11-16 checkpoint):** Lazy history source providers can change a layer lock/revision or silently swap earlier source objects. `DrawingDocument._replay_native_tile_delta` now validates bounded/canonical signed tile keys and full RGBA8 before/after snapshots, then rechecks all source identities, bytes, layer editability, node identity and shared revision *after every provider returns* and before consuming any Rust token or publishing a detached fallback. The new real-native 25-check witness and 12-assertion negative control prove rejection without consuming history and successful retry; see [replay evidence](../evidence/T-148-2026-11-16-native-history-replay.md). Native history eviction/detachment remains a snapshot fallback and universal authority is still open.
- [x] **Atomic Rust history payload parity (2026-11-16 checkpoint):** `replay_history_token` now validates the full bounded signed-tile expected/replacement RGBA8 payload, layer, unique IDs, source bytes and directional top native history event *in the same FFI call before consuming its token*. Godot still performs its reentrant-lazy-source preflight, but a caller-mutated replacement image can no longer make Godot publish different RGBA8 from Rust. A new 20-check real native test rejects corrupt Undo/Redo images without advancing either revision or cursor, and confirms exact retry. A Rust unit test checks duplicate/missing tiles, large signed IDs, hidden RGB, canonical-source tampering and direction mismatches. **24 Rust tests**, strict Clippy, Atlas/Object/history neighbors and both 96px witnesses pass; see [payload parity evidence](../evidence/T-148-2026-11-16-native-history-payload.md). **Detached fallback is still not universally Rust-owned.**
- [x] **Checked in-sync detached-history replay (2026-11-16 checkpoint):** `DrawingNativeTiles.replay_detached_history` atomically verifies a bounded set of expected/replacement packed RGBA8 tiles when a document/Atlas history delta no longer has a usable live Rust token **but the persistent Rust store is still on the current document revision**. The FFI validates the complete signed tile list, byte lengths, canonical sources, editability, resident memory budget and active transaction before publishing anything; it then advances the one shared revision and clears unmatched Rust Undo/Redo tokens rather than inventing tokens missing from the host timeline. `DrawingDocument` installs exactly the preflighted projection only after native acceptance and records updated native source-object identities, so subsequent Brush gestures can reuse Rust's canonical tile data. A real 21-check Godot regression traverses two native strokes through live-token Undo, detached Undo/Redo and a fresh Brush, retaining transparent hidden RGB and identical native/document bytes, alongside a 25-test Rust suite. **History snapshots are still retained by GDScript, and absent/stale native stores still use the existing detached fallback**; this is not universal native history ownership. - [x] **Absent/stale-store detached history bootstrap (2026-11-16 checkpoint):** `DrawingDocument._replay_native_tile_delta` no longer publishes a Godot-only RGBA8 projection when its Rust store is missing or behind the document revision. After fully checking all lazy providers, source identities and tile bytes, the document configures a **provisional** `DrawingNativeTiles` at the current revision, bulk-imports only the bounded preflighted tile sources, and calls Rust's existing atomic `replay_detached_history`. Rust acceptance precedes the replacement of any live store pointer or Godot source/history publication. A rejected native import/replay leaves both document revision and the previously attached store unchanged. An **ahead-of-document** native revision fails closed without replacing it. A successful replacement retires stale source identities; unrelated layer tiles are explicitly reauthorized on their next native gesture. Live in-sync token replay is unchanged. A **34-check real-native regression** covers absent/stale owner recovery, signed tile bytes/hidden RGB, Undo/Redo, fresh paint, wrong source and native transaction rejection; a negative control against the previous document implementation fails 19 assertions. **25 Rust tests**, Atlas/Object replay and both graphical 96px witnesses pass; see [bootstrap evidence](../evidence/T-148-2026-11-16-detached-bootstrap.md). Mixed Undo/Redo + fresh stroke source parity and source identity substitution are regression-tested.
- [x] **Bounded external raster transaction bridge (2026-11-15 next checkpoint):** With a current persistent Rust store, ordinary `_publish_edit` and `_publish_tile_edit` operations now prevalidate all source-object identities and send at most 128 whole-tile before/after spans to a **single** `adopt_external_edit` call. Rust checks expected revision, layer authority, resident-source byte equality, unique signed coordinates, exact RGBA8 spans, memory budget and changed bytes **before** any native pixel/history mutation; success creates one native tokenized history entry shared with Brush/Eraser, with exactly one document revision. The document's detached projection and history envelope are prepared before that native call; after Rust accepts, it does not invoke lazy providers. Mixed native Brush → external raster → Brush, multi-layer edits, native Undo/Redo, hidden RGB, signed tiles and portable `.drawing` source bytes pass. - [x] **Metadata-only revision bridge (2026-11-15 checkpoint):** Checked `DrawingNativeTiles.advance_metadata_revision(expected, discard_redo)` mirrors a one-step non-raster document revision without touching canonical RGBA8, imports or native Undo. Godot uses it for creation/rename/visibility/lock/reorder, density (before content), semantic objects and text commits; property/reorder/text-only history replay preserves native redo tokens, whereas a new untracked edit invalidates redo in both timelines. Rust rejects stale, overflow or active transactions without mutation; a rejected bridge detaches the document's stale store rather than keeping a competing revision. At that checkpoint, byte-changing subtree operations and text rasterization still took the conservative rebase path; later checkpoints narrow these exceptions. - [x] **Semantic subtree revision preservation (2026-11-15 checkpoint):** `remove_subtree` now classifies the *entire* subtree before mutation: removing a group/text/object-only tree advances the same checked Rust metadata revision as rename/reorder; a subtree containing **any raster node** still increments Godot's revision without pretending Rust source is unchanged, requiring the next native edit to rebase. `_replay_structure` applies the same distinction to create/remove Undo/Redo, preserving Rust raster tokens and Redo through semantic-tree history jumps. The 35-check real-native regression covers flat and nested groups/text/objects, structural Undo/Redo, source import counts, subsequent Brush, and conservative nested raster deletion. See [semantic subtree evidence](../evidence/T-148-2026-11-15-semantic-subtrees.md).
- [x] **Never-authorized raster subtree revision bridge (2026-11-15 checkpoint):** Rust now exposes `advance_unreferenced_layers_revision(expected, layer_ids, discard_redo)` for structural removal/restore and raster creation replay. It advances the shared revision **only** if every affected raster ID is absent from resident and authorized tiles, active transactions, and *both* history stacks; even an imported all-transparent tile counts as owned. Missing/stale/active/oversized/duplicate IDs are rejected with no native state change, preserving the older checked rebase path for real native sources. Nested unimported raster children (including a deferred signed hidden-RGB source) now preserve unrelated Brush history through delete/Undo/Redo and standalone `.drawing` Save/Open. - [x] **Native-owned structural subtree park/restore (2026-11-15 checkpoint):** A recorded local `remove_subtree` with native-resident raster descendants now verifies every known imported RGBA8 tile against Rust and parks 1–128 raster layer IDs in **one** checked Rust revision. Parked layers deny direct paint, import and history replay while their canonical bytes/Undo tokens remain resident; other layers remain editable. Undo/Redo restores/parses the byte-identical detached subtree, rebinds source identities, and advances the same Rust revision without reimporting. - [x] **Detached subtree import revision bridge (2026-11-15 checkpoint):** `import_subtree` now prepares the entire detached hierarchy and its dirty-tile projection *before* mutating the document, rejects parked native ID reuse and advances exactly one shared revision using the checked `advance_metadata_revision` bridge for semantic-only imports or `advance_unreferenced_layers_revision` for raster descendants that Rust has never owned. This preserves unrelated Rust Brush history, native source authorizations, and byte-exact copied signed RGBA8/lazy-source content; a copied raster imports its source lazily only when later painted. Rust rejections (owned ID reuse, stale revision, >128 raster IDs, active store) retain the conservative checked-rebase path instead of claiming a partial native advance. - [x] **Unreferenced text-to-raster revision bridge (2026-11-15 checkpoint):** `rasterize_text` builds its detached glyph RGBA8 tiles before asking `advance_unreferenced_layers_revision` to advance the shared document/Rust revision for the converted text layer ID; `_replay_text_tree` applies the same checked guard on conversion Undo/Redo without discarding native Redo. This preserves previously owned Brush history on **other** layers while allowing the first Brush on the converted glyph layer to import its actual source tiles. The guard refuses IDs previously authorized, painted or parked in Rust, even if a glyph Brush was undone, so such conversions retain the conservative rebase path instead of claiming byte authority. The new [text conversion checkpoint](../evidence/T-148-2026-11-15-text-raster.md) passes **32 Godot checks**, including byte-identical semantic/raster preview, native history continuity, exact text-glyph Brush Undo/Redo, Save/Open, and a previously-owned negative control, alongside 22 Rust tests and graphical neighbors. - [x] **Unrecorded native-owned raster subtree retirement (2026-11-15 checkpoint):** Direct `remove_subtree()` and external-history removals without a local structural Undo now invoke `retire_layers_revision` with a bounded set of raster IDs, after the same source-object and full RGBA8 parity preflight as recorded parking. Rust atomically releases only those layers' canonical tiles, authorization, editability and Undo/Redo tokens; unrelated native history stays live, with a shared monotonic revision. A direct deletion creates **no** parked tombstone, so reimporting its ID starts from a fresh source. Local history entries targeting removed IDs are pruned, preserving Undo/Redo of unaffected raster gestures. Rust rejects active/stale, duplicate/empty, over-128 and parked IDs without partial mutation. On a changed source or rejected bridge, Godot takes the existing conservative rebase boundary. - [x] **Atlas global native-tile history command (2026-11-15 checkpoint):** `AtlasDrawingEdit` now freezes the *whole* `DrawingDelta` via `detached_copy()` when the Atlas-owned timeline commits a native Brush/Eraser gesture. Real Rust strokes interleaved with an Atlas grid edit now Undo/Redo byte-exactly using the live native token stack; caller mutation cannot modify the global history copy, stale source blocks replay without consuming the command, and an explicitly detached Rust store falls back to the saved whole-tile payload until the next native gesture reauthorizes. - [x] **Integrated native Object Editor source lifecycle (2026-11-15 historical checkpoint):** A real compiled NativeHard transaction on a private Object Editor draft now has a 38-check regression covering signed 64px source tiles, transparent hidden RGB, live Rust Undo/Redo, unpublished draft isolation across two placed instances, immutable Object Save and independent Save As with fresh layer identities, rebinding only the selected instance through Atlas history, both published source versions after disk-backed Object-registry reload, portable `.drawing` export/open and subsequent native painting, and rejected stale Save preserving the private native transaction and source bytes. - [ ] **Canonical lifetime / universal revision authority:** Across native gestures Rust now owns the actual brush tiles and history, but some raster mutations bypass these two publisher paths and metadata/tree edits still mutate the serialized document revision and can invalidate native history. Migrate *all* raster source and history mutations to one persistent native authority, or establish an explicit atomic external-edit import/history protocol, without relying on a shadow snapshot timeline for prior raster events. Godot remains the display/save projection and layer metadata owner.
- [ ] **Final acceptance:** Validate Atlas/Object save consumers, native source/history behavior across mixed edit tools and reentrant source invalidation using one universal revision protocol. Do not unblock T-149 or claim final native-store ownership from this checkpoint.

Detached replay now bootstraps a provisional native store when missing or out of sync, but the host-owned detached history timeline remains; the native store is not yet universally authoritative across the mixed document timeline.
