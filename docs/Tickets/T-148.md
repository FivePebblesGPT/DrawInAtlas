# Native-owned tiled raster editing and atomic undo transactions

**Goal:** Make Rust authoritative for canonical raster tile contents **during painting and publication**. Current 256px sparse `DrawingRasterTile._pixels` dictionaries, `DrawingEditSession._stage_brush_tile()/paint_path_hokusai()` pixel loops and `DrawingDocument._publish_tile_edit()` per-pixel history-map construction must no longer sit on the interactive Brush hot path.

## Deliverable

- Implement an opaque native raster-document/tile store with bounded signed tile IDs, configurable storage stride, canonical straight RGBA8 and correct hidden RGB. Choose sparse/dense/copy-on-write representation based on source preservation and representative memory/CPU benchmarks; **do not assume the display-tile stride matches storage**.
- Make Rust perform hard/preset rasterization, blending, erasing, mask/selection checks, tile-local staging, rollback journals and changed-region detection. Have Rust batch/retain native tile buffers; **no full-pixel coordinate/color triple stream and no GDScript blending or per-pixel staging** in Brush/Eraser.
- One atomic native edit transaction records base document/source revision, layer authority, source tile generations/identities, affected dirty rectangles and compact reversible tile-before/after state. Revalidate at the transaction boundary before publishing anything; a failed/stale source read, locked/hidden layer or stale revision must commit **zero** tiles and be retryable. Use one authoritative revision protocol shared with Godot, not competing native and GDScript revision counters.
- Expose bounded native tile handles/packed RGBA8 spans and transaction IDs for preview, dirty tracking, history, serialization and display integration. Avoid copying canonical raster pixels back into `Dictionary[String,int]` or constructing one string-key per touched pixel merely to produce Undo history.
- Retain the non-raster layer tree and UI metadata in GDScript; document byte-stream contracts and bulk import/export needed by T-149. This ticket can test its native store independently before full Godot consumer conversion.

## Acceptance

- [ ] Native deterministic tests and Godot bridge tests for 512²/96px edits, large signed coordinates, tile seams, multiple layers, locked/hidden selection, masks, erasure, transparent hidden RGB, alpha, stale source, atomic cancellation/failure and exact **same-backend** preview/committed/save/Undo/Redo results.
- [ ] Per-tile correctness and lifecycle traces, bounded memory/overflow handling, dirty-region parity and source-unchanged guarantees; no cross-mode pixel parity requirement.
- [ ] Profile per-gesture GDExtension transfer bytes/calls and demonstrate GDScript no longer loops over painted pixels for Brush/Eraser. Full UI/display ownership transfer is gated by T-149.

## 2026-11-15 native store progress (acceptance still open)

The direct native pipeline now has a real, compiled `DrawingNativeTiles` object and an independently tested `DrawingNativeBrush.apply_tile_batch`→`commit_tiles` path. See [ABI contract](../NATIVE_RASTER_TILES_ABI_V1.md) and [execution evidence](../evidence/T-148-2026-11-15-native-store.md).

- [x] Rust canonical straight-RGBA8 dense byte storage in sparse signed tile map (configurable 16–2048px stride), explicit source authorization, full-tile hidden RGB preservation, masks and layer authority.
- [x] Native hard/preset/eraser blending and clipped signed source sampling, detached batch preflight/rollback, dirty tile rectangles and generations; pending brush batch is **acknowledged or rewound atomically** with tile staging.
- [x] Paired atomic brush+tile commit, native reversible full-tile Undo/Redo (one history event per gesture), no-op without revision, bounded 256MiB memory and 64 history events, canonical native revision with source stamps.
- [x] Bounded tile-level source discovery and up-to-128-item canonical export pagination; exact native byte Save/Open snapshot roundtrip; real 512² / 96px Godot bridge, large ±2^42 coordinates, masking/selection, hidden RGB, injected error and retry, wrong-layer/locked failure, source unchanged, erasure, Hokusai Undo/Redo.
- [x] Existing Godot Canvas and older stroke-contract tests remain green, including software-X11 integration and Hokusai 96px witness. Independent native path no longer sends per-pixel output to Godot.
- [ ] **Critical live cutover:** `DrawingCanvas` / `DrawingEditSession.paint_path_native()` must stop consuming `preview_changes()` per-pixel packed deltas and `_stage_brush_tile()` / `_stage_native_pigment_delta()` GDScript loops during actual Brush/Eraser gestures. This also requires document revision/history authority transfer, rather than a second native counter beside `DrawingDocument.revision`; native store can currently be instantiated independently but is not yet the live document.
- [ ] **Final acceptance:** Run native preview versus real interactive Canvas publish, `.drawing` save/reload and undo semantics under one shared native document revision; full live process call/byte profile without GDScript per-pixel Brush/Eraser staging. T-149 display/persistence integration is dependency-blocked until this ticket's remaining gate is resolved; do not waive it merely because the native-only test passes.

**Status remains In Progress.** This is a substantial, validated native foundation, not yet completion of T-148's stated interactive Brush hot-path goal. No manual-review gate is needed for this engineering work; T-095 hardware/owner acceptance is unrelated and remains open.
