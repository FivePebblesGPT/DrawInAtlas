# Preserve Object Editor metadata when rename or Save As is rejected

**Done — independent bounded Object Editor transaction-safety fix (2026-11-15).**
T-125 guards publication while an unpublished Brush/Eraser stroke remains
pending, but the named **Save Source As** handler still assigned
`session.variant_name` *before* calling the guarded publisher. Rejection left
the user's proposed variant name in the private editor session even though no
asset was published. A failed or malformed publisher could similarly leave a
stale target. Object source Rename also accepted changed metadata while
Brush/queued input was unpublished, bypassing the analogous Object frame
context rule from T-130.

## Independent acceptance

- [x] Reject changed Object source names before mutating `session.name` during
      a released or queued Brush transaction. Allow an equivalent, trimmed
      name request without cancelling input.
- [x] Authorize Save Source As **before** staging the proposed variant title.
      Preserve the previous `variant_name` and publisher-call count when pending.
- [x] On failed or malformed publisher result, restore the previous variant
      target while preserving source identity, name, edit history and dirty
      draft. On success, keep normal named variant publication and clearing.
- [x] Reproduce on the exact T-130 Git tree: new Godot source/interaction oracle
      fails **5/21** assertions. Candidate passes **21/21**, including two
      chronological Brush transactions, canonical pixels and real publisher
      callbacks; strict headless log verification retains teardown diagnostics.
- [x] Run Object Editor, pending-stroke and standalone regressions, native X11
