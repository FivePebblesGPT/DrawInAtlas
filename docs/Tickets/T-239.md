# Reject retained out-of-order native host history replay

**Bounded T-148 child.** `DrawingDocument._replay_native_tile_delta` used a
side-effect-free *top-of-stack* token check, but if a non-top token was
requested, it silently used `replay_detached_history`. For edits on disjoint
tiles, source parity could still pass. This accepted out-of-order host Undo or
Redo and cleared the native history stacks, making the correct chronological
history unplayable. Evicted tokens legitimately need detached replay and must
not be conflated with still-retained tokens.

## Acceptance

- [x] Add a read-only native query for token presence across retained Undo and
  Redo stacks; keep token identity distinct from whether it is the **next**
  event in the requested direction. Preserve the native 64-event bound.
- [x] Reject a retained non-top token with `HISTORY_ORDER` before lazy source
  callbacks or native mutation, and recheck after callbacks. Keep source,
  revision and dirty-history unchanged on rejection.
- [x] Verify ordered host Undo/Redo restores exact bytes including transparent
  hidden RGB, while evicted and token-free detached snapshots continue using
  the checked Rust fallback.
- [x] Reproduce the regression against the prior document code, run native,
  standalone and Atlas history suites, and wire a strict required-native CI
  marker without modifying unrelated review gates.

## Completion — 2026-11-22

The final 36-check Godot witness fails **10/36** against the prior document
code and passes **36/36** with the order fence. Both retained older Undo and
retained later Redo reject before reading a lazy source; the original Rust
tokens remain usable in the right order. A genuinely evicted older token and a
token-free detached event still replay through bounded native snapshots.
Rust's 36 unit tests and the focused standalone/Atlas native-history suites
pass locally. [Execution evidence](../evidence/T-239-2026-11-22-native-history-order.md).

**Scope boundary:** The host remains responsible for the global command
sequence and snapshot identity. This fence prevents a native-retained token
from unexpectedly destroying the native history timeline; it does not make
all producers Rust-owned, nor approve T-148/T-149, hosted CI or physical UX.
