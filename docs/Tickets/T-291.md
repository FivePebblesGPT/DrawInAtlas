# Reject selection-excluded flood-fill seeds before lazy source reads

## Reproduced defect

`DrawingEditSession.flood_fill()` correctly rejects invalid coordinates and
RGBA8 before source resolution (T-289), but an otherwise valid seed outside
the selection was still passed to `_fill_source_pixel()`. A remote/missing lazy
source could be invoked and make a gesture fail, even though the fill frontier
would discard the seed without writing a pixel. If the source existed, the
no-op also flattened an accepted deferred Brush preview into global pixel
maps. This was unnecessary representation work with observable side effects.

## Acceptance — verified

- [x] Reproduce with a real Godot 4.8 beta4/Rust-backed session containing a
      deferred Brush and an unrelated lazy-source fill seed. On the prior
      implementation the final 33-check fixture fails 10 assertions.
- [x] Check `selection.allows(seed)` after coordinate/RGBA8/budget/closed checks
      and **before** source resolution or deferred preview materialization.
      Keep an excluded seed a successful no-op with the current change count.
- [x] Include out-of-bounds rectangular selection, active-empty selection,
      explicit pixel-mask hole and inverted selection. All four exclusions
      must avoid the unavailable lazy provider, leave the document revision
      and deferred Brush untouched, and preserve their original semantics.
- [x] Invalid RGBA8 and invalid view-relative seed must still be rejected
      even when a selection would exclude that seed.
- [x] A valid retry in the *same session* must resolve the lazy source once,
      publish exact transparent hidden-RGB fill and Brush bytes in one native
      transaction, and restore both on Undo/Redo.
- [x] Gate the 33-check native witness within the existing required T-068
      fast-desktop CI step, with exact marker and fail-closed log checker.
- [x] Run neighboring native fill/frontier, bulk preflight, cache, verified
      staging and history publication tests; keep T-148/T-068 integration and
      T-250 owner review gates unapproved.
