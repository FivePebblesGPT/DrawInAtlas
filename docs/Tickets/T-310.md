# Versioned binary .drawing document and measured storage optimization

## Owner finding — 2026-11-25
Binary .drawing file format and space usage optimizations requested.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
Design and implement a versioned binary standalone .drawing codec with compact typed metadata, sparse compressed raster payloads, exact RGBA8 including hidden RGB, bounded reads/decoding, stable IDs and editable text/object records. Use a reproducible baseline of real/synthetic representative documents for size and time measurements; optimize based on measured results. Preserve atomic Save/Save As and recovery. Keep Atlas sparse multi-file contract unless separately authorized; document compatibility policy for existing standalone files without inventing a migration requirement.
