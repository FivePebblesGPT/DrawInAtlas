# Remaining 96px/100-event critical-path latency after row-skip native scan

**Motivation:** T-191 preserves exact Hokusai source/history and bypasses unchanged raw tile rows, but paired full-gesture p95 remains above the **250ms milestone / 200ms stretch** in most trials. Native Hokusai raster still costs roughly 50ms and frame/drain scheduling adds full-gesture tail. See [T-191 evidence](../evidence/T-191-2026-11-17-native-row-scan.md).

## One bounded deliverable

- [x] Reprofile the current full 96px/512², 100-event critical path (raster, changed-pixel scan, staging, 6ms soft input drain, commit, first preview, frame postdraw, release→settled); keep true process exit and raw failure evidence.
- [x] Reproduce a fail-first issue and retain **one causally measured improvement** with repeated reversed-order same-native-binary A/B. Do not manipulate sample retention, preview visibility, backend, or the soft input-drain deadline to claim 250/200ms.
- [x] Assert signed/masked/hidden-RGB, brush/eraser, frozen/queued input, cancellation, native atomic commit/rollback, Save/Open, history, bounding, source hashes and graphical/Atlas parity.
- [x] Report cold/warm full-gesture p50/p95 against **250ms and 200ms**, native CPU phases, FPS/frame tails, release→commit/settled, input backlog, bytes, RSS and physical-owner limitations. Split any remaining target as an explicit bounded follow-up rather than a false acceptance claim.
- [x] Do not approve T-095 owner/hardware acceptance, T-151/T-152 post-consolidation gates, T-148/T-149 native transition, or T-105 Windows/export gates.

## Completion (2026-11-17)

[Native write-journal profiling and parity evidence](../evidence/T-192-2026-11-17-native-dirty-journal.md): production native raster batches reuse the existing rollback journal for exact changed tile candidates, avoiding a second per-dab dirty `HashSet`. A strict rapid gesture makes **2,134** tile requests, formerly **2,134 redundant dirty-set insertion attempts**, now **0**, while scanning 240 journal keys. A fail-first native test and real graphical parity proof (32 Rust tests, 81 graphical checks) preserve signed/masked/hidden-RGB, Brush/Eraser, frozen/queued inputs, atomic rollback, history, cancellation and Save/Open. Reversed-order same-native rapid/full-workspace A/B processes retain exact source hashes and valid exits. CPU, whole-gesture and frame/release timing remain **mixed**, so this is a bounded elimination of redundant hash work, **not acceptance of 250ms p95 / 200ms stretch or physical hardware FPS**. [T-193](T-193.md) remains Ready for the residual target. Manual-review and native-transition gates are unchanged.
