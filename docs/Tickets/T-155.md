# Atomically replace previously parked text-derived native raster sources

**Split from T-148:** T-154 preserves painted glyph RGBA8 and native history
when Undo converts a raster back into semantic text. Editing that text and
rasterizing it *again* branches history and produces a different source at the
same ID. The previous `advance_unreferenced_layers_revision` rightly rejected
an ID still parked in Rust, but Godot advanced its own revision anyway.
The next Brush then rebased the whole store and discarded unrelated Ink tokens.

## Acceptance

- [x] A new semantic-text conversion on an **in-sync parked raster ID**
  atomically releases only that ID's old Rust tiles, authorization, editability,
  parked reservation and obsolete history. The new glyph tiles are imported
  on demand, never confused with the old source, and unrelated native
  canonical pixels and Undo tokens remain intact.
- [x] Reject stale/ahead revision, active native edit, repeated/empty/unparked
  IDs and oversized native requests without partial source/tree publication.
  After cancelling an active transaction, the same conversion is retryable.
  A current Rust-owned *unparked* ID cannot masquerade as unreferenced.
- [x] Preserve the ordinary T-154 park/unpark Undo/Redo path for unchanged
  text-raster history; never authorize a newly created semantic text layer
  with an identity still reserved by a parked native raster.
- [x] Real Godot and Rust fail-first, exact RGBA8 Undo/Redo, Save/Open,
  native tile, Atlas/Object and graphical 96px Hokusai neighbors pass.
  T-095 physical-device/owner acceptance remains untouched.

## Completed 2026-11-16

Rust `DrawingNativeTiles.replace_parked_layers_revision(expected, ids)` is
one quiescent, 1–128-ID, checked `r → r+1` transition. It validates **all**
IDs are distinct, nonempty and parked and the revision is current before
selectively retiring their canonical tiles/authorization, removing related
Undo entries and clearing the branched Redo stack. It cannot be used as an
arbitrary unrecorded deletion or bypass the normal byte-identical T-154
restoration. Unaffected layer source and Undo remain in Rust.

`DrawingDocument.rasterize_text` builds the complete replacement snapshot
before the bridge, rejects a native store **ahead** of the host, and calls
replacement only for parked IDs; live in-sync nonparked IDs still require
Rust's unreferenced proof. The old native source-object identities are
released only after the atomic bridge succeeds. A previously behind store
retains the existing checked rebase/reauthorization path. `commit_text`
rejects creating a semantic layer under a parked native ID.
