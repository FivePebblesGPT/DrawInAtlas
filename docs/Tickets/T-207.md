# Restore T-127 pending Brush Undo/Redo regression for native completion

## Scope and acceptance

The historical required `t127_pending_history_smoke.gd` failed **7/40**
checks after Legacy Brush retirement: its setup used a 3px stationary dab
that did not reliably paint under native Hokusai, and two checks required a
native stroke to remain pending for exactly two process frames. Neither is
part of T-127's Undo/Redo source/history guard contract.

- [x] Replace the setup dab with a moving 24px Hokusai stroke that actually
      produces an Undo candidate. Keep the original source-pixel, history,
      save/reopen and exact RGBA8 Undo/Redo checks.
- [x] Accept both legal post-refusal outcomes after two frames: pending
      transaction, or **all** expected ordered transactions committed. Check
      **both revision and history cursor** in the latter case; do not accept
      partial publication as proof of completion.
- [x] Preserve guard checks *while input is pending*: direct Undo/Redo,
      Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z and History-panel buttons must leave
      source revision, history cursor and pending input untouched and show a
      visible refusal. Once committed, both normal history operations resume.
- [x] Preserve the existing `T127_HISTORY_PASSED checks=40 failures=0`
      required-CI marker and add a Python source contract that rejects the
      obsolete two-frame and stationary-dab expectations.
- [x] Reproduce the old failing fixture; repeat final-source headless and
      software-X11 runs with strict marker validation, validate neighbors,
      offline Rust/Python, type check and lint. Preserve all raw exits and
      logs without treating unrelated failures as passes.

## Evidence and limits

[Fail-first, validation commands, hashes and raw process logs](../evidence/T-207-2026-11-19-native-history-oracle.md).
Final native regression: **40/40 ×4 headless and ×2 X11**, all exit zero;
existing CI source contracts: **4/4**. T-128 and T-129 historical smokes
continue to fail **8/37** and **2/35** respectively and remain separate
work. No production brush, workspace, scheduling, native engine, file-format,
or release-CI policy was changed.

T-127's original bounded Undo/Redo implementation remains Done. This ticket
repairs only the outdated regression harness, **not** physical input latency,
200ms p95/FPS, hosted CI, Windows portability, architectural consolidation
or independent owner signoff. T-095, T-106, T-180 and the native-transition
gates remain open; no manual approval is inferred.
