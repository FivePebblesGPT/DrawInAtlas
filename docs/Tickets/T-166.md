# Reject unauthorized native raster projections at save publication

**Split from T-148.** A painted tile is authorized by the persistent Rust
store, but `DrawingRasterTile` remains a mutable Godot display/save projection.
A caller could mutate that tile *in place* without advancing either revision.
`export_manifest()` then hashed the unauthorized Godot bytes as canonical,
and `mark_published()` could acknowledge them as saved. A native-ahead store
was likewise ignored by both paths, allowing an inconsistent savepoint.

## Acceptance

- [x] Before a logical/sparse/standalone manifest is exposed, verify that an
  attached Rust store has precisely the document revision, and that all
  Rust-authorized, live projected tiles have the expected object identities
  **and exact RGBA8 bytes** (including alpha-zero hidden RGB). Reject stale
  projections with `STALE_SOURCE` without changing bytes, history or dirty
  state. Do not resolve lazy sources during this preflight.
- [x] Apply the same check before `mark_published()` can advance a saved
  revision or clear dirty tiles. A failed save acknowledgement cannot claim
  an externally mutated tile is durable.
- [x] Preserve native-absent historical save behavior, unreferenced lazy
  sources, valid save/acknowledgement, and exact native Undo/Redo. Avoid any
  new migration, ABI alias or fallback renderer.
- [x] Prove fail-first behavior against the previous save publisher; run a
  real Hokusai/ Rust-owned document witness and neighboring Rust, Godot,
  Atlas/Object and software-X11 suites with process exits and raw logs.
- [x] Update the required-native CI loop, parent T-148, native ABI and
  Kanban Index. Keep T-095 owner/manual and T-149 dependency gates intact.

## Evidence and boundary

See [T-166 execution evidence](../evidence/T-166-2026-11-16-native-save-fence.md)
and its raw logs. This is a **save/export acknowledgement** guard, not a
complete migration of the host-owned snapshot/history timeline. The raw
`snapshot_for_save()` dictionary API remains a separate T-148 integration
boundary; its consumers must not treat an unchecked snapshot as authoritative.
T-148 remains In Progress; T-149 stays Blocked; T-095 remains owner-gated.
