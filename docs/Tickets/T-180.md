# Rebuildable offline toolchain and Make-first native Drawing launch

**Problem:** The native Hokusai engine is required, yet standalone Drawing's
old README runs without compiling or loading its GDExtension. Existing offline
bundle8 is manually assembled and difficult to regenerate or update.

**Goal:** Two supported Linux x86-64 development workflows: system-installed
Godot/Rust/uv with overrideable paths, and a single, version-locked transferable
toolchain archive. GNU Make orders build, native extension registration, import,
smoke tests and launch. No Nix store, Docker or custom full build framework.

## Scope
- `Makefile`: `drawing`, `atlas`, `build`, `test`, `python-test`, `lint`,
  `format`, `doctor`, `bundle`, `bundle-verify`, `bundle-check`.
- `toolchain.lock.toml`: official Godot 4.8 beta3 and uv artifacts with
  SHA-256, Rust 1.99.1, Cargo.lock and pinned Ruff/ty versions.
- Online `make bundle`: fetch/verify release assets; rustup-install pinned
  toolchain and components; cargo-vendor locked crates; preload offline uv;
   create normalized `.tar.zst` plus per-file manifest and checksum sidecar.
   Use zstd level 19 and enforce a **500 MiB (524,288,000-byte)** compressed cap.
- Offline `make drawing TOOLCHAIN=bundle BUNDLE=...`: check archive, extract
  safely, compile without network, stage mandatory .so/manifest, preregister
  extension before Godot import, launch.
- `local.mk` overrides for system development. Native-absent staging must
  require an explicit negative-fixture flag; no runtime fallback.
- Restore a clean clone on a host where the old archive has been deleted.

## Acceptance
- [x] System mode builds and launches the real editor on owner's Linux host.
- [ ] Fresh online machine regenerates the bundle **without existing bundle8**.
- [x] Fresh sandbox with network disabled compiles offline, imports native
      classes and passes real native Brush/Eraser and Atlas tests.
- [x] Bundle verification rejects archive corruption, changed lockfile,
      unsafe archive members and wrong platform; generated output documents
      SHA-256 and source provenance.
- [ ] Repeating clean bundle creation establishes whether byte-for-byte
      reproducibility actually holds (record both hashes; do not assume).
- [x] Python Ruff/ty and Rust format/test checks pass under declared tools;
      local Python minor and wheel-cache portability explicitly recorded.
- [ ] README, Make targets, CI and packaging instructions agree; maintain
      T-095 owner hardware and T-105 Windows gates separately.

**Local validation checkpoint (2026-11-17):** System Godot 4.8 beta3, Rust
1.100.0, Python 3.14.10 and uv 0.13.8 pass the native build/tests. A new
Rust 1.99.1 bundle compiles native code in a cold bubblewrap network namespace
and passes both Godot projects plus repeated offline Ruff 0.17.5 / ty 0.0.104.
Wayland graphical native Canvas: 46 checks, zero failures; standalone Save/Open
and the 537-test Python suite also pass. Native binary/ABI failures and path
overrides are exercised. First archive rebuilds differed only in rustup's
component registry ordering; normalized clean repeats and hosted CI are pending.
