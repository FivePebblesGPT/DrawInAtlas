# Preserve the historical T-068 Skia brush parity oracle under native ownership

## Problem

The required fast-desktop T-068 group on the PR #22 squash (`bbae76c3`)
failed when it regenerated the historical Godot 4.8 beta2 Skia oracle.
The old `>2^53` world anchors are not publishable by the current Rust tile
store. After relocating the probe into a legal native projection, another
legacy assumption remained: the generator read `commit().delta.after` as if
native commits still exposed per-pixel history maps. That delta is now empty
on successful native commits, so it falsely reported zero changed pixels.

## Acceptance (bounded to this one fixture)

- [x] Reproduce failure on the real required-native Godot beta4 build.
- [x] Keep the original beta2 fixture and its >2^53 historical signed anchors
      byte-for-byte unchanged; do not update expected pixel digests.
- [x] Regenerate all 16 cases at a **fixed, valid large signed anchor** using
      the real `DrawingEditSession` and published document RGBA8.
- [x] Accept only this exact anchor relocation and beta4 engine metadata;
      require complete equality of every coverage index, changed-pixel
      index, alpha/color digest, transformed path and case ordering.
- [x] Add negative tests for unauthorized anchor changes, coverage/pixel
      changes, digest tampering and case reordering.
- [x] Verify neighboring pinned Skia/Blend2D and native RGBA8 contracts;
      separately report unrelated red T-068 smokes without waiving them.
- [x] Update the ticket index and evidence; do not assert hosted-CI green,
      full native architecture completion or owner review approval.

## Result — 2026-11-23

The live beta4 oracle regenerates **16/16 cases** with all historical raster
results identical. Its world anchor changes solely from the archived
`±9007199254740993` to native-publishable `±1125899906842625`. No production
source and no historical fixture bytes changed. The strict cross-engine
comparator still detects corrupted coverage, output, case ordering and
unexpected anchors.
