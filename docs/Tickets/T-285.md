# Normalize repeated Godot beta4 Linux native exports without losing existing bytes

## Defect and scope

Godot 4.8 beta4 may export a root-level `libdrawing_brush.so`. The beta4
upgrade already handled **the first** export by relocating the exact staged
library to its canonical native resource path, but a **second** export into the
same packaged directory leaves both paths present. The existing-library
branch called the final exact-tree inspector immediately, which rejects the
extra root-level library even if it matches the staged build. The previously
packaged native binary, ELF and PCK should remain safe and reusable.

## Acceptance

- [x] Reproduce failure on the current beta4 checkout with a canonical native
      distribution followed by an identical root-level engine copy.
- [x] Accept only the **exact two-native-file intermediate inventory** for this
      one repeat-export path, with canonical and engine copies byte-identical
      to the staged native SHA-256; do not weaken final artifact inspection.
- [x] Inspect the canonical ELF/PCK/native projection before removing the
      redundant copy, and re-inspect the final exact distribution.
- [x] Restore the engine copy on a late inspection error; never overwrite the
      canonical file or erase mismatched, symlinked or foreign content.
- [x] Test successful repeat, stage mismatch, damaged PCK, symlink, unexpected
      file, injected late failure, and preserve normal first-export cases.
- [x] Run adjacent PCK integrity, package, CI and portability tests; validate
      ticket-store dependencies and record the hosted/owner limits.

## Result — 2026-11-23

[Fail-first evidence and passing tests](../evidence/T-285-2026-11-23-reexport-normalization.md)
prove the repeated-export defect on the pre-fix beta4 code and its correction.
The 29-case Linux packaging suite and 45 adjacent PCK/CI/portability Python
contracts pass. All malformed/disallowed intermediate layouts remain rejected
without changes to previously exported bytes. No painting, raster, memory,
brush or native Rust implementation changed.

**Limits:** This is a reproducible structural packaging/rollback fix with
synthetic ELF/PCK fixtures; this environment has no official Godot Linux
export templates for a fresh packed-release boot. A new hosted beta4 export,
physical Windows/Linux review, T-180 release signoff and owner UX gates remain
open. T-201 and T-212 retain their earlier, narrower Done evidence.
