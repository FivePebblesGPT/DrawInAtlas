# Preserve unrelated native Redo during external subtree transfer replay

## Scope
Atlas Move/Copy replays must not branch native history independently of
its chronological command owner. Keep unrelated applied and undone raster
commands resident while replaying either a raster or semantic subtree, and
reject busy/stale semantic transfer boundaries before compensating mutations
become necessary. This is shared history infrastructure, not Atlas UX approval.

## Acceptance
- [x] Fail-first native two-document raster and semantic Move/Copy witnesses.
- [x] Preserve unrelated native tokens through import, retirement, and sibling
  order restoration; ordinary local mutations retain their default branch policy.
- [x] Reject busy/stale transfer boundaries, including pending script edits
  before native attachment, without mutating the documents or cursor.
- [x] Actual host branching releases abandoned tokens, retains earlier applied
