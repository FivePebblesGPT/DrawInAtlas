# Add raster Shapes tool and contextual options

## Owner finding — 2026-11-25
No shape tool in standalone Drawing.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
