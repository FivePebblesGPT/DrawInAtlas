# Replace deleted T-095 scripted-delta CI bridge with required-native checks

## Bounded scope and acceptance

After T-153 deleted `t147_scripted_session_bridge.gd`, three historical
T-095 tests (`hokusai_bulk_delta_smoke`, `t095_tile_shift_smoke`,
`t095_tile_commit_smoke`) still preloaded it. **All three failed to parse** on
the pinned Godot 4.8 beta3 runtime. Fast-desktop required CI invoked the first;
the optional native workflow invoked all three. Recreating a simulated
NativeHard/Hokusai producer is contrary to the required single Rust engine.

- [x] Reproduce and retain all three nonzero parse-failure process exits.
- [x] Require *actual* Hokusai native pigment rollback and unchanged retry
      (`t095_native_pigment_atomic.gd`, 57 checks), signed lazy raster bounds
      (T-158, 24 checks) and native replay/publication bounds (T-159, 39 checks)
      **in the existing fast-CI step**, preserving its required check ID.
- [x] In the optional native workflow, retain the already-run real pigment,
      signed and tile-contract tests and substitute the old native-independent
      tile-commit script with `t148_document_tile_publication.gd` (56 checks).
      Give that existing witness a strict `*_PASSED` marker while retaining
      its original `RESULT` line and all assertions.
- [x] Remove the three un-runnable `.gd` scripts and their `.uid` sidecars,
      without restoring the old scripted adapter or changing production code.
- [x] Preserve fail-closed **process exits**, strict Godot marker validation,
      exact successful assertion counts, CI fail-late collection and existing
      46 required step IDs. Add five source-contract tests, run them fail-first,
      and execute them inside the existing required CI step.
- [x] Run actual Godot, native Rust, Python, CI-contract, Ruff, ty, explicit
      typing and ticket validator checks, retaining raw logs and failures.

## Evidence and remaining gates

[Commands, fail-first processes, strict-marker negative control, source hashes,
exits and final checks](../evidence/T-211-2026-11-19-required-native-ci.md).
The removed scripts each failed before running assertions with a missing
preload; the real native test candidates passed under the same pinned
Godot/native installation. On final sources the pigment/24/39 checks pass
**twice each**; tile publication passes **56/56** with a strict success marker.
No Brush pixels, scheduler, Rust source or publication logic were modified.

This resolves **the three stale T-095 scripted-bridge CI invocations only**.
It does **not** claim green hosted fast CI or complete T-106/T-180, does not
supplant all other historical native/Legacy regressions, and does not approve
T-095's physical-device/manual-review or T-148/T-149/T-150 native transition.
