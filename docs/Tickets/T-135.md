# Enumerate committed sparse viewport tiles without scanning empty cells

**Done — 2026-11-15, bounded GDScript renderer throughput improvement.**
This is an independently testable T-086 follow-up. Its existing occupancy
index already prevented transparent texture allocation and helped the cold
scheduler, but `DrawingCanvas._draw()` still visited **every** display cell at
very wide zoom, even when only two source tiles were occupied. It formatted a
key and performed an occupancy lookup per empty tile on each redraw.

## Engineering acceptance

- [x] For a trustworthy indexed committed viewport, enumerate only occupied
  128px source-space display tiles within the visible window. Sort signed rows
  and columns to preserve previous draw-order and tile-scaling behavior.
- [x] Preserve the original conservative full traversal for any detached Brush
  or Move preview, unknown/malformed/oversized occupancy, or dense viewport.
  Never infer visibility from a partial source index; preserve text, source
  epoch, layer visibility, dirty history and exact raster semantics.
- [x] Do not change the 144-texture (9MiB) retained limit, cold-budget rules,
  alpha blending, pixel format, source document, Undo/Redo or save schema.
  Expose visible-versus-examined counts separately in Canvas metrics.
- [x] Demonstrate the original cost with the same native 120,701-cell sparse
  workload, verify signed RGBA8 framebuffer parity after navigation, edits,
  Undo/Redo and visibility changes, and repeat per-draw CPU timings.
- [x] Add a 16-check headless oracle, 23-check native X11 witness and strict
  log/Python contracts. Run neighboring viewport, renderer, preview-index,
  standalone, parser and ticket-validator regressions. Preserve 46 required
  CI check IDs; add native test only to existing on-demand T-086 workflow.
