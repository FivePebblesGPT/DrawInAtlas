# Bounded sparse atomic Brush publication and Undo

**Parent:** [T-095](T-095.md). **State:** Done for the narrowly tested publication path, **not** parent owner/device responsiveness.

## Delivered

- In `DrawingDocument._publish_tile_edit()` validate each tile patch and its source identity before constructing a detached candidate. Read originals directly from the canonical sparse integer-offset map; merge all nonzero patch entries using native `Dictionary.merge()` rather than one GDScript `set_rgba()` per changed pixel. Zero RGBA8 erasures remove sparse keys; alpha-zero **nonzero** hidden-RGB values remain intact. Publication remains atomic after preflight; empty/corrupt/stale/reentrant results are rejected before installing any prepared tile.
- Tile publication creates the two canonical string-keyed RGBA8 history maps locally, so `DrawingDelta.from_owned_maps()` now **transfers** that exclusively owned pair rather than immediately duplicating 262,144 keys twice. Public `DrawingDelta.new()` and mixed/global `_publish_edit()` keep their defensive copies. Existing local history, external history and replay paths still receive independent immutable-source tile snapshots and one reversible commit.
- Add a **197-assertion** headless source/history regression with signed non-power-of-two/256px strides, hidden RGB, erasure, source identity, two independent layers, late invalid tile, revision rejection, retry, signed masked Brush and Eraser, cancellation, canonical delta parity, and 512×512 four-tile SHA-256; report CPU, canonical-map entries and Godot static/peak memory. Extend the 100-event graphical benchmark with per-stroke Godot memory high-water marks. Wire the new oracle into the **on-demand** T-095 workflow with a strict T-094 log verifier and raw-log artifact; 46 required fast-CI checks remain unchanged.

## Evidence and limitations

[Commands, paired cold/warm software measurements, 197/198-check red/green oracle, raw-log hashes and native tests](../evidence/T-100-2026-11-12-sparse-publication.md).

In four matched Legacy 96px/512×512 Xvfb pointer strokes per variant, publication CPU p50/p95/max changed **1349/1465/1465ms → 1041/1234/1234ms**. Four valid 262,144-pixel strokes and Undo/Redo passed in **both** variants. Peak Godot static memory after the first stroke fell from ~226MB to ~183MB (monotonic engine high-water counter), reflecting fewer transient delta-map clones. The dense headless red control **fails** an opt-in 1850ms CPU ceiling on baseline (1959ms) and **passes** on candidate (1132ms); CI runs the correctness oracle **without** a synthetic speed ceiling.

Whole-gesture p50 **regressed** slightly in this noisy four-pair sample (5382ms → 5543ms) while commit CPU fell in every matched stroke; software raster staging/display still dominate. This ticket closes a narrow, reproducibly cheaper **publication** path, not end-to-end Brush latency. The Godot 6ms drain budget remains soft; candidate Legacy drains reached 38.5ms and one NativeHard graphical run reached 74.2ms. No physical input-to-photon timing or strict frame-safety pass is claimed.
