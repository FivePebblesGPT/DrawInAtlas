# Reserve history ownership during pending script edit sessions

**Bounded T-148 child.** T-243 protects active Rust tile transactions, but a
`DrawingEditSession` may stage pixels before `DrawingNativeTiles.begin_edit` or
without ever beginning a native stroke. The document revision and native
`has_active_edit()` both remain unchanged until publication. Consequently,
`set_external_history()` could silently change who owns the pending command.

## Acceptance

- [x] Register every new script edit session (including direct constructors)
  before pixel staging, without retaining abandoned RefCounted sessions.
- [x] Refuse local-to-Atlas and Atlas-to-local ownership changes while any
  live session is open, without changing revision, pixels, native store or
  local/global command history. Idempotent owner calls remain allowed.
- [x] Release the reservation after cancel, successful commit, no-change
  commit, stale failed commit, or destruction; overlapping sessions cannot
  release one another's reservations.
- [x] Verify the first script-only edit commits to the correct Rust-backed
  local/Atlas timeline with exact signed RGBA8, hidden RGB and Undo/Redo.
- [x] Reproduce fail-first failures, run neighboring regressions and pin
  standalone and real Atlas exact-count checks in required CI.

## Completion — 2026-11-22

With the previous implementation, **7/50** standalone checks and **9/18**
real Atlas loaded-document checks fail. The weakly registered session guard
passes **50/50** standalone and **18/18** Atlas checks after the fix, while
preserving the T-243 active-native guard. It does not keep an abandoned session
alive, and a second pending session still holds its own reservation after the
first cancels. See [execution evidence](../evidence/T-244-2026-11-22-pending-session-handoff.md).

**Scope:** Pending `DrawingEditSession` command ownership only; arbitrary
external commands, universal Rust raster authority, hosted CI and owner
hardware acceptance remain outside this child. T-148 remains In Progress;
T-149 remains Blocked.
