# Operation-specific native raster backend decision

**Parent:** [T-068](T-068.md). **State:** Done. This ticket has its own independently verifiable outcome; it does not inherit the parent’s remaining manual/device acceptance.

## Problem
T-068 has numerous kernel parity experiments but no measured production backend decision for real editor gestures.

## Bounded implementation / research
Compare optimized GDScript, optional native hard brush, Blend2D, Skia and Hokusai only for operations with comparable semantics; include the cost of input, preview, publication, storage and display, not just kernel CPU. Write a choose/defer/reject decision per operation.

## Acceptance and evidence requirements
Publish source-identical fixtures, comparable cold/warm p50/p95 and memory, license/dependency/maintainability analysis and a recommendation that does not make optional native code a mandatory standalone dependency. Label any operation without full parity as not comparable.

## Existing evidence / starting point
[T-068 historical experiments](History-T068.md) and [96px end-to-end evidence](../evidence/T-095-2026-11-11-96px-godot-profiler.md).

## Scope boundary
Change only this deliverable; keep canonical straight RGBA8, signed source coordinates, layer/mask semantics and atomic Undo/Redo where relevant. Preserve the existing T-094 fail-closed CI log policy. Record actual commands, exit codes, raw failure controls and source SHA. Do not treat Xvfb/Mesa engine callbacks as physical input-to-photon timing.

## T-104 decision (2026-11-12)

**Done for this independent research deliverable**, not a native integration,
full-editor speed acceptance or closure of T-068/T-095. Operation-specific
choose/defer/reject decisions, licenses and dependency burden, 10 identical
native hard-brush fixtures with warm-call p50/p95, 16 Skia cases, 512/1024/2048
fresh Linux process HWM and an actual 96px Godot pointer/framebuffer comparison
are recorded in [the evidence](../evidence/T-104-2026-11-12-operation-backends.md)
and the fail-closed [decision JSON](../benchmarks/T104_2026-11-12_backend_decision.json).
The T-068 native detached results are replayed and bound to exact file hashes,
not falsely relabeled as fresh full-editor or cold GPU tests. Missing native
three-stroke exit verification is explicitly excluded from warm editor p95.

**Decision:** choose portable optimized GDScript/Godot for hard Brush/Eraser,
preview, publication and Undo; retain optional NativeHard for exact hard strokes
and optional Hokusai for *non-equivalent* `.myb` presets; reject Blend2D/Skia
as drop-in hard-brush backends due to corpus nonparity, and defer new native
fill/path/text adoption until matching real-editor tests justify it. Do not
make a native binary mandatory. The new progressive-display-aware pointer
oracle and the T-104 report unit tests passed; the old pointer oracle failed
four premature-frame corner checks. T-105 portability, OS memory/VRAM, owner
hardware, hosted CI and T-095 manual acceptance **remain open**.
