# Restore T-130 pending source-context smoke across fast native completion

## Bounded regression and acceptance

After Hokusai became mandatory and native drain scheduling improved, the
historical T-130 smoke retained an assumption that two queued gestures must
still be unpublished **two Godot frames after the rejected Deselect**. The
actual T-130 contract is stronger and independent of that timing: Deselect
must not mutate the selected mask while native painting is pending, and
both Brush transactions must publish to source/history before selection
is cleared. The unchanged fixture reproducibly exited 1 with one failing
assertion (`Deselect cannot invalidate source on later frame`).

- [x] Preserve the immediate pending-stroke refusal, unchanged selected
      mask, visible warning, intact queued successor and no premature history.
- [x] After two frames, accept **only** (a) an unchanged source mask with
      paint still pending or (b) an unchanged mask with **both** native
      transactions already committed. Do not accept a lost mask or a
      prematurely discarded/partially published stroke.
- [x] Retain all 34 model assertions, strict `T130_CONTEXT_PASSED` CI marker,
      two history commits, source-pixel/Save/Open and the image/Object-frame
      refusal checks. Do not modify production Drawing code or CI steps.
- [x] Reproduce fail-first under real pinned Godot beta3, then verify four
      independent headless and two X11 runs, plus strict marker and Python
      source/CI tests. Preserve raw logs and neighboring failure results.
- [x] Keep parent T-106/T-180 hosted CI and owner/device approval gates open.
