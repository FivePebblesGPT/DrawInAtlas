# Reject reentrant in-place source changes during native Brush publication

**Bounded T-148 child.** T-234 froze native Brush output descriptors and
source *identities*, but `_publish_native_tile_edit` retained no final
source-byte comparison. A later lazy source callback could change an earlier
`DrawingRasterTile` in place, preserving its object identity and document
revision. The publisher then returned a valid-looking prepared edit whose
`before_tiles` no longer described the live source.

## Acceptance

- [x] Recheck the exact RGBA8 of every resolved source tile after all lazy
  callbacks and before returning a publishable native transaction. Preserve
  transparent hidden RGB and the absent-tile distinction.
- [x] Use previously captured `before_bytes`, without retaining another
  full-tile snapshot; reject `STALE_PIXEL` before Rust commits or installs
  projected Brush pixels.
- [x] Cover native-absent and already-attached Rust authority, negative
  unchanged-source control, two-tile publication and valid prepared install.
- [x] Reproduce against the previous document source, exercise neighboring
  standalone/Atlas/native-X11 suites, and add a strict required-native CI gate.

## Completion — 2026-11-22

The 18-check real-native regression fails **2/18** against the previous
`HEAD` source, then passes **18/18** with the guard. Source callbacks can still
change their *own* upstream objects; rejection promises no Brush publication,
not rollback of provider side effects. Neighboring native publication/Atlas
history suites and native-X11 Canvas pass.

[Execution evidence](../evidence/T-238-2026-11-22-brush-source-reentrancy.md).

**Scope boundary:** This protects the document-side Brush preflight, not
host-owned history command lifetime or universal native raster production.
T-148 remains In Progress, T-149 Blocked, and no owner/hosted-CI gate has
been self-approved.
