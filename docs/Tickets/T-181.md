# Keep visible native stroke tiles on screen during deferred refresh

Owner report: `Screencast_20261117_033517.webm` shows all but the cursor-near
128px display tiles disappearing during movement and returning when the held
cursor becomes stationary. Document data is not deleted.

## Scope and acceptance

- [x] Reproduce with real native classes and an actual graphical framebuffer.
- [x] Preserve warm display tiles on every moving/held/committed draw; defer
      genuinely cold texture population without changing the bounded cache.
- [x] Retain existing cold-population, over-budget and native history checks.
- [ ] Run the regression from the hosted required toolchain workflow.
- [ ] Record fail-first/after-fix outputs and synchronize the ticket index.

The 54%-zoom/96px-native regression initially lost 8–12 of 16 committed display
tiles during motion (19 checks, 11 failures). Excluding existing textures from
the cold-population defer branch restores every tile (19 checks, zero failures).
The compositor refreshes existing textures rather than drawing stale content.
Native cumulative dirty descriptors still cause broad refresh work; no physical
latency acceptance, native-authority completion or T-149 closure is implied.
