# Make standalone and registry-owned Drawing files binary-only

**Owner direction, 2026-11-27:** binary-only application persistence; no historical save migration.

Remove legacy JSON/base64 `.drawing` encoding/decoding and the `legacy` save option, including the default legacy in-memory codec and every live caller. Switch `object_library.gd` immutable registry revisions to the same binary writer as standalone and portable Object files. No old-save migration or alternate fallback.
