4.8 beta4 and the required Rust extension. Its successful lazy fill expects
`DrawingDelta.after` (the retired native per-pixel history map), while its
far-world seed/fill/Undo uses a `>2^53` signed anchor that cannot publish
through the current bounded native tile projection. Neither failure alone
establishes incorrect flood-fill pixel geometry.
