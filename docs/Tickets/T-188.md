# Reduce remaining 96px native stroke latency after direct preview

**Motivation:** T-187 removes most single-layer GDScript preview compositing,
but the unchanged 100-event, 96px/512² Hokusai
`total_to_postdraw_ms` still exceeds the **250ms milestone / 200ms stretch**:
two repeated same-binary software-X11 native direct A/B rounds have pooled
cold p50/p95 **343/383ms** and warm **344/358ms**, still over 250ms. Do not promote a rendering-CPU
microbenchmark or frame median as complete gesture latency.

## Scope (one independently measured next step)

- Reprofile the direct path's remaining **native stage (~113–137ms)**,
  input-drain/FFI overhead and release→commit/postdraw segments. Identify the
  next dominant *causal* hotspot from measured traces, not speculation.
- Implement **one bounded improvement** using a fail-first native/graphical
  regression and repeated same-binary baseline/counterfactual. Keep native
  Rust/Hokusai sole Brush/Eraser backend and stable 100-event source oracle.
- Preserve single/multi-layer source alpha and hidden RGB, masks, signed
  coordinates, floating/source edits, queued/frozen/cancel behavior,
  Save/Open, Undo/Redo, native preview visibility, cold/warm cache
  definitions and bounded memory. Don't drop frames/tiles to inflate FPS.
- Report unchanged 96px/512² `total_to_postdraw_ms` cold/warm **p50/p95**
  against **250ms and 200ms**, stage and release timings, postdraw frame
  distributions, >83.33ms fraction, first preview/input backlog, uploads,
  native exports, peak RSS, hashes and complete failed attempts.

## Acceptance

- [x] One repeatable matched native optimization with exact source and history
      parity, supported by real graphical/headless regressions.
- [x] 250ms milestone and 200ms stretch are measured against the full gesture
      with no hidden queue/release regression; explicitly carry forward any
      unmet threshold rather than declaring success.
- [x] Keep T-095 physical-owner and T-151/T-152 post-consolidation review
      separate; do not self-approve manual/hardware gates.

## Completion evidence (2026-11-17)

[Same-binary rapid and full-workspace A/B, 63-check native graphical parity,
28 Rust tests, raw logs and unsuccessful attempts](../evidence/T-188-2026-11-17-run-aware-native-staging.md).
T-185/T-187 instrumentation splits the remaining ~110–140ms rapid stage:
roughly 50ms MyPaint raster, ~20ms native changed-pixel scan, ~35–45ms
native tile application, ~10ms native tile discovery before the change.
The retained **one bounded optimization** groups contiguous Hokusai pixel
runs by native storage tile before applying them, and skips repeated tile
set insertions in native authorization. Counterfactual per-pixel grouping is
available only under `DRAWING_T188_PIXEL_GROUP_COUNTERFACTUAL=1` for same-binary
comparison. No Brush/Eraser backend, raster sample count or preview budget changes.

Two different native-binary snapshots were each tested **within** paired
same-binary X11 A/B rounds. In the final paired round, complete 100-event
cold p50/p95 moved **388/494→266/422ms**, warm **358/450→286/297ms**,
with cold stage p50 **143→101ms** and warm **125→104ms**; the earlier
identically paired round was mixed for complete cold latency despite lower
native-stage cost. All 16 valid gestures across these two rounds preserved
the same 262,144-pixel source digest and complete Undo/Redo/framebuffer checks.
Full-workspace comparisons show consistent native staging reduction but
**variable frame p95 and release→settled**; each run still includes a long
frame. No physical acceptance is claimed.

The **250/200ms full-gesture targets remain unmet**, explicitly carried to
[T-189](T-189.md). The T-095 hardware/owner decision, T-151/T-152
post-consolidation reviews and native/export gates remain independent and open.
The broad offline `make check` command was interrupted at Atlas import after
Python/lint had passed; standalone native, Atlas history, Rust and graphical
checks were rerun separately. The full evidence retains failed and incomplete
runs instead of treating the interrupted command as a pass.
