# Preflight all native history/adoption FFI payloads before RGBA8 copying

**Bounded T-148 child.** The 128-tile and stride-sensitive 256 MiB envelope
was checked before entering native history/adoption, but the Rust FFI loops
copied each tile's `PackedByteArray` to a `Vec<u8>` while still decoding later
descriptors. A malformed later tile could therefore allocate and account for
large earlier snapshots before rejecting the request.

## Acceptance

- [x] Validate the *whole* incoming tile array before any explicit full-buffer
  clone in recorded/untracked adoption, detached replay, and token replay.
  Enforce configured stride lengths (`0` or exactly `stride² × 4`), signed
  native bounds, unique tile coordinates, and field types; retain the existing
  count and aggregate transfer budget.
- [x] Reject a later malformed descriptor without counting earlier full-tile
  copies in `external_bytes_received`, and without advancing revision or
  consuming a native history token. Preserve the v1 empty-tile representation.
- [x] Verify valid signed direct adoption, exact transparent hidden RGB,
  recorded/untracked history, detached replay, and token Undo/Redo after a
  rejected batch, using a real native extension.
- [x] Reproduce failures on the previous native binary, run Rust and
  standalone/Atlas native regression suites, and pin the new test in required
  native CI. Do not close T-148 or any owner approval gate.

## Completion — 2026-11-22

The 32-check native GDExtension test fails **4/32** against the pre-fix
binary and passes **32/32** with the shared descriptor preflight. Rust's 36
unit tests, the native history/adoption and Atlas matrices, and the 46-check
native-X11 Canvas witness pass locally. The new CI step is source-validated;
GitHub-hosted CI on this local commit is **not** verified.
