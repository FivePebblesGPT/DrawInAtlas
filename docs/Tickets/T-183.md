# Audit and correct native brush preset identity and edge behavior

## Owner testing — 2026-11-17, after PR #20

| Selected preset | Owner-observed result |
| --- | --- |
| Hard Round | Soft rather than a hard brush |
| Soft | Very soft, airbrush-like; no spray patterns |
| Ink | Behaves like a hard brush |
| Airbrush | Soft |

These are owner observations, not a diagnosed cause or measured falloff profile.
T-182 delivered the selector wiring; it did not establish that each preset's
perceived shape matches its name. T-153's Hokusai-only backend decision remains.

## Deliverable

1. Trace selector metadata → Canvas preset ID → `.myb` bytes → native
   `begin_stroke` settings. Check hardness/falloff, opacity/flow, spacing,
   pressure response and width interpretation before choosing a fix.
2. Reproduce all four presets through the actual Drawing workspace with the
   same color, opacity, pointer path, pressure and 60/96px sizes. Compare native
   source alpha profiles with the rendered view at 100% and zoomed-out scales.
3. Make Hard Round visibly hard-edged under ordinary default mouse input;
   preserve meaningful, documented distinctions among Soft, Ink and Airbrush.
   Record the observed absence/presence of grain or spray texture explicitly;
   the owner's description alone is not a specification for a new particle engine.
4. Correct the actual mapping/settings/interpretation responsible. Keep stable
   preset IDs and native Brush/Eraser, masking, straight-RGBA8 and history
   contracts. Preserve old preset hashes/results as the pre-change control.

## Acceptance

- [ ] Reproduce the reported mismatch with recorded settings and screenshots /
      radial or edge alpha samples; identify its actual cause.
- [ ] Hard Round defaults match the hard-edge intent; the other presets have
      explicit descriptions and representative native-stroke examples.
- [ ] Add a regression at the real failing boundary, beyond merely checking
      preset names or file existence; verify Eraser, preview/commit and Undo/Redo.
- [ ] Re-run performance comparisons under the same preset hash, or establish
      a new baseline when corrected semantics change the workload.

This is native preset correctness, not restoration of NativeHard or Legacy
pixel geometry. Profile/optimization evidence lives in T-185/T-186.
