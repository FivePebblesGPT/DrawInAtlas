# Residual 200ms stretch and paced full-workspace frame/release tail

**Motivation:** T-195's bounded second post-release drain improves the same-
binary 96px/100-event software-X11 complete-gesture median, but its cold p95
is 252.6ms and warm p95 209.4ms over four observations each. First-preview
callback times worsen in the measured optimized runs, and the 54%/100% full
workspace still has inconsistent release/settled and frame tails. See
[T-195 evidence](../evidence/T-195-2026-11-17-release-catchup.md).

## Completed bounded change (2026-11-17)

Retained an **idle-deferred single drain only for deep post-release input
backlogs** (at least 32 still-pending source events after the normal mouse-up
6ms-soft-deadline drain). This preserves the T-195 live/ordinary/held
scheduling path and avoids blocking mouse-up for a second synchronous batch.
The extra callback is guarded by the original `DrawingEditSession` identity,
requested finish and checked document revision, so cancel/replacement/stale
callbacks are inert. `DRAWING_T196_DEFERRED_CATCHUP_COUNTERFACTUAL=1` disables
only the new drain with the same native binary and source checkout.

The 100-event fill retains 86 queued source events at release. The four
final, reversed-order same-binary modes have four cold/four warm observations
per mode (all zero exits): cold `total_to_postdraw_ms` p50 **204.2→182.8**,
p95 **215.2→227.4**; warm p50 **192.8→192.3**, p95 **217.3→205.4**.
First-preview p95 **43.4→49.2** cold and **39.4→50.7** warm; the 200ms p95
stretch target **is not achieved**. The sample is too small to infer a general
latency/FPS win. The synchronous release-drain candidate was rejected because
it prolonged the mouse-up callback from ~9ms to 19–36ms in observed cases.
A non-gated deferred candidate was narrowed after paced-frame regressions.

Four final full-workspace processes (32 scenarios, all valid zero exits) at
54%/100% include cold/warm/held Brush and Eraser. All had zero pending source
events at release and therefore correctly took no new deferred drain; their
frame/release/first-preview tails remain variable, with long intervals. All
source identities, native history, selection/hidden RGB, cancellation, Save/Open
and mask tests remain valid. The new graphical regression passes **99/99**,
including shallow-stroke gating and cancellation of an already-queued callback.
The older T-195 isolated cadence regression excludes T-196 when measuring the
T-195 counterfactual, so the previous release batching contract remains
independently testable. [Detailed evidence and raw process logs](../evidence/T-196-2026-11-17-deferred-backlog-drain.md).
