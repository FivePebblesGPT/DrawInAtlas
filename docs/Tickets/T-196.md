# Residual 200ms stretch and paced full-workspace frame/release tail

**Motivation:** T-195's bounded second post-release drain improves the same-
binary 96px/100-event software-X11 complete-gesture median, but its cold p95
is 252.6ms and warm p95 209.4ms over four observations each. First-preview
callback times worsen in the measured optimized runs, and the 54%/100% full
workspace still has inconsistent release/settled and frame tails. See
[T-195 evidence](../evidence/T-195-2026-11-17-release-catchup.md).

  cold/warm benchmark, plus held Brush/Eraser at both zooms with first-preview,
  queued release→commit/settled, frame input age, long frames, RSS and identity.
- [ ] Attribute a remaining **wall-clock** bottleneck (especially frame
  scheduling vs 6ms stage time) independently; use one reversible, fail-first
  change only with demonstrable complete-gesture or paced-frame benefit.
  Do not repeat blind transaction-cap adjustments or infer speed from counters.
- [ ] Preserve real Hokusai native source SHA, exact input/pressure/interpolation,
  preview, selection/hidden RGB, cancellation, native history, portable Save/Open
