# Interactive layer-group disclosure and structural indentation

## Owner finding — 2026-11-25
Layers panel uses text-based group markers and whitespace indentation instead of clickable expand/collapse buttons and actual button indentation.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
Replace text markers with actual row disclosure controls and structural layout indentation (not whitespace in labels). Keep eye/lock controls and layer selection distinct; preserve stable hierarchy, filtering/paging, reorder and keyboard access.
