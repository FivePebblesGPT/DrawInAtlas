# Drawing feature inventory and familiar standalone UX

**Status: WAITING FOR OWNER FEATURE LIST.** Product inspiration: reduced-feature Paint.NET/PhotoCraft, not every feature those editors provide.

## Plan
1. Convert owner's upcoming list into essential/next/out-of-scope capabilities, tool behavior, keyboard shortcuts and discoverability rules.
2. Cover common Drawing features independent of Atlas: snapping, generic layer groups, one-text-per-layer lifecycle, rasterization, selection, masks, image files, navigation, undo and open/save.
3. Prototype UX at small and large documents: thousands of text layers must remain navigable via grouping/virtualization, with selection state distinct from the map floor group.
4. Define usability acceptance flows in standalone Drawing, and Atlas integration flows for shared vs copied art, switching floor/detail, blank high-detail UI and global cross-map undo.
5. Open bounded implementation tickets once the owner agrees the feature matrix. The minimal T-053 vertical slice should not wait for full feature completeness.

## Acceptance
Owner approves a finite feature inventory and can perform representative pointer/keyboard workflows. No test-count-only UX signoff.
