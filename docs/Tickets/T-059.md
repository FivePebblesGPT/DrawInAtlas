# Drawing feature inventory and familiar standalone UX

**Status: WAITING FOR OWNER FEATURE LIST.** Product inspiration: reduced-feature Paint.NET/PhotoCraft, not every feature those editors provide.

## Plan
1. Convert owner's upcoming list into essential/next/out-of-scope capabilities, tool behavior, keyboard shortcuts and discoverability rules.
2. Cover common Drawing features independent of Atlas: snapping, generic layer groups, one-text-per-layer lifecycle, rasterization, selection, masks, image files, navigation, undo and open/save.
3. Prototype UX at small and large documents: thousands of text layers must remain navigable via grouping/virtualization, with selection state distinct from the map floor group.
4. Define usability acceptance flows in standalone Drawing, and Atlas integration flows for shared vs copied art, switching floor/detail, blank high-detail UI and global cross-map undo.
5. Open bounded implementation tickets once the owner agrees the feature matrix. The minimal T-053 vertical slice should not wait for full feature completeness.

## Acceptance
Owner approves a finite feature inventory and can perform representative pointer/keyboard workflows. No test-count-only UX signoff.

## User-supplied UI proposal — 2026-11-01
The uploaded **[[DRAW_MODULE_UI_SPEC]]** is now part of the repository as a **proposed design**, not a finished or signed-off implementation. It specifies fixed menus and scrollable tool controls on the *same* top row with `BarDivider`, plus document tabs, compact left tool rail, right Colors/Layers/History dock, and cursor/dimensions/zoom status. Commands and keyboard shortcuts replace a redundant quick-access toolbar. [[T-063]] owns implementation/overflow/input acceptance in three phases; this ticket still awaits the promised **feature list**, especially for the Object Editor.

## Round 7 — UX choices settled, feature list still pending
- Object Editor runs as a **dedicated document tab** using Drawing (T-062). Asset Browser is a normal dock peer (T-065) with the same tabbing, resizing and visibility behavior as Colors/Layers/History.
- Show project-side `Objects/` files as browsable objects, including unreferenced saved variants, missing/`NULL` proxies and child references. Asset deletion choice is explicit: remove references, keep NULL placeholders or cancel.
- The user accepted blank high-level artwork with visible grid/navigation overlays; app-wide selection-history setting OFF by default; camera focus on undo without changing zoom; configurable entrance double click. These are not pending generic suggestions.
- Proposed full Draw tool/feature list (effects/brush variants/import/export/etc.) remains **not yet provided**. Do not treat [[DRAW_MODULE_UI_SPEC]] as that list.
