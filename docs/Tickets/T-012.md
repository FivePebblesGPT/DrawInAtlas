# Define local battlemats as within-map canvas objects

## Source and confirmed constraints
[[ManualReview_2026-10-30#Usability testing|Usability testing]], items 10–12, and the user's clarification in [[E-006]]. A battlemat is a canvas object inside a local map. It is not a separate footprint-owned document, is unavailable at world/hex overview, and cannot contain another battlemat.

## Acceptance
- Define object identity/bounds, layer/drawing association and persistence responsibilities.
- Define how a local detail context is recognized within the shared-board/LOD model.
- Specify move/resize semantics with explicit options for moving the drawings or only the object bounds.
- Agree snapping, selection and coordinate invariants before implementation; identify migration/cleanup needs in the existing placement model.
