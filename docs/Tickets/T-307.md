# Text Options panel, live text preview and menu commands

## Owner finding — 2026-11-25
Need a Text Options panel with real-time text preview and common text options accessible from the menu bar.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
Add a dockable Text Options panel in the shared workspace, with live in-canvas text preview and common font, size, style, color and alignment controls; expose a useful subset through menu commands without redundant conflicting state. Keep one editable text element per layer, bundled-font portability and explicit rasterization.

## Acceptance
- [x] Live editing updates preview without per-keystroke committed layers/history; cancel restores initial state; commit is one coherent edit, Undo/Redo and Save/Open preserve editability.
- [x] Verify new and existing text, keyboard focus, font fallback and panel menu access, including Object Editor.
- [x] Inspect real text panel, menu, and preview at small/normal/HiDPI widths.
- [x] Record fail-first functional evidence where applicable, neighboring regression results, and actual visual inspection for UI changes in accordance with AGENTS.md. Update the ticket and Index; no owner signoff is inferred from engineering completion.

## Implementation and evidence — 2026-11-25

- Detached, revision/target-pinned semantic draft is substituted at its original layer-order position (or appended to the target parent for new text). Existing text is not modified until Apply; empty drafts cannot commit. Warm preview cache invalidates only intersecting old/new glyph footprints. Apply/Ctrl+Enter creates one coherent edit; Escape/Cancel restores pixels and history. Tab/tool/layer changes discard the draft; Save/Close/Export refuse pending text.
