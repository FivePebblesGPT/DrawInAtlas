# Group panels by icon proximity while keeping panel and group drags distinct

## Owner design (2026-11-20)

Dragging **one panel icon near another group's icons** groups the panels, **not** merely because two icons are close in the static layout. The user must complete a thresholded drag and valid merge-target drop. Panel icons always move **individual panels**; dragging T-223's triangle marker is the only group-drag gesture.

## Acceptance

- [x] An explicit hover preview distinguishes group merge, insert/reorder between groups, and detach/split; no accidental merge simply from passing nearby.
- [x] Existing `DrawingDockDrag` and `DrawingDockLayout` commit/rollback remain authoritative. Esc/invalid drops restore all panel IDs, group membership, active tabs, panel order and floating geometry exactly.
- [x] Moving an icon out produces a singleton if needed; floating hosts still contain exactly one group, without duplicate controls.
- [x] Scroll/autoscroll, narrow dock, physical pointer threshold, keyboard alternative, saved layout and native insertion-hint framebuffer checks pass.

Requires T-223 so group drag cannot be confused with individual icon drag. T-083 is still unapproved.

**Prerequisite update — 2026-11-22:** [T-223](T-223.md) is Done: the dock now distinguishes the whole-group triangle marker from individual panel icons, including thresholded drag and context-menu semantics. T-224 is **Ready** to add explicit proximity merge/insert previews and transactional individual-panel reorganization. This is **not** evidence that T-224's acceptance criteria have been implemented or reviewed.

## Delivered — 2026-11-22

Implemented on `sprint/2026-11-20-selection-dock-colors-brushes`; see [native, model and Atlas evidence](../evidence/T-224-2026-11-22-icon-proximity.md).

- A panel icon becomes a single-panel drag only after the existing 7px pointer threshold. Only hovering a visible target icon strip/rail or explicit group gap can commit an insert, merge, reorder or split; passing across an expanded panel body or floating body invalidates the candidate. Dragging the triangle marker remains a **whole-group** gesture.
- Blue insertion line/caption means same-group panel reorder, green target outline/line and contextual caption means **merge into a different group**, amber line/caption means singleton split or whole-group move. Canvas detach still uses the existing floating preview. The overlay is display-only; all commit, stale-baseline rejection and Esc/focus rollback remain in `DrawingDockDrag`/`DrawingDockLayout`.
- Horizontal tab-strip drag autoscroll complements the existing vertical dock/floating scroll. Same original `Control` views, floating one-group hosts, keyboard Ctrl+Alt alternatives and layout v1 persistence remain in effect.
