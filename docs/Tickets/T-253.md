## Engineering completion — 2026-11-22

**Done for the measured software fix, not hardware/owner UX signoff.** In a
512×512 selection with 71,901 occupied pixels (representative of the owner
screenshot), the untouched prior code freezes X11 input→frame for **p95
1,127ms** (7 trials); the fixed code reaches **p95 179ms**. A controlled
fail-first run fails the same 500ms assertion. Headless synchronous staging
plus commit dropped **1,112ms→87ms** for 71,900 pixels. Ctrl+D remains
non-content and fast. The cause was per-occupied-pixel global GDScript
staging and history projection; the replacement batches checked RGBA8
storage tiles with one atomic native Rust history transaction and retains
mixed-edit fallback.
