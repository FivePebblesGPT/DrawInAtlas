## Review candidate (2026-10-30) — awaiting acceptance of fill policy

Implemented the policy and preview implementation in [[BUCKET_WORKFLOW]]. The specific contiguous/global, premultiplied-alpha tolerance, replacement-vs-compositing and release-to-commit choices must be reviewed with the owner; **do not check off T-023 solely because the automated implementation passes**. Behavior is opt-in where possible: default is exact-match contiguous on the active raster layer, with 0% tolerance; terrain retains its existing exact-palette semantics. No native-save schema or existing paint content was modified.

- Raster: 4-connected contiguous or global among *stored* pixels of the active raster layer; normalized premultiplied RGBA seed tolerance 0–100%, alpha replacement, Shift temporarily inverses global mode, 262,144-pixel transaction limit.

- Pointer press creates a **visible detached preview**; release commits one command, Escape/tool/layer change/outside-board/focus loss cancels without mutation. Error messages explain unbounded/no-op/locked/hidden and limit failures. Old direct `fill_at(point)` remains available for code callers.

## Staged edit-mask safety follow-up — 2026-11-01 (acceptance pending)

A pending Bucket fill previously validated the raster source and document
identity on release but **not its selected-cell edit scope**. Selecting another
cell while a pointer preview was in progress could therefore commit pixels
computed under the previous cell's mask, after the old region was no longer
eligible. This matters even when the layer's pixel bytes do not change.

- The detached candidate now snapshots the *effective* edit-scope enabled
  state and the exact board-space polygon at preview creation. Release rejects
  an altered mask (changed selected cell, lock state, or grid geometry) before
  dispatching the history command; it clears the preview and reports the
  rejection. Cancellation also releases the mask snapshot.
- Unrestricted mode remains unaffected by cosmetic changes to the highlighted
  cell because no eligibility boundary has changed. A fresh preview with the
  current mask still commits normally. There is no stored schema change.
- The expanded headless Bucket suite tests changed selected cells, grid
  rotation, safe retry, and unchanged unrestricted scope. The native suite
  exercises a real pointer press, selection change and release on the canvas.

**Policy remains unapproved:** this defensive fix does not settle the
contiguous/global choice, premultiplied tolerance, replacement alpha, or
press/preview/release interaction. Keep T-023 unchecked until owner review.
