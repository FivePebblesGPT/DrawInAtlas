# Preflight destination-native retirement before Atlas transfer Undo

**Split from T-148.** `AtlasDrawingTransfer.revert()` restored a moved
subtree into its source before checking whether Rust would permit deleting
that subtree from the destination. A busy or native-ahead target could reject
retirement after source restore. Compensating source deletion then advanced
revision(s) even though Atlas rejected Undo; retry could fail because the
host revision ledger and both native stores had diverged.

## Acceptance

- [x] Before **either** source restoration or target retirement in Atlas
  Undo, ask the destination's read-only `preflight_unrecorded_subtree_removal`
  to validate current revision, editability, active Rust transactions and
  canonical RGBA8 ownership. Reject without changing document revisions,
  source/destination membership, Rust tokens or the Atlas cursor.
- [x] The same check applies to Copy Undo (target-only deletion); a held
  destination transaction must be retryable without losing the command.
  Preserve valid Move/Copy Undo/Redo identity, full RGBA8, and unrelated
  source and destination native history.
- [x] Run the identical real-native test against the old `revert()` as a
  fail-first control, then with the change. Cover both a busy target and an
  attached-native-ahead target.
- [x] Run Rust unit/fmt/strict Clippy/release, root and Drawing/Atlas/Object
  history and transfer regressions, and graphical 96px and Canvas witnesses.
  Do not claim hardware latency acceptance.
- [x] Add required-native CI coverage and update ABI, T-148 and Kanban;
  retain checksummed raw logs and validate the ticket store.

## Boundary

The preflight is synchronous and read-only, just before the source restore.
It closes the ordinary rejected-destination retirement case, **not**
general two-document distributed atomicity under arbitrary reentrant host
callbacks. T-148 remains In Progress; T-149 stays Blocked, and T-095 still
requires owner/hardware acceptance.

## Evidence and remaining boundary

[Execution evidence](../evidence/T-172-2026-11-16-atlas-undo-preflight.md)
records an actual 30/30 Godot 4.8 beta3 + Rust/Hokusai native test,
4/30 failures from the previous Undo implementation, 25/25 Rust unit tests,
and 24/24 final native/root/Atlas/Object/X11 build-and-test invocations.
The full-canvas 96px software-X11 run covered 262,144/262,144 pixels at
367.080 ms to post-draw; it does not satisfy physical T-095 acceptance.
This ticket does not close T-148's general host-owned detached history or
arbitrary reentrant two-document atomicity. T-149 remains Blocked.
