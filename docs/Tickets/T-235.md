# Preflight tile-local patch descriptors before lazy source reads

**Bounded T-148 child.** `_publish_tile_edit` formerly validated one patch
and its session source immediately before resolving that tile. Thus a later
noncanonical key, bad RGBA8 or missing source could invoke an earlier lazy
provider. A reentrant provider could also change a later patch value,
insert another session-source descriptor, or mutate a previously checked
resident tile in place while keeping the document revision unchanged.

## Acceptance

- [x] Validate every tile key, native signed projection, local index, RGBA8
  replacement and required session source before invoking any provider.
- [x] Freeze patch dictionaries and the session source map; reject reentrant
  additions/replacements and in-place changes to prior source bytes before
  attaching a Rust store, advancing revision or publishing any changed tile.
- [x] Retain valid extra verified-but-unchanged session source entries, sparse
  hidden RGB, signed whole-tile atomic Undo/Redo and untracked native edits.
- [x] Demonstrate an unchanged-code fail-first witness, an exact final marker,
  neighboring native/Atlas regression checks and required-native CI contract.

## Completion — 2026-11-22

The producer now validates and snapshots the complete request before lazy
resolution. It stages from frozen patches, retains per-source canonical SHA-256 tile fingerprints, and checks original inputs and source bytes again before native
adoption. The expanded 34-check test reproduces **17 failures** against the
prior implementation and passes **34/34** with the fix. Neighboring native
publication/history, independent sparse oracle and Atlas history pass.

[Reproduction and validation evidence](../evidence/T-235-2026-11-22-tile-patch-preflight.md).

**Scope boundary:** This guards only direct tile-local patch publication. It
does not migrate other raster producers to Rust-native rendering or replace
host-owned detached history commands. T-148 remains **In Progress**, T-149
remains **Blocked**, and physical owner/hosted CI gates remain unapproved.
