# Restore T-066 signed-coordinate save/failure fixture after native boundary hardening

## Problem and bounded scope

The required fast-desktop CI runs `tests/campaign_bundle_smoke.gd` under
T-066. That historical test authored `(2^53+1, -(2^53+1))` and required a
successful campaign-generation save. T-158/T-159 subsequently constrained
**persisted raster tile projection** to the safe inclusive `±2^52` pixel
budget; `DrawingDocument.export_manifest()` now correctly rejects that
fixture with `COORD_RANGE`. The test went red even though save rejection was
the intended native-safety contract. T-066's previously implemented storage
architecture and Done status are not reopened.

## Acceptance

- [x] Exercise genuine sparse, hidden-RGB Save/Open with a positive and negative
      signed pixel **within** the native-safe `±2^52` projection, using the
      shared `SignedTiles` bound instead of a newly hard-coded value.
- [x] Retain the historical out-of-range signed-int64 pixel edit as a
      **negative save** fixture, asserting `COORD_RANGE`, a still-dirty source
      and byte-identical published root pointer.
- [x] Independently reopen the previous generation and prove its exact
      hidden-RGB source pixel was not replaced by the rejected unsafe edit;
      retain compressed-chunk corruption and recovery assertions.
- [x] Preserve actual Godot fail-first, repaired and neighboring root/native
      process exits, strict markers, Python checks and source-diff review.
- [x] Do **not** relax the native coordinate boundary, change painting or
      persistence code, mark hosted CI green, or infer owner approval.

## Delivery and gates

The existing `tests/campaign_bundle_smoke.gd` now passes 91/91 assertions.
The unmodified version reproducibly exited 1 at a single save assertion,
`Raster source outside safe signed projection bounds`, with 74 checks.
The signed test still covers sparse source roundtrip and corrupted/missing
physical blobs; it no longer claims that an **out-of-range** raster tile can
be persisted. T-158/T-159 native safety remains unchanged. The root editor,
storage, native signed tile and replay tests all passed, as did 56 toolchain
Python tests. See [execution evidence](../evidence/T-202-2026-11-19-signed-save-fixture.md).

**Hosted GitHub fast-desktop CI was not run on this local commit.** T-180,

gates, and the unrelated T-085/T-087/native-export CI work is not closed.
