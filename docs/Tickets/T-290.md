# Preflight bulk raster edits before materializing deferred Brush or lazy sources

## Reproduced defect

`DrawingEditSession.fill_rect()` and `apply_region()` validated only candidate
counts and RGBA8 byte length before walking pixels. A two-pixel rectangle at
`x=2^30-1` therefore resolved an otherwise valid lazy tile and staged its
first pixel **before** the second pixel failed the view-relative `±2^30`
limit. This was a rejected gesture with an observable external source read.
Moreover, `fill_rect()`, `apply_region()` and `paint_polygon()` flattened a
previously accepted deferred Brush's tile-local preview into global pixel
maps **before** rejecting an invalid color or coordinate range.
