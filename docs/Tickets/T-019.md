# Selection tool and selection masks

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 16; shared tool contract: [[E-TOOLS]].

## Acceptance
- Selection affects the **active layer by default**; Paint.net is the primary interaction reference.
- Agree familiar selection, additive/subtractive selection, deselection and cancellation interactions using editor references.
- Any cross-layer selection option must be explicit rather than silently replacing the active-layer default.
- Treat “Restrict edits to current tile” as a selection mask over the continuous board.
- Selection is understandable across layers, chunk seams, hex borders and zoom/detail changes.
- Copy/cut/delete and transforms affect the intended editable content, preserve protections and integrate with undo/save.

## Implementation and verification — 2026-10-30

The Paint.NET-derived **whole-object active-layer selection contract** is
recorded in [[SELECTION_AND_EDIT_MASKS]]. Default selection replaces; Ctrl adds,
Alt subtracts, Ctrl+D/Enter deselect, Escape cancels an in-flight gesture.
Explicit authoring targets, stale-source guards, tile edit masks, undo and
native persistence are preserved. Hidden authored detail is not select-all
eligible. No unrequested cross-layer or partial-pixel selection mode was added.

Automated acceptance: `tests/selection_smoke.gd`,
`tests/selection_interactions_smoke.gd` and
`tests/selection_interactions_visual.gd`, plus the existing clipboard,
editing and persistence suites. Manual usability review remains outstanding;
this implementation is not proof of product acceptance.
