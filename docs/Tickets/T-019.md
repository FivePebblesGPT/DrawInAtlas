# Selection tool and selection masks

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 16; shared tool contract: [[E-TOOLS]].

## Acceptance
- Selection affects the **active layer by default**; Paint.net is the primary interaction reference.
- Agree familiar selection, additive/subtractive selection, deselection and cancellation interactions using editor references.
- Any cross-layer selection option must be explicit rather than silently replacing the active-layer default.
- Treat “Restrict edits to current tile” as a selection mask over the continuous board.
- Selection is understandable across layers, chunk seams, hex borders and zoom/detail changes.
- Copy/cut/delete and transforms affect the intended editable content, preserve protections and integrate with undo/save.
