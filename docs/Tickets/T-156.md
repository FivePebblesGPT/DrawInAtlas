# Replay historical pixel-map Undo/Redo through native tile authority

**Split from T-148:** Older local and Atlas-owned history events can still
contain `DrawingDelta.before/after` per-pixel dictionaries (`tile_stride == 0`).
If a later Hokusai Brush attaches `DrawingNativeTiles`, undoing that Brush
and then replaying an older pixel event previously called only GDScript
`_publish_edit(..., record_history=false)`. The document advanced while the
attached Rust revision did not; the next Brush forced a history-clearing
rebase, despite no independent source mutation.

## Acceptance

- [x] When Rust is already attached, replay a historical pixel-map event
  through one bounded, checked whole-tile native detached-history transaction.
  Do not append a new Rust Undo token outside the host's chronology. Preserve
  the original historical delta type and the same document/local or Atlas
  command cursor semantics.
- [x] Validate complete matching pixel keys, canonical signed coordinates,
  bounded tile count and pre-allocation byte budget, 32-bit RGBA values, exact
  original pixels and source revisions. Revalidate all tile identities/bytes
  after lazy callbacks through the existing native replay preflight. A rejected
  native-ahead, malformed, changed-source or over-limit request must publish
  **zero** document or Rust revisions and remain retryable.
- [x] Undo/Redo of an older pixel edit and newer Hokusai stroke preserve
  exact signed-tile RGBA8, alpha-zero hidden RGB, the same attached native
  store and subsequent Brush edits without a stale rebase. Test standalone
  local history **and externally owned Atlas-style command replay**, plus
  Save/Open and actual Godot/Rust integration neighbors.
- [x] Demonstrate a fail-first control against pre-change document code;
  Rust unit, rustfmt, strict Clippy, native integration and software-X11
  witnesses pass. Keep T-095's owner/device gate unchanged.

## Completed 2026-11-16

`DrawingDocument._replay_pixel_delta_native` converts an old pixel-map history
snapshot to whole RGBA8 tiles only after a native store is attached, bounding
its prepared buffers to 128 tiles and a conservative 256MiB/three-span budget.
Missing tiles are explicit zero sources; untouched pixels and hidden RGB
remain in the detached byte images. It validates the old per-pixel source,
caller-owned history snapshot and canonical 64-bit keys before calling the
existing `_replay_native_tile_delta`, which repeats source resolution and
full identity/byte/revision validation before Rust commits. Detached Rust
replay intentionally retires obsolete native tokens, **not** the host's
chronological delta; later native Redo replays its exact tile envelope.

This is a **cold history bridge**, not another Brush algorithm or a per-pixel
interactive staging path. Historical direct-session replay without an attached
store still uses the existing GDScript path; remaining raster producers and
universal native-source lifetime are part of **T-148 In Progress**.
