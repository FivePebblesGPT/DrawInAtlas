# Rebuild native Brush before the T-085 on-demand held-preview witness

## Defect and scope

The T-085 on-demand `godot-native-t085-stroke.yml` workflow staged Drawing and
imported it **without compiling its mandatory Rust GDExtension**. Clean Git
checkouts do not contain the generated `.so`, so the workflow could fail before
its real X11 test. Its `grep -q T085_NATIVE_PASSED` also accepted an incomplete
run with a manually printed success marker and no checked 840-point replays.

This is a **bounded CI and verification repair**. No production Brush, native
raster, preview, timing, standalone/Atlas document, or palette code changes.

## Engineering acceptance — Done

- [x] Pin Rust 1.99.1 and Godot 4.8 beta 3; `make build TOOLCHAIN=system`
      builds the required extension and stages/imports **both Drawing and
      Atlas** before any native stroke scripts run.
- [x] Exercise both the 81-check headless T-085 model and the 144-check real
      X11 held-preview witness; retain both diagnostic logs as CI artifacts.
- [x] A dedicated strict verifier requires the 144-check zero-failure summary,
      **31 short samples at each of 100%/50%/25% zoom**, **three 840-point
      native replays at each zoom**, three matching summary records and a
      timing record. Fail closed on incomplete/duplicated reports, script
      crashes and unknown renderer errors. Only specifically recognized
      post-success RID/texture leak diagnostics are tolerated and reported.
- [x] Add a `make test-live-stroke` clean-native reproducibility target with
      model and framebuffer checks; add a Python contract proving that the
      original workflow fails and the corrected gate is wired to the verifier.
- [x] Run local offline native build/import, X11 test, queued-history,
      Brushes, Atlas Brushes, preview retention, typing and ticket validation.

**Evidence:** [T-262 local fail-first, native and CI coverage](../evidence/T-262-2026-11-22-live-stroke-ci.md).
