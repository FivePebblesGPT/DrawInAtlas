# Preflight stride-aware direct native raster transfers

**Split from T-148.** The ordinary non-Brush `_publish_edit` and
`_publish_tile_edit` paths enforced only the 128-tile cap, and only inside
`_install_prepared_edit` after resolving pending tile sources. At 2048px,
six full-tile source/before/after spans need up to 288 MiB, exceeding the
native store's conservative 256 MiB transfer budget. Rust's
`adopt_external_edit` and `adopt_untracked_edit` entries converted input
`PackedByteArray` buffers into `Vec<u8>` before a count/stride cap.

## Acceptance

- [x] Count distinct signed tile IDs for direct pixel maps, and patch tile
  entries for tile-local producers, before lazy reads, full RGBA8 copies or
  publication. Use the same three-span/256 MiB ceiling as T-229 and retain
  the 128-tile cap on **native-attached** documents; keep historical
  native-absent direct behavior unchanged until T-150.
- [x] Independently reject oversized recorded and untracked external-edit
  descriptors in Rust *before* allocating input vectors or charging input
  bytes. Reject with no native/source revision or history mutation.
- [x] Prove pre-fix failures, early refusal for six 2048px or 129 64px
  tiles without touching a pending source, and positive signed two-tile
  canonical editing, hidden RGB, Undo/Redo and Save/Open.
- [x] Verify native tests, neighboring standalone and Atlas source/history
  suites, an actual native-X11 Canvas gesture, and the required-native CI
  marker. Document scope boundaries without closing T-148.

## Completion — 2026-11-22

The direct pixel and tile-local edit entry points now reject an oversized
transaction before invoking any pending/lazy source. The shared native
installation step repeats the budget check as defense in depth. Both Rust
external-adoption entry points verify the same stride-sensitive ceiling
before materializing Godot byte arrays into Rust-owned vectors.

[Fail-first reproduction, local validation and remaining gates](../evidence/T-231-2026-11-22-direct-budget.md).

**Scope boundary:** This is an allocation-safety and revision-atomicity
check, not a full resident-memory or process-RSS guarantee. It does not
bootstrap Rust ownership for new non-Brush edits in native-absent documents,
migrate Atlas's host-owned timeline, or complete T-148. T-149 remains
Blocked, and owner/hardware and hosted-CI gates remain open.
