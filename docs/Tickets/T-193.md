# Remaining 96px/100-event Hokusai raster and complete-gesture latency

**Motivation:** The T-192 journal removes 2,134 redundant native dirty-set insertion attempts per scripted gesture, but paired cold/warm p95, software-X11 frame tails and release-to-settled latency remain variable. The 250ms p95 milestone and 200ms stretch target are not reliable; Hokusai raster (~50ms) and frame/input scheduling still dominate. See [T-192 evidence](../evidence/T-192-2026-11-17-native-dirty-journal.md).

## One bounded deliverable

- [x] Reprofile the current 96px, 512², 100-event native path and identify an independently attributable raster/input-drain bottleneck (raster, fixed-point scan, stage, queued release, first postdraw, frame tails).
- [x] Build a fail-first correctness/latency witness and one measured, reversible optimization; use repeated reversed-order same-binary A/B with **zero-exit** strict source/frame/history checks. Do not fake the 250/200ms goal by reducing samples, masks, preview, backend, batching deadline or soft drain semantics.
- [x] Preserve signed/hidden-RGB/selection pixels, frozen/queued Brush/Eraser, atomic commit/rollback, cancel, Undo/Redo, Save/Open and native/Atlas graphical fidelity.
- [x] Publish cold/warm full-gesture p50/p95 against 250ms/200ms, native CPU phases, first-preview, release→settled, frame/backlog tails, bytes and RSS; retain unsuccessful/incomplete attempts explicitly.
- [x] Keep T-095 owner/physical approval, T-151/T-152 post-consolidation, T-148/T-149 transition and T-105 Windows/export gates open. Split any unmet performance target into a separate explicit follow-up.

## Completion (2026-11-17)

[Native rollback-journal hint A/B and parity evidence](../evidence/T-193-2026-11-17-native-journal-hint.md): the final 32-slot direct-mapped batch-local hint skips **1,840/2,134** redundant authoritative journal map membership probes in the unchanged strict rapid stroke, with safe collisions, rollback and same-binary fallback. Two failed candidates and their source hashes are retained. **34 Rust tests**, **83 graphical checks**, the direct native/standalone/Atlas suites, and four zero-exit full-workspace processes establish native source/history parity. Two reversed-order rapid A/B pairs show **mixed or regressed whole-gesture timing**; the bounded win is the exact map-probe count reduction, **not** reliable 250ms/200ms latency, frame tails or owner hardware acceptance. [T-194](T-194.md) remains Ready for the unachieved complete-gesture target. Unrelated transition, Windows/export and manual-review gates remain open.
