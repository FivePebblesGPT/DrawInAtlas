# Preflight native flood-fill document projection before lazy reads

## Defect

The view-relative ±2³⁰ checks added in T-289/T-292 do not bound global
coordinates after adding the session's signed 64-bit anchor. `begin_edit()`
legitimately accepts a wider historical ±2⁶⁰ anchor than Rust's ±2⁵²
pixel projection. At a native projection edge, `flood_fill()` could fetch an
unpublishable seed's lazy tile or stage an out-of-projection frontier neighbor
and reject an otherwise legal edge fill during native publication.

- [x] Match `_publish_edit()`'s *native* projection selection: attached Rust
      store, or supported native stride with the extension registered. Retain
