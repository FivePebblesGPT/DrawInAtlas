# Editable text layer on first edit; explicit rasterization

**Status: PLANNED.** Owner's new requirement overrides the current Objects-layer text routing as a future target.

## Plan
1. Resolve text-layer granularity in T-051 (one text object per layer or multiple objects in a text layer); agree fonts/units/format.
2. Selecting Text or cancelling a draft leaves document and history untouched. First valid text **commit** creates a new editable text layer and content atomically and undoably.
3. Existing text can be reselected/edited with font, alignment, wrap, transform, color and small-text culling preserved.
4. Implement explicit undoable `Rasterize Layer`, committing pixels at defined density while retaining layer order, alpha and visual fidelity. Rasterized result is no longer text-editable until undo.
5. Test empty/cancelled drafts, first creation, multiple texts, selection, undo/redo, locks, stale targets, save/reopen, font fallback and standalone/embedded behavior.

## Acceptance
Exactly one intended layer created on successful first edit, never on tool selection; editable text until rasterized; faithful and undoable conversion; Atlas need not understand text internals; no old-save migration.
