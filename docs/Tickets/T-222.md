# Replace giant dock minimize chrome with compact icon interactions

## Owner design (2026-11-20)

Replace the full-width `‹ Minimize panels` row with a small **translucent half-circle overlaid on the dock's outer edge**, present and discoverable in both expanded/minimized states. It must not obscure painting or consume a full panel row.

Each panel has one stable icon. **LMB** on an inactive icon selects/opens that panel/group; LMB on its already active open icon collapses or hides that group/flyout. **RMB** shows a panel context menu (three-dots behavior without a permanently visible three-dots button). Keep whole-dock minimize distinct from per-group collapse.

## Acceptance

- [ ] Half-circle overlay replaces giant row, works at expanded/minimized widths, in narrow windows and with 150–200% scaling.
- [ ] Icon LMB/RMB actions behave consistently for singleton, grouped, active/inactive and minimized flyout states; right click never accidentally activates.
- [ ] Click vs drag uses an explicit threshold; focus, tooltips, keyboard menu access and accessible labels remain.
- [ ] No lost/duplicated view, orphan popups or captured canvas input; persistence, native pointer/framebuffer and Atlas/standalone checks pass.

Owner acceptance remains under T-083. See [the dated design](../DRAWING_UX_REVIEW_2026-11-20.md).
