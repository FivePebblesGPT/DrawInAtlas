# Replace giant dock minimize chrome with compact icon interactions

## Owner design (2026-11-20)

Replace the full-width `‹ Minimize panels` row with a small **translucent half-circle overlaid on the dock's outer edge**, present and discoverable in both expanded/minimized states. It must not obscure painting or consume a full panel row.

Each panel has one stable icon. In the **expanded dock**, LMB on an inactive panel icon selects it (and expands its group if collapsed); LMB on the already active icon in an expanded group collapses that group. In the **minimized rail**, the same icon instead opens/selects or toggles the group's flyout **without overwriting the persistent collapsed-group bit**. T-223's triangle marker is the independent, always-explicit collapse/expand control. In **floating hosts**, an icon simply selects the panel: clicking the active tab does not collapse or close the host. **RMB** shows a panel context menu (three-dots behavior without a permanently visible three-dots button). Keep whole-dock minimize distinct from per-group collapse.

## Acceptance

- [x] Half-circle overlay replaces giant row, works at expanded/minimized widths, in narrow windows and with 150–200% scaling.
- [x] Icon LMB/RMB actions behave consistently for singleton, grouped, active/inactive and minimized flyout states; right click never accidentally activates.
- [x] Click vs drag uses an explicit threshold; focus, tooltips, keyboard menu access and accessible labels remain.
- [x] No lost/duplicated view, orphan popups or captured canvas input; persistence, native pointer/framebuffer and Atlas/standalone checks pass.

## Engineering delivery — 2026-11-22

- The persistent, non-scrolling, translucent vector half-circle (`dock_toggle.gd`) is positioned at the canvas/dock seam; the old full-width expanded minimize button and minimized expand button were removed. Its click/focus/tooltip/accessible label and Window-menu equivalent remain available. Godot's content-scale factor was checked at 100%, 150% and 200%.
- The expanded icon selects an inactive tab and expands a collapsed group, while activating the already selected tab toggles **that group's** collapse bit. Minimized icon clicks change only the transient flyout, preserving the stored group collapse. The existing floating-host active-tab no-op is preserved; its visual icon conversion belongs to T-225.
- RMB and Shift+F10 on a panel icon open a single context menu scoped to that **clicked panel**, offering left/right reordering, split and float. The active selection is never changed merely by opening a menu. The existing transactional drag threshold takes precedence over click activation, including Escape/cancel and focus-loss handling.
- Added `drawing/tests/t222_dock_native.gd` (53/53 native-X11 checks with framebuffer screenshots), `tests/t222_atlas_dock_native.gd` (12/12 embedded Atlas checks), and updated the old T-079 graphical witness for the superseding half-circle chrome (40/40). Existing dock layout, cross-drag, one-group floating, edge resize, history, native pointers and persisted recovery regression suites pass.
