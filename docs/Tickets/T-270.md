# Restore required-native T-091 floating-dock CI and Atlas cancellation witness

## Problem

The T-091 on-demand floating-dock workflow staged and imported standalone
Drawing without building the **required Rust Hokusai GDExtension**. A fresh
runner does not have the `.so` in Git, so UI tests could fail during startup
before checking the floating host. That workflow also omitted the canonical
Atlas Drawing consumer, although floating host behavior is shared.

This is a bounded CI/test correction under the engineering-in-progress T-091;
**not** a claim of completed physical Windows/Linux or owner UX review.
