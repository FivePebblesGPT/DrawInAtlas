# Restore verified-source mixed flood-fill staging on native tile history

## Problem

`tests/drawing_fill_verified_stage_smoke.gd` fails **8/29** checks on the
Rust-backed Godot 4.8 beta4 build. Two post-commit assertions require retired
per-pixel `DrawingDelta.before`/`after` data, even though native commits expose
pixels through `DrawingDocument.read_pixel()` and native history. The other six
failures follow from publication at an unsupported signed anchor beyond 2^53.
The failure does not independently demonstrate a mixed-command fill defect.

## Acceptance — one independently verified CI fixture repair

- [x] Reproduce the 8/29 failing baseline with the actual native extension.
- [x] Keep the independent per-session immutable-source `_before` / `_after`
      checks, exhausted-budget atomicity, early edit → fill override → later
      edit, source immutability and optimistic stale-revision rejection.
- [x] Assert every straight RGBA8 pixel (including zero-alpha hidden RGB,
      barrier and blank guard) in the mixed-command region after commit, Undo
      and Redo, verifying one native revision rather than retired history maps.
- [x] Test two fills sharing the original source across a legal large signed
      tile seam. Compare source, commit, Undo and Redo, including guard pixels;
      retain masked-first and unmasked-second fill semantics.
- [x] Retain the public wide signed edit contract while verifying that unsafe
      native publication fails without changing revision or valid pixels.
- [x] Run fail-sensitive mutations of local and far-world expected pixels;
      run native boundary/fill neighbors and existing Python contracts.
- [x] Update parent ticket, index and retained execution evidence without
      altering raster production code or changing manual-review gates.

## Result — 2026-11-23

The repaired Godot 4.8 beta4 native test passes **36/36**. Its fail-first
baseline was **8 failures / 29**. Deliberately changing one expected late
pixel yields **2 failures**, while corrupting one signed-seam expected pixel
yields **3 failures**. Nine neighboring native suites and the focused Python
contracts pass. No production renderer, document, tile or native library code
was modified.
