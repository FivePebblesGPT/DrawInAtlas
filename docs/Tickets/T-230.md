# Bootstrap native ownership for detached historical pixel Undo/Redo

**Split from T-148.** Older local and Atlas-owned `DrawingDelta` history can
carry per-pixel `before`/`after` maps without native tiles. T-156 converted
these events only when `DrawingDocument` already held a `DrawingNativeTiles`
store. If the native store was absent (for example, before the first Brush or
after portable Open), local/host Undo/Redo still committed a **Godot-only**
revision. The next Hokusai transaction would have to rebase, losing continuity
with the host's chronological detached snapshots.

## Acceptance

- [x] With the Rust GDExtension present, send legacy per-pixel replay through
  the existing bounded `_replay_pixel_delta_native` → checked native whole-tile
  replay path **even when no store was attached**. Do not change historical
  `_publish_edit` construction or the native-unavailable negative fixture.
- [x] Prove fail-first local and host-controlled Undo/Redo, exact signed-tile
  canonical RGBA8 (including alpha-zero hidden RGB), shared revision, native
  owner reuse for a subsequent real Hokusai stroke and fresh `.drawing` Open.
- [x] Reject invalid coordinate/source, more than 128 touched storage tiles,
  and busy native transactions without partial pixels, revision or attachment;
  retry after cancellation. Preserve detached owner copies.
- [x] Update prior T-156 expectations, native ABI docs and required-native CI;
  validate nearby native-history, text, Atlas, Object and native-X11 tests.

## Completion — 2026-11-22

`DrawingDocument.replay_delta` now chooses the checked native pixel bridge
whenever the Rust tile-store class is available. The bridge already validates
all sparse coordinates and lazily read sources, constructs bounded whole-tile
snapshots, creates a provisional Rust store, and publishes it only after a
successful native replay. Non-native historical test projects retain the
existing direct fallback until the separate T-150 Legacy retirement.

[Fail-first reproduction, local regression matrix and remaining gates](../evidence/T-230-2026-11-22-detached-pixel-bootstrap.md).

**Scope boundary:** This establishes canonical Rust ownership on the first
**history replay**, not on all legacy *edit production*. Host-owned event
snapshots, other raster publishers and native source/lifetime unification
remain T-148 work. T-149 is Blocked; owner hardware and hosted CI acceptance
are not claimed.
