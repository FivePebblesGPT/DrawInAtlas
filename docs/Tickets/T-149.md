# Godot native dirty-tile preview, display and persistence seams

**Goal:** Integrate T-148's native raster-document authority with Godot Canvas rendering and the standalone/Atlas document interfaces through **bounded tile-level seams**, not pixel dictionaries.

## Deliverable

- **Input seam:** GDScript owns pointer reception, tool selection, canvas camera, document/layer UI and batched `begin/append/end/cancel` commands. Rust owns resampling/dabs, brush strategy, blending/masking, tile staging, transaction generation and native undo data. Instrument sample-batch count/age and input→preview scheduling.
- **Display seam:** Native engine returns signed dirty display-tile descriptors/rectangles and contiguous RGBA8 buffers or native handles with explicit lifetime. Godot retains `RenderingServer`, texture cache, camera transforms and draw submission. Separate storage stride (default 256px) from display textures (currently 128px). Cache/reuse unchanged textures; measure packing/copies and `ImageTexture.update()` cost, without assuming zero-copy or subrectangle GPU updates.
- **Document seam:** GDScript owns layer hierarchy, metadata, history UI, and save/load orchestration; Rust owns raster tile bytes, content revision protocol and undo/redo snapshots/deltas. Implement bulk tile import/export for standalone `.drawing`, Object publication and Atlas consumers, with agreed atomic source authority. No hidden back-conversion to per-pixel GDScript maps for each stroke.
- Handle detached preview, queued second gesture, in-flight save/close/tab-switch/Undo guards (T-124–T-134), stale/lazy source, empty source tiles and independent Drawing export. Keep fallback/unknown tile presentation fail-safe during transition.

## Acceptance

- [ ] Native X11 framebuffer and headless model oracles cover strokes while held, post-release catch-up, queued gestures, pan/zoom, Undo/Redo, Save/Open and Object/Atlas boundaries; preview and persisted content agree with **each selected backend's own** output.
- [ ] Bounded tile handles/buffers across each seam; no hot-path per-pixel GDScript blending/staging/history-map roundtrip. Surface copies/texture uploads instrumented.
- [ ] One canonical revision/transaction owner across UI and raster store. Existing user-visible file safety and invalidation behavior retained; run independent Drawing consumer and suite integration checks.

## Boundaries

It is acceptable for transitional alpha builds to fail while replacing the interfaces. Final native-tile integration must be testable; Legacy removal is deliberately reserved for T-150. Existing T-086 display-hardware review stays separate.
