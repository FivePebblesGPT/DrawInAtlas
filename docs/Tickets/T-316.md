# Authorize verified physical sparse raster sources on first read

## Scope
Continue the shared Drawing source-authority migration without introducing
Atlas feature scope or changing its physical format. Physical sparse manifest
Open remains metadata-only. Each resolved, digest-checked source enters Rust
at the current revision before its Godot projection is published. Portable
Open retains T-315's all-source provisional initialization; historical
logical-only and native-unsupported fixtures retain their existing behavior.

## Acceptance
- [x] No native store allocation or raster decode on physical manifest Open;
  untouched metadata export does not resolve pending chunks.
- [x] First verified signed RGBA8 source initializes a provisional owner;
  later reads preserve its revision, savepoint and Undo/Redo tokens. Hidden
  RGB, locked/hidden sources, native stroke preview and commit remain exact.
- [x] Corrupt, reentrant obsolete or native-rejected sources leave pending
  descriptors untouched. Save/Copy validates authorized bytes before paint.
- [x] When Undo restores a pending subtree, later source reads do not strand
  the structural Redo. Promote only exact digest-checked late sources after
  successful native parking; busy/stale failures retain the original event.
- [x] Real campaign generation/recovery and editor Save/Load regressions;
  integrate required Make/CI witness, document limits, preserve review gates.

## Completion — 2026-11-25
[Execution evidence](../evidence/T-316-2026-11-25-native-sparse-sources.md).
This closes the bounded physical sparse admission path, not native paging or
universal history ownership. The native store's 256 MiB aggregate resident,
transaction and history budget is now also enforced on sparse reads; when
exhausted, admission fails explicitly and the source remains pending. There
is not yet a clean-source eviction/re-admission policy. Large map browsing
and post-consolidation memory/latency profiling remain open in T-148/T-149.
