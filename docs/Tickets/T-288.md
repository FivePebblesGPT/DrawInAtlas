# Restore required Rust ownership and honest beta4 evidence in the T-068 fill-to-frame CI

## Reproduced failure

The optional `.github/workflows/godot-native-t068-fill.yml` imported the project
without compiling/recording the mandatory Rust GDExtension. A clean checkout
has no distributable native `.so`, so this could not prove current native fill.
The script also checked retired `DrawingDelta.after` pixel counts. On the
current Rust-backed beta4 checkout its **15 fill cases failed (15/96)**,
although native publication had succeeded. The process profiler incorrectly
stamped its result `pinned Godot 4.8 beta 2 required by caller`, even when
Godot beta4 was actually running.

## Acceptance — complete

- [x] Install pinned Rust 1.99.1 and invoke `make build TOOLCHAIN=system`
      **before** optional fill profiling. This target compiles, registers,
      imports and probes native Brush and Tiles in both Drawing and Atlas.
- [x] Test the real workflow/lockfile/Make ordering; fail closed if a runner
      drops the build, replaces it with a Drawing-only stage, changes the
      pinned engine/Rust, or moves the build behind the profile.
- [x] Measure input-to-frame at the original sizes/trials without hiding
      a regression behind retired history-map assertions. Verify all committed
      canonical RGBA8 pixels and each clear-border edge after the timed frame.
- [x] Verify profiler provenance against the pinned official Godot version
      and the actual engine hash, fail on missing/wrong versions and reject
      different engine builds between independent runs.
- [x] Retain actual beta4 native/X11, negative control, Python and neighbor
      evidence. Keep owner/physical hardware/hosted gating separate.

## Verified outcome (2026-11-23)

Fail-first Python CI contract detected missing native setup, and native X11
reproduced **15/96 coverage failures**. The repaired five-trial witness passes
**96/96**. Altering the canonical expected color makes **all 15** fill cases
fail, proving the correctness check cannot be satisfied by an empty history.

The complete workflow-shaped profile produced **two independent successful
21-trial beta4 processes, 385 checks each (770 total)**, for 32/64/96px fills.
The profiler's engine is the observed official Godot 4.8 beta4 hash
`b070e63b161aa816afac71dcfc9d60859d38f220`, not a historical label.
The sampled 96px event-to-postdraw p95 values were **228.023ms** and
**214.903ms**, and sampled VmRSS peaks were 282,984 and 280,096 KiB.
The actual `make build` path and native registration succeeded; neighboring
native frontier/cache/verified-stage and Atlas scope tests passed
**56/39/36/103** checks. Python contract, lint, and ticket-store checks pass.
