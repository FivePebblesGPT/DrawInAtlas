# Define viewport-appropriate zoom and artwork LOD

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 2; confirmed artwork-layer meaning in [[E-006]].

## Work
Study Leaflet's relevant zoom/LOD/preview principles and compare them with the current experience: small on-screen hexes and disproportionately large Greyhaven tile detail. Translate useful principles into the shared-board model rather than copying a map-document switching hierarchy.

## Acceptance
- Explain the current scale mismatch with a reproducible example.
- Agree coordinate/resolution relationships, viewport-coverage criteria and transition behavior before implementation.
- Demonstrate coherent world overview/local detail through zoom in both directions.
- Record unresolved thresholds explicitly; the old fixed camera limits/three-extra-step document gate are not inherited requirements for artwork LOD.
