# Preserve foreign temporary entries during rejected native Linux packaging

## Problem and acceptance

T-212's final cleanup unconditionally unlinked a fixed
`libdrawing_brush.so.tmp` path even if the preflight rejected the export
**before the packager had created that file**. This could erase another
process's bytes or symlink, or mask the original validation error with an
`IsADirectoryError` for a directory bearing that name. T-213's strict
inventory correctly rejects all three entries, but did not protect them
from the unrelated T-212 cleanup handler.

- [x] Reproduce deletion of foreign regular files and symlinks, plus the
      masked validation error for a foreign directory, against the old code.
- [x] Allocate each install temporary exclusively with `mkstemp`, retaining
      ownership of its actual pathname; clean up **only** a file allocated by
      this invocation. Restore the staged native library mode (rather than
      leaving the exclusive temporary at 0600), final digest, atomic rename,
      rollback and exact-tree inspection.
- [x] Rejected exports retain the bytes and entry types of any pre-existing
      foreign temp-looking path. An injected interrupted native-library copy
      removes only the newly created partial temporary and parent directories.
- [x] Preserve normal package inspection, stage validation, cross-device
      native preflight, late-rejection rollback, genuine packed-app ABI boot,
      Python checks, Rust checks, Ruff/ty, and the Kanban dependency validator.
