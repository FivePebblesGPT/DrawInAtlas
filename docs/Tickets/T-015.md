The earlier data-conversion and approval proposals below are historical investigation notes, NOT required future work. ## Continued preflight hardening — 2026-11-01 (approval still pending)

The read-only `AtlasLegacyMigrationAudit.inspect` now flags a conversion hazard
that the earlier metadata inventory could not detect: **nontransparent artwork
outside the historical placement's registered child-board crop**. For each
nonsymbolic placement, it checks alpha-used pixel rectangles in signed raster
chunks, including the raster's density and affine transform, and checks
semantic line/path vertex extents with brush width. Warnings retain floor,
layer and chunk/object identifiers for locating the original record. This is a
conservative *screening* check, not a lossless conversion proof; rotated pixel
bounds can overestimate coverage, and text/props require specialist geometry
review. Transparent-only chunks do not trigger a false clipping warning.

The report additionally distinguishes text, image props, editable wall paths,
GM tokens, and per-floor fog state. Nonempty token layers, fog, and semantic
text/prop extents explicitly require policy review; they must not silently be
folded into a child-map footprint. Symbolic placements still have no spatial
crop. Top-level risks are summarized per reason and placement while
`artwork_crop_warnings` keeps individual contexts. The audit remains detached,
read-only and requires approval; neither live artwork nor native save schemas,
legacy readers, or default files have been changed. The T-015 checkbox stays
open pending owner decisions and a separately authorized conversion.

The expanded isolated native-roundtrip test now covers signed nontransparent
chunks, fully transparent outlying chunks, rotated raster transforms, stroke
bounds, semantic text, tokens, fog, and repeatable/no-side-effect inspection.

## 2026-11-03 — marker-only authoring retirement checkpoint (not closure)

The owner has waived migration of historical user saves. In this phase we
removed **all production commands that create child-map/placement bundles**:
`AtlasCreateMap.apply()` refuses `BATTLEMAP` kind; `AtlasLinkEdit` is now a
small, atomic marker-only navigation transaction that rejects nonempty
legacy placement arguments and stored placement IDs, including from low-level
callers. `AtlasLinkedMaps` refuses such edits rather than flattening a saved
footprint, and `prefab/link_dialog.tscn` no longer offers spatial/symbolic
modes, footprint geometry, unit-pitch or center-on-footprint controls. The
independent map/floor relationship, marker position, arrival zoom/focus,
selected-cell restrictions, stale-snapshot rejection, history and native
save semantics stay available.

The legacy tests `tests/links_smoke.gd`, `tests/linked_maps_ui_smoke.gd`
and `tests/smoke.gd` now exercise independently created map documents and
ordinary navigation markers, not low-level creation of historical battlemaps.
`tests/t015_retirement_smoke.gd` specifically rejects forged nested-map and
placement commands without mutating the campaign. The three focused suites
are included in fast push CI after the main Godot class import.

**Focused verification:** T-015 retirement **13/13**, marker/history/native

## 2026-11-03 — active runtime retirement and archival isolation (Done)

This closes the engineering-only T-015 scope under the **owner's explicit
2026-11-01 migration waiver**, not an implied approval of the historical
conversion proposal. The old `AtlasPlacement` resource, the saved `placements`
array, and `placement_id` remain **archival read/write metadata only**, so
opening and saving an old native fixture does not erase or silently convert it.
`AtlasLegacyMigrationAudit` remains a standalone, read-only archaeology tool.
The original maps, floors, artwork pixels, layer order, grids, map IDs and
incoming/outgoing link records are preserved. No old data converter is run.
There is no active command that creates or modifies footprint ownership.

The live boundary now enforces these invariants:

- `AtlasCampaign.find_links_at`, `AtlasMapNavigator` and
  `AtlasOverview` consider **only independent marker links** for pointer hits,
  spatial filters and Open/Focus. Historical footprint links stay listed with
  a *Retired placement link* explanation, but cannot be navigated, focused,
  moved or edited. No fallback anchor or placement polygon becomes a marker.
- The canvas renders only active marker circles/labels. It never draws old
  footprint polygons or move-preview geometry. The layer-panel actions and
  linked-map dialog likewise disable retired links; all mutation commands
  reject them before changing history or the saved graph.
- `AtlasMapReferences` no longer captures parent or child boards as
  registered overlays. The Inspector now offers **Off / Markers** rather than
  misleading aligned-preview options, and hides historical parent reference,
  opacity, freeze and source-placement controls. Independent map search,
  explicit navigation/Back, selected-cell filter and general Drawing previews
  are unaffected.
- Old spatial-preview renderer assertions were moved intact to
  `tests/retired_legacy/references_ui_footprints_legacy.gd.txt` for archaeology;
  the active `tests/references_ui_smoke.gd` tests current marker-only semantics.
  Pure rotated-footprint geometry math remains tested separately in
  `tests/aligned_detail_previews_smoke.gd`, not by the runtime renderer.
