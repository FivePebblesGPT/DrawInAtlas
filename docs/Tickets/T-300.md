# Preserve pending Brush when a bulk edit intersects only selection mask holes

## Defect

[T-299](T-299.md) eliminated a no-op with disjoint selection **bounds**, but a
sparse pixel mask or boolean Subtract/Intersect expression can exclude every
pixel of a region *inside* its conservative bounding rectangle. `fill_rect`,
`apply_region`, `paint_polygon` and `clear_rect` still materialized accepted
native Brush preview state and sometimes touched an unavailable lazy source,
even though no bulk edit pixel was eligible.

## Completed acceptance

- [x] A selection with overlapping conservative bounds but **zero allowed
      pixels** in a small valid bulk area makes all four commands successful
      no-ops before lazy source resolution or any deferred Brush conversion.
      Preserve preview epoch, staged/native state, source-cache count and
      document revision, including masked pixel holes and chained boolean
      Subtract/Intersect expressions.
- [x] Use `DrawingSelection.allows_any_in_area` to prove exclusion only for a
      bounded candidate intersection (at most **4,096** pixels). Plain
      rectangular selections retain the O(1) overlap path; unknown larger
      complex regions fall through to the existing per-pixel mask and must
      **never** be assumed excluded. Inverted, disabled, and additive
      selections preserve their existing semantics.
- [x] Native Brush commits byte-exactly after no-op commands; actual allowed
      pixels still read lazy sources, retry, commit and Undo/Redo, including
      transparent hidden RGB.
- [x] Real Godot 4.8 beta4/Rust fail-first on untouched source:
      **13 failures / 59 checks**; corrected witness **62/62**, and an
      intentionally weakened overlap predicate fails **13/62**. Nine adjacent
      root/Atlas witnesses pass **652/652**. Required T-068 CI retains its
      46-step inventory, exact marker and strict log gate.

[Fail-first, mutation, passing, and neighboring logs](../evidence/T-300-2026-11-24-masked-overlap.md).

**Boundary:** The bounded preflight is intentionally conservative on large
complex masks and does not attempt to change sparse Delete traversal, native
raster ownership, host CI, hardware performance or any owner's visual approval.
T-068 and T-148 remain In Progress; T-250 remains an unapproved manual gate.
