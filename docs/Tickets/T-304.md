# Simplify Selection menu, shortcut captions and snapping chrome

## Owner finding — 2026-11-25
Rectangle selection and Move selected pixels duplicate toolbar tools in Selection; selection modes need Selection > Selection mode; shortcut labels need distinct color; Snap (8 px) toggle should be removed.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
Remove duplicate tool-selection commands from Selection without removing toolbar actions or keybindings. Move Replace/Add/Subtract/Intersect into a dedicated Selection mode submenu with synchronized active state. Render shortcut captions in a distinct readable color across menus. Remove the visible Snap (8 px) toggle, including stale overflow/menu copies; retain generic snapping APIs and Atlas candidate contracts unless separately changed.
