# Preflight host transfer publication and ordered restoration

## Scope
Atlas Move/Copy replay must not publish one document before a predictable
refusal from the other document. Validate the outgoing retained tree and
canonical raster sources without lazy callbacks, including revision headroom.
Restore the original sibling position in the import revision itself. Undo of
an independently copied locked/hidden root must not depend on ordinary layer
delete permissions or weaken those permissions for ordinary commands.

## Acceptance
- [x] Fail-first witnesses for protected Copy Undo, ordered Move Undo,
  revision exhaustion and reentrant destination mutation during lazy capture.
- [x] Reject changed source metadata, raster bytes and pending descriptors
  before destination publication; preserve history, dirty state and revisions.
- [x] Copy captures remapped detached IDs before import publication; Move
  retains a single logical snapshot shared by both document visits.
- [x] Restore original sibling order in one revision, including final
  available native revision; no fallible post-publication live export.
- [x] Preserve lock/visibility properties and ordinary deletion guards;
  host Copy Undo checks its retained source and editable parent.
- [x] Real native fail-first/green regressions, pinned Make and CI integration,
  adjacent history/persistence checks and ticket validation.

This is host-coordinated preflight plus deterministic publication, not a
single Rust transaction across two stores. The defensive compensating path
remains for unexpected internal failure; independent Copy Redo trusts its
retained snapshot. T-148 stays In Progress and T-250 stays Manual Review.
