# Fail closed on rejected native semantic-only subtree removal

**Split from T-148.** T-173 protects public metadata operations and T-176
protects semantic structural Undo/Redo, but `DrawingDocument.remove_subtree()`
continued to erase **semantic-only** (no raster descendants) nodes before
calling `_advance_nonraster_revision()`. During an active Rust stroke or
native-ahead revision, that post-mutation bridge detached the canonical Rust
store, committed the Godot deletion and could strand its native Undo history.
T-168 already fences *raster-bearing* subtree removal; this ticket closes the
complementary semantic-only path.

## Acceptance

- [x] If Rust is attached and no raster descendants exist, acquire the
  exact checked native metadata revision **before** `_erase_subtree()`;
  reject busy or divergent Rust stores with `NATIVE_METADATA` or
  `STALE_REVISION`, without changing nodes, revision, local/host history,
  dirty state, canonical tile bytes or native attachment.
- [x] On an authorized removal, increment Godot/native revisions once,
  preserve existing native Brush Undo tokens and full hidden-RGB bytes;
  keep local recorded Undo/Redo and nonhistorical and Atlas/host-owned
  structural behavior correct. Native-absent behavior stays available until
  T-150.
- [x] Exercise real Hokusai source/history with recorded, unrecorded,
  external-history, busy-native and native-ahead semantic deletions; verify
  subsequent Brush on the same Rust store, exact retry, nested Undo/Redo,
  and `.drawing` Save/Open. Run the identical fixture against the pre-fix
  source as a fail-first control.
- [x] Run offline pinned Rust tests, rustfmt, strict Clippy, release build,
  native structural/metadata neighbors, Atlas/Object integration and two
  software-X11 graphical witnesses. Record raw execution logs with SHA-256
  checksums and add required-native CI coverage.
- [x] Synchronize T-148, ABI documentation, `docs/Index.md`, ticket
  dependencies and the validator without changing manual-review gates.

## Scope boundary

Only `remove_subtree()` where the **entire removed subtree is semantic-only**.
Raster-bearing removals retain T-168's parked/retired/unreferenced native
protocol. This does not complete T-148's host-owned detached-history or
universal raster authority acceptance; T-149 remains Blocked, and T-095
hardware/owner signoff is independent.
