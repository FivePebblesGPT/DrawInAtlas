# Fail closed on rejected native semantic structural Undo/Redo

**Split from T-148.** Public layer metadata writes were checked before mutation
under T-173, but local `DrawingDocument._replay_structure()` still changed
Godot's tree before calling `_advance_nonraster_revision(false)`. If a Rust
stroke was active or the native revision had moved ahead, replay could report
success, detach the Rust store and advance only the local history cursor.
This ticket fences the **semantic-only structural replay** paths (property,
reorder, semantic create and semantic subtree removal) without changing raster
parking or host-owned detached history.

## Acceptance

- [x] Validate structural-history targets and acquire the exact checked Rust
  metadata revision **before** changing Godot layer properties or membership.
  Busy and native-ahead stores reject with `NATIVE_METADATA` / `STALE_REVISION`.
- [x] Preserve local Undo/Redo cursor, revision, hierarchy, semantic values,
  dirty state, full native RGBA8 (including transparent hidden RGB), and Rust
  Undo tokens on rejection; keep the same native store attached.
- [x] Use `discard_redo=false` for accepted history replay, preserving the
  redo timeline, while public *new* metadata operations retain their default
  branched-history behavior. Verify successful Undo/Redo retries.
- [x] Exercise a real Hokusai Brush before and after structural history replay,
  native-ahead rejection, native-absent compatibility, and `.drawing` Save/Open.
- [x] Add required-native CI, source/ABI/index updates, fail-first control,
  raw logs with verified SHA-256 hashes and ticket-store validation.

## Boundaries

T-176 does **not** close native-owned raster create/remove structural replay,
text↔raster replay, external Atlas/Object host-owned detached history, other
non-Brush raster producers or universal native revision authority. Those remain
T-148 acceptance work; T-149 stays Blocked. No T-095 hardware or owner signoff.
