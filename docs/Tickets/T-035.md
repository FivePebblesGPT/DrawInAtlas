# Simplify selection geometry

## Source
[[ManualReview_2026-10-30#Code review|Code review]], items 7–9; target: `scripts/editing/selection_geometry.gd`.

## Acceptance
- Clarify hit testing, bounds, coordinate spaces, selected-content identity and transform/mask validation.
- Split multi-concern functions into named/commented steps with explicit types.
- Preserve existing selection and transform behavior during refactoring; separate any new tool-design changes under [[E-TOOLS]].
- Verify representative geometry/native interaction cases and code-only readability.

## Implementation — 2026-10-30

- Documented the distinction between **document-space ink points**,
  **raster-local board units**, and **signed sparse raster pixel chunks**;
  raster selection still uses the derived transformed AABB of the complete
  chunk envelope (including transparent areas and gaps), not a pixel mask.
- Kept `select_indices()` responsible for detached layer identity snapshots,
  atomic stroke-index validation and whole-layer raster selection. Documented
  that index positions are not persistent object IDs, selection is invalidated
  by source changes, and marquee hits require full padded bounds.
- Extracted `_hits_stroke()` from reverse-painter-order `select_point()` so
  text glyph bounds, filled interiors, rendered editable paths and segment
  tolerance have one named algorithm. Raster point picks still inverse-map
  document coordinates into the layer's local bounds.
- Kept `transformed()` as the guard/clone/validation boundary. Extracted
  `_transform_ink()` for uniform scale, width/text rotation and per-stroke
  old/new scope checks; extracted `_transform_raster()` for affine placement
  composition and whole-envelope old/new scope checks. All edits remain on
  detached snapshots, rejected operations leave the original untouched, and
  full layer codec validation still gates success. No public API, persistence
  representation, tool design or edit-history behavior changed.
- Extended `tests/selection_smoke.gd` with stacked filled-hit priority,
  sparse negative/partial chunk bounds, transformed AABB, local-to-document
  picking, gap-envelope semantics, complete marquee, detached pixel buffers,
  and source/destination mask rejection.
