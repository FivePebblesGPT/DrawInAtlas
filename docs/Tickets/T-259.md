# Recover floating-panel gestures when mouse-up is lost but focus remains

## Defect (2026-11-22)

T-257 added Escape rollback and T-258 cancels a floating host's in-flight move/resize/tab transfer on OS focus loss. A different failure remained: if the OS/window manager dropped **mouse-up without changing application/window focus**, the next `InputEventMouseMotion` could report that the left mouse button was no longer held. `DrawingFloatingHost` continued interpreting that motion as a drag, leaving a temporary rectangle or tab transfer live and potentially accepting a delayed release.

## Acceptance — engineering Done

- [x] A motion event without `MOUSE_BUTTON_MASK_LEFT` cancels only the pending floating gesture/cross-drag *owned by that host*, restoring the original move/resize rectangle and preventing any delayed mouse-up from committing it.
- [x] Legitimate held-left drags and subsequent fresh mouse presses continue to work, including resized/corner geometries, tab ownership and idle sibling isolation. Existing Escape and focus-out cancellation remain equivalent.
- [x] Fail-first standalone X11 and Atlas-hosted tests cover move, resize, tab cross-transfer, late release, multiple simulated UI scales, document revision/dirty state and follow-up legitimate gestures.
- [x] Preserve the one-group host, native raster history and per-panel persistent layout ownership. Run neighboring docking regression suites and record limitations without granting an owner-review gate.

**Implementation:** In [`DrawingFloatingHost`](../../addons/drawing/floating_host.gd), an unpressed motion detected while this host owns an in-flight pointer gesture invokes the same shared rollback helper used by Escape and focus-out. The handler returns before processing motion as a drag. An idle sibling does not cancel any other host's gesture.

**Tests:** [`t259_floating_lost_release_native.gd`](../../drawing/tests/t259_floating_lost_release_native.gd), [`t259_atlas_floating_lost_release_native.gd`](../../tests/t259_atlas_floating_lost_release_native.gd), [`on-demand CI`](../../.github/workflows/godot-native-t259-floating-release.yml), `make test-floating-release`.

**Evidence:** [T-259 engineering report](../evidence/T-259-2026-11-22-lost-release.md).

**Review boundary:** Software-X11 input with an injected missing-release sequence is not physical Windows/Linux or window-manager certification. **T-091 stays In Progress; T-083 and T-250 are unapproved.**
