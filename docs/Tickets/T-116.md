# Verify Atlas Text Save/Open against portable campaign generations

**State: Done** for this independent test-only persistence repair. T-027's
Text editor controls, font/fallback and 9px screen-space readability policy
remain outside this ticket and require separate owner review.

## Defect and bounded change

The historical `tests/text_smoke.gd` invoked the live Atlas Editor's
`_on_save()` (portable generation publication) but then attempted to reopen
its retired single-file `.scn` path with `load_campaign()`. That produced two
real failures on pinned Godot 4.8 beta3, even though the editor published its
portable campaign correctly. The old test also used a separate legacy-native
save for the D1 text layer, rather than exercising the Editor's current Save.

- Load both D0 and D1 snapshots with `AtlasCampaignStore.load_portable_result()`
  after actual Editor saves. Require valid generation IDs, an existing portable
  project root, no obsolete single-file head, and an exact whole-campaign
  dictionary roundtrip.
- Compare the saved Objects-layer dictionaries and text content, ensure
  saved D0 text reopens as editable, and verify D1 detail-level persistence.
- Undo and Redo *after* the D1 save must not mutate the independently
  loaded published generation.
- Run this test in the existing required T-055 Atlas composition CI step
  with a separate 120-second watchdog, raw log and strict T-094 success-marker
  verification, preserving **46 required CI check IDs**.

No application runtime, campaign schema, native codec, user-facing text controls
or review flags change. No hosted or physical device acceptance is inferred.
