# Atlas composition: embedded Drawing, entrance input and read-only previews

**Status: PLANNED.** Asset semantics (T-060) and world/detail/floor model (T-061) are independently reviewed prerequisites. No mandatory native LOD library.

## Plan
1. Consume the canonical Drawing package from the same monorepo; verify the Drawing project itself builds independently. Atlas may supply document handles, floor-group views, world-to-asset transforms and explicit current-detail edit target.
2. Use the asset registry/binding API from T-060: live linked artwork updates all instances; a copy is a new asset. Preserve per-map transforms and avoid hidden edits to source assets on layer/group operations.
3. Atlas maps one floor to one Drawing layer-group view. World coordinates are shared among authored levels, while Drawing receives only asset-local/editor-space render and edit requests. Show no lower-level art when higher-detail content is missing.
4. Keep grid/hex overlay, links, fog, tokens, projector and navigation outside Drawing. Atlas can supply generic snap targets and board-space edit masks; Painting tool wins click arbitration at entrance locations.
5. Only Selection/ObjectSelection/Pan double-click of the **same stable entrance ID** may navigate. Use explicit hit testing and stale target rejection; define overlapping entrance handling and click threshold in T-051. A single click must not navigate.
6. Global undo/redo uses T-054 context, navigating to the originating map. Atlas may change map/floor/detail presentation during zoom but must freeze the in-flight Drawing edit target until commit/cancel.
7. Preview capture uses Drawing read-only rendering through explicit viewport bounds/LOD and transformed asset references, not interactive `AtlasCanvas`; no document mutations, correct alpha and cache invalidation.
8. Incrementally remove transitional `AtlasCanvas`/editor facades after tests, rather than one giant rewrite.

## Acceptance
Same Drawing painter in both apps; atlas floor groups and shared/copied art behave correctly; blank D-level stays blank; world transformations align; paint-over-entrance paints; double-click with navigation tool works; undo back to A; previews are read-only; no Atlas dependency in Drawing.
