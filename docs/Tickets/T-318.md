# Acquire native text raster ownership during detached structural history replay

## Scope
Close the T-148 text-to-raster history gap after a native owner is detached,
recreated without glyphs, or stale. The semantic text tree and ordered history
remain host-owned; this checkpoint does not replace the general host timeline.

## Acceptance
- [x] Undo of a detached rasterization compares the live raster to its saved
  history snapshot, acquires the exact signed bytes and parks them atomically.
- [x] Redo of a detached rasterization adopts the stored glyph source into a
  provisional or existing unreferenced owner before publishing its projection.
- [x] Parked history remains byte-checked; incomplete or invalid descriptors,
  pending transactions, stale attached revisions and over-budget sources fail
  without consuming the structural step or exposing a partial owner.
- [x] Native replay preserves unrelated Undo/Redo tokens, does not create a
  pixel event, and empty rasterizations do not create tombstones.
- [x] Real pinned native, Rust and neighboring history/persistence tests;
  document the additive ABI and integrate Make/CI.
