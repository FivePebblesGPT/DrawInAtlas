# Make recent colors deliberate commits and remove redundant Restore previous

## Owner reproduction — 2026-11-22

While dragging the native ColorPicker hue/value control toward pure red, the recent bar fills with **intermediate colors from the drag**. The owner's `image(1).png` (committed as [`DrawingCurrent.png`](../assets/drawing-ux-2026-11-22/DrawingCurrent.png)) shows the gradient, versus the original `DrawInAtlasColorPanelConcept.png` design ([owner review](../DRAWING_UX_REVIEW_2026-11-22.md)). The separate `Restore previous` control is redundant beside a correct recent-colors strip.

![Owner's original Color panel concept](../assets/drawing-ux-2026-11-22/DrawInAtlasColorPanelConcept.png)

## Acceptance

- [x] Picker drag may update live FG/BG preview and active color continuously, but inserts **at most one deliberate settled color** into recents when a pointer gesture commits (and never per intermediate `color_changed` frame). A canceled/no-op gesture adds nothing. Handle typed Hex, keyboard changes, preset/recent choices and Swap/Default through explicit settled-change semantics rather than arbitrary timer sampling.
- [x] Include a gesture-aware state machine or equivalent for native Godot ColorPicker interactions. Keep exact RGBA8, alpha-zero hidden RGB, deduplication, bounded recents, selected FG/BG role and suppress both active colors from displayed bars; earlier historical entries must remain retrievable.
- [x] Remove the redundant `Restore previous` UI action and any unneeded spacing; keep Swap/Default discoverable but compact. Avoid adding a second custom picker or visual labels absent from concept.
- [x] Match FG/BG blocks and recent vertical-strip proportions to the owner's concept, including narrow/floating/minimized presentations.
- [x] Provide a real pointer-drag witness over many hue/value steps: live color changes many times, recents gain **one** settled entry, Undo/Redo/document dirty state unaffected. Test cancellation, hex, role switch mid-gesture, persistence and X11/Atlas embedding.

**Boundary:** T-226 is historically Done for its initial filtered recents and inline ColorPicker. T-250 owner review is still required.

## Engineering completion — 2026-11-22

**Done for this bounded UX implementation, not owner UX signoff.** The actual native
`ColorPicker` now makes live FG/BG updates without recording intermediate drag
steps. Pointer release, keyboard key-up, committed hex, and line-edit focus exit
settle one change; Escape cancels an active gesture. Role switching first settles
the previous role. The bounded six-entry recent-color ring retains canonical
RGBA8 identities (including hidden RGB at alpha zero), while filtering both
current pigments at display time. The two previous-color restore controls and
redundant Recent/Editing captions are removed; FG/Swap/BG and the six vertical
recent bars share the compact strip, with the inline native picker immediately
underneath and exact hex/default controls available lower in the scroll.

Palette state now persists in an independent bounded/strict/atomic application
preferences file, never in Drawing document revision, dirty bit, or undo history.
The same panel is reparented for floating and Atlas consumers.
