# Reduce residual native Drawing latency after exact preview invalidation

**Motivation:** T-186's [matched evidence](../evidence/T-186-2026-11-17-exact-native-dirty-preview.md)
proves reduced Canvas recomposition, texture requests and long frames without
warm-tile holes. The separately pinned 96px/512² T-146
`total_to_postdraw_ms` remains ~517ms cold p50 / ~613ms warm p50 under
software X11, above **250ms milestone / 200ms stretch**. Do not treat
T-186 completion as achievement of these targets.

## Scope (one independent next step)

- Re-profile the **remaining** rapid T-146 latency and full-app tail after
  batch-local preview changes. Distinguish native stroke staging, redundant
  full-storage-tile RGBA read/export and post-staging render/composite work;
  focus on the next dominant stage with measured CPU/FFI/copy evidence.
- Implement **one bounded** further improvement only after a matched,
  fail-first counterfactual shows why it should help. Do not combine unrelated
  pipeline rewrites or hide pixels behind cold population budgets.
- Keep the same 100-event 96px/512² `total_to_postdraw_ms` metric, source and
  preset identities, native backend, environment and cold/warm cache definitions.
  Report p50/p95, frame p50/p95, >83.33ms fraction, first preview, input
  backlog, release→commit/settled, requested uploads, native exports and RSS.
- Preserve source alpha/hidden RGB, native masks, signed tiles, queued/cancel
  gestures, T-181/T-186 framebuffer retention, Save/Open and Undo/Redo.
  Regression and raw failed attempts must be retained.

## Acceptance

- [ ] Before/after includes a repeated matched counterfactual with preserved
      native output and no queue/post-release latency displacement.
- [ ] Achieved 250ms and attempted 200ms are reported against the **unchanged**
      full rapid metric; any unmet milestone remains explicitly open.
- [ ] Real native graphical and headless regression suites pass; no manual
      T-095 hardware/owner review is self-approved.

T-151/T-152 post-consolidation and T-095 physical comfort remain separate
hard acceptance gates, not silently included in this independent milestone.
