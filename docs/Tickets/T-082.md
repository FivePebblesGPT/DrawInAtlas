# Transactional cross-container docking with alignment previews

**Status:** Blocked on T-081. See [agreed docking behavior](../DRAWING_DOCKING_SPEC.md).

## Scope

- Drag an individual panel tab **or a whole tabbed group** between the expanded right dock, its minimized icon rail and one or more floating in-app containers.
- Show unambiguous target previews for insert before/after a particular group, before/after a tab within a group, and group merge/split. Preview reflects actual cursor position and final order, including relevant separators and tabs.
- **Whole-group redock:** dragging a floating tabbed group into the dock reinserts **every member in its current order at the indicated insertion position**. The full icon sequence returns to the dock rail, with separators reflecting group boundaries. A single-tab drag transfers only that tab.
- Dragging a group out of the dock removes **all** its icon buttons and separator boundaries from that dock; floating host retains its own tabs and supports subsequent reordering.
- Transfers must be transactional across both source and destination. A cancelled drag (Esc, invalid target, focus change) restores exact prior ownership, active tabs and ordering; no duplicated live UI, orphaned tabs or document edits.
- Handle resize/scroll while previewing, input event routing and keyboard-accessible target choice wherever feasible. Native OS windows remain out of scope.

## Acceptance

1. Native end-to-end evidence: group Colors + Layers, detach the group, reorder it to Layers + Colors while floating, and redock **between two existing groups**. Assert rail icon order and group separators match the precise indicated insertion target; no original icons remain stranded.
2. Test single-panel moves separately, group merges, split targets, scroll-edge positions, repeated dock/undock, multiple floating hosts, narrow window and high DPI.
3. Esc/invalid destination/target destruction returns exact source/destination models and original focus, without duplicate controls or dropped input into the canvas.
4. Cross-container tests run alongside T-079–T-081 regression suites. No persistence or owner signoff is implied; those are [T-083](T-083.md).

Engineering ticket; manual UX acceptance remains T-083.
