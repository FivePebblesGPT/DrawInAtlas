# Replace sparse Drawing manifests and Atlas generation records with binary

**Owner direction, 2026-11-27:** binary-only application persistence; no historical save migration.

Replace `DrawingBundleManifest` and `AtlasCampaignBundle` JSON roots, backup pointers, generation indexes, registry/object snapshots and content-addressed document manifests with versioned, bounded, typed binary records. Reuse an object-free binary envelope where practical; preserve native `.scn` metadata, sparse compressed tile blobs and portable directory hierarchy. Update path and digest contracts coherently; no JSON fallback or migration.

## Acceptance
- [ ] Validate magic/version/schema, exact lengths and digest before bounded decode; reject unsupported types, malformed/oversize records, unsafe paths and stale generation leases. Maintain exact signed addresses and deterministic canonical encoding/digests.
- [ ] Preserve single atomic root publication, independent prior-generation recovery, immutable reference identity, lazy loading, deduplication, unchanged-document reuse, dirty/savepoint semantics and verified asset/font references. No eager decode or destructive GC.
- [ ] Update Save/Load, Copy, recovery and failure-injection witnesses, including partial copies, interrupted publication, stale concurrent writers, signed pixels and hidden RGB. Record actual storage/latency tradeoffs and run native/hosted tests.
