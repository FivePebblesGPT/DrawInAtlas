## Mid-gesture edit-mask safety follow-up — 2026-11-01

- Fixed a preview/commit authorization mismatch: a Line now captures the map,
  floor, Raster layer, and exact selected-cell mask when pressed. If the
  current target or mask differs on release, it discards the detached preview
  instead of painting under a different mask, and displays a rejection message.
  Re-selecting the original cell permits a fresh gesture; selecting a cell with
  masking disabled does not cause false rejection.
- `tests/line_smoke.gd` now covers visible masked previews, stale-cell release
  with **no raster/history mutation**, clean cancellation, fresh-mask retry,
  undo, and unrestricted selection changes. `tests/line_visual.gd` exercises
  the stale-cell case via native pointer input and checks the actual raster
  and status display. No save schema or approved interaction policy changes.
- This engineering follow-up does **not** supply the outstanding owner's
  approval of endpoints, constraints, styling, or release-to-commit behavior.
  The Index checkbox stays open.

## T-111 mid-gesture release authorization (2026-11-12)
