# Fence host-owned history against an implicit local takeover

**Bounded T-148 child.** `DrawingDocument.set_external_history()` previously
blocked the local-to-host transition when `_events` held local commands, but
allowed the reverse transition even after recorded Atlas/native edits. Host
commands are intentionally not kept in `_events`, so the empty local timeline
was not evidence that the host had discarded its command history. Switching
to local mode could silently orphan host Undo/Redo and native tile tokens.

## Acceptance

- [x] Record the document revision when host ownership is selected. Allow a
  no-op call or a transition back before any revision-producing edit; reject
  the transition to local ownership after a host-owned revision with
  `HISTORY_OWNED` and no side effects. Repeated enable calls must not reset
  the ownership fence.
- [x] Cover recorded native edits, untracked raster publication, semantic-only
  structural changes and a complete host Undo/Redo sequence. Equal restored
  pixels must not imply that discarded host commands are safe.
- [x] Preserve old local-to-host guards, no-change mode selection and rejected
  operation behavior. Verify exact hidden RGB, revision, store identity,
  native history tokens and local/Atlas integration with actual native tiles.
- [x] Add fail-first evidence, required-native CI coverage, ticket/Index
  updates and regression results without self-approving T-148 or owner gates.
