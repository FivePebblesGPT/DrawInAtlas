# Fail closed on rejected native semantic-only detached subtree imports

**Split from T-148.** `DrawingDocument.import_subtree()` prepared semantic-only
nodes but then called `_advance_nonraster_revision()`. That helper increments
Godot's revision first, drops an attached Rust store if Rust refuses the
metadata revision (busy/stale), then allows the imported nodes to publish.
Raster-bearing imports were already guarded by T-169; this covers the
previously unprotected **zero-raster** path, including standalone Copy.

## Acceptance

- [x] A semantic-only detached import acquires the exact native metadata
  revision *before* publishing nodes, dirty state or untracked history.
  Rejection is typed (`NATIVE_METADATA`, `STALE_REVISION`) and failure-atomic.
- [x] Preserve valid nested group, text, object import and native-absent
  compatibility; copying to a busy native destination leaves both documents
  unchanged, and retry after releasing the native transaction succeeds.
- [x] Preserve canonical RGBA8 and native Undo tokens through a valid import,
  later Hokusai Brush/Undo/Redo and `.drawing` Save/Open. Reject native-ahead
  source without detaching the original tile store.
- [x] Run an independent real-native Godot fixture plus the **same** fixture
  against the pre-fix publisher (fail-first); run pinned offline Rust checks,
  neighboring Drawing/Atlas/Object regressions and two graphical witnesses.
- [x] Add required-native CI, T-148/Index and ABI updates, raw execution logs
  with verified SHA-256 manifest and ticket-store validation.

## Scope boundary

T-175 closes **semantic-only detached import**, not internal structural
history replay, host-owned detached history authority or all raster producers.
No T-149 unblocking, hosted CI green or T-095 manual/hardware approval follows.
