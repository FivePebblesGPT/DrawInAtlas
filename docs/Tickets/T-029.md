# Audit dictionary conversions and remove obsolete JSON-era code

## Source
[[ManualReview_2026-10-30#Code review|Code review]], item 2.

## Work
Inventory `to_dict`/`from_dict` callers and distinguish obsolete user-save logic from current cloning, validation, digest, history and clipboard responsibilities. Design replacements where needed before removing adapters.

## Acceptance
- Every remaining conversion has an explicitly reviewed current purpose; approved obsolete paths are removed.
- Resolve native Resource validation/copy/integrity responsibilities without creating a second hidden authority.
- Preserve exact pixels/metadata, independent copies, undo and recovery; revalidate [[E-SAVE]].
- Decide any persistence/schema change explicitly, with scoped follow-ups where the audit reveals larger work.

## Outcome — 2026-10-30

**Accepted cleanup decision:** Keep the existing single-file native `.scn` persistence format and schema version 6. The audited dictionary adapters all have current non-JSON-save responsibilities (strict validation, detached history/selection and clipboard snapshots, native digest, legacy compatibility, and read-only inventory). **No exclusively obsolete campaign JSON adapter was found**, so no `to_dict`/`from_dict` API was deleted. These functions are not a second persisted save authority; see [[DICTIONARY_CONVERSION_AUDIT]]. This preserves the native-save gate rather than inventing unapproved schema changes.

**Implemented cleanup:** Refactored `AtlasLayerCodec.valid_collection()` so it validates typed layer metadata and live raster-chunk invariants without deep-copying every decoded Image. `clone()` reuses that validation step but still makes isolated Image copies for editing/history. Rejects inconsistent in-memory chunk keys and null/invalid chunks before cloning; validation and cloning continue to rely on one dictionary metadata parser. Corrected two stale source comments that called native saves JSON. Added `tests/dictionary_conversion_audit_smoke.gd` and a CI check.

**Verification (Godot 4.8 beta2):** new audit **17/17**; all **40 applicable headless regression suites** (split across executions after combined-run timeout); **4 native framebuffer suites** (`visual_smoke`, `linked_maps_ui_smoke`, `references_ui_smoke`, `layer_hierarchy_visual`); parser/resource import, explicit-type audit; main scene launch; non-threaded Web release export; four fresh-process source/exported-pack save reads and writes. Existing `storage_smoke` independently passed **76 checks**, covering exact pixel bytes, recovery and injected IO faults. These checks ran before the final null-chunk guard, which was separately validated by the new 17-check audit; no schema or end-user save data changed. Remote CI and manual usability acceptance are not claimed.

**Deferred, independently scoped:** legacy placement migration T-015, raster import/chunk design T-030, tile naming/type authority T-031, field invariant documentation T-032, and any future measured replacement of dictionary-based history snapshots or semantic hashing.
