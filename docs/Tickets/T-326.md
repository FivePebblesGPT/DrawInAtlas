# Preserve transferred raster layers' own native history between visits

## Scope
A reversible external structural transfer must not retire the actual moved
or copied raster's native paint tokens. Keep the chronological host's native
events in their original document while releasing the departed live source.
Re-admit the complete raster source set when the layer returns, including
blank coordinates needed by retained Undo/Redo. Repeated moves back into a
previous document must work without parking duplicate live source buffers.

## Acceptance
- [x] Fail-first Move/Copy and repeated cross-document move witnesses.
- [x] Retain both applied and future tokens belonging to transferred IDs,
  release departing source tiles, and reject replay until sources return.
- [x] Re-admit complete sources including blank history coordinates, without
  overwriting live or parked native sources or inventing a paint token.
- [x] Reject ordinary identity reuse while history remains; branch/reset
  releases abandoned tokens and makes absent IDs reusable.
- [x] Exact signed hidden RGB through chronological Undo/Redo, independent
  native rejection tests, pinned Make/CI integration and adjacent regressions.
