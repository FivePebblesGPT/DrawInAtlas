# Acquire native raster ownership during detached subtree removal history

## Scope
Close the local structural removal replay gap when the original native owner
is absent or a replacement owner has no references to the affected raster
IDs. Admit the entire retained raster subtree before publishing a restored
tree, or park the verified live sources before removing it again. This is
not general Atlas timeline ownership or mixed partially-owned source adoption.

## Acceptance
- [x] Undo with no native owner or an entirely unreferenced replacement
  acquires all retained signed RGBA8 sources in one checked revision.
- [x] Detached Redo compares the live hierarchy, retained tile set and exact
  bytes, and parks the affected raster IDs atomically, including siblings.
- [x] Invalid late descriptors, additional unauthorized tiles, stale/active
  owners and script reservations reject without consuming history or exposing
  a partial native owner. Subsequent replay validates newly admitted sources.
- [x] Preserve unrelated native Undo/Redo; no new pixel history event.
  Completely empty/unresolved removals retain their metadata-only path.
- [x] Preserve original lazy descriptors without reading them, and retain the
  prior physical late-source promotion and logical-only lazy behavior.
- [x] Run pinned Godot/Rust regressions, update the ABI and require the new
  witness in ordinary Make and fast desktop CI.
