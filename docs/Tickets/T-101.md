# Optional NativeHard and Hokusai end-to-end throughput

**Parent:** [T-095](T-095.md). **State:** Done for this optional native-path
optimization and its tests; **not** a pass of the owner's latency target.

## Delivered

- Retain the real NativeHard swept-coverage ABI and transactional Rust
  `begin_hard_batch` / `commit_hard_batch` / `rollback_hard_batch`.
  For a batch that has not mixed public edits, select the existing verified
  `_stage_brush_tile()` directly **once before the pixel loop**, rather than
  dispatching each native-covered pixel through `_stage()` and testing the
  brush-only fast path again. An earlier mixed edit/Hokusai session still
  uses `_stage(..., internal_brush=true)` and full canonical keys. Each
  failure rolls back preview journals and native coverage/cursor as before.
- Add an independent 5,035-assertion native-packed-coordinate transaction
  oracle covering huge signed anchors, masks, Brush/Eraser, hidden-RGB source,
  transparent and partial-alpha history, late lazy-source failure and retry,
  one revision, Undo/Redo and **four red controls** against T-100.
  A separate opt-in, seven-trial 65,536-coordinate headless CPU benchmark
  isolates GDScript staging overhead; it is not a CI timing requirement.
- Keep bundled Hokusai presets and pigment-export logic unchanged after
  profiling: the separate Hokusai staging micro-optimization tried locally
  did not give a dependable win. Keep NativeHard optional: no new binary,
  FFI version requirement, exported method, preset format or release build
  dependency. Wire the standalone oracle with fail-closed T-094 log handling
  into the on-demand T-095 workflow and raw artifact retention.

## Evidence and limitations

[Benchmarks, old-source negative controls, exact test invocations, commit
provenance and native-present/native-absent outcomes](../evidence/T-101-2026-11-12-native-dispatch.md).

In a first same-host seven-trial CPU-only comparison, the median for staging
65,536 prebuilt NativeHard coordinates improved from **284.175ms to
232.521ms** (p95 415.862ms to 309.358ms). Measured source-only timing
excludes native coverage, drawing/preview composition and pointer receipt.
The 96px full-canvas Xvfb/Godot pointer oracle retains exact source bytes,
100 input events, Undo/Redo and one history revision. Its whole-gesture
lag remains **seconds**, not 100ms. The measured per-stage soft drain
budget was not enlarged; software stalls can exceed 6ms. A real bundled
Hokusai .myb stroke, pigment atomicity and source-byte parity remain
independently tested, but no Hokusai throughput improvement is claimed.
