# Reserve Atlas command history during a Drawing publication

**Bounded T-148 child.** `AtlasEditHistory.commit_drawing()` validates its host
context before calling `DrawingEditSession.commit()`, but the commit can invoke
lazy raster providers synchronously. Before the `AtlasDrawingEdit` is appended,
those callbacks could reenter the same Atlas timeline to run Undo/Redo, create a
command, record selection, mark the state saved/dirty, or reset the campaign
history. Even a nested commit of the same pending session was accepted.

## Acceptance

- [x] Reserve the Atlas command timeline from the start of `session.commit()`
  through command insertion **and** revision-ledger publication.
- [x] Reject nested Drawing commits, grid/transfer/asset commands,
  selection-history edits, Undo/Redo, reset, and checkpoint/dirty-state mutation
  during that window without touching the existing history.
- [x] Do not retain a reservation after rejected publication; ordinary host
  commands and Undo/Redo resume. Preserve the intended single Drawing command,
  native tile history token, signed alpha-zero hidden RGB and Atlas playback.
- [x] Reproduce the reentrant failure before implementation, add an exact-count
  Atlas integration regression to required fast CI, and run neighboring native
  history, ownership and Atlas regressions.

## Completion — 2026-11-22

The final 126-check real Atlas/native fixture fails **22/119** checks against
unmodified `AtlasEditHistory`, and passes **126/126** after the reservation.
It covers the lazy-publication reentrancy seam, nested commit, command,
selection, Undo, Redo, state markers, reset, synchronous `changed` observers,
rejected-commit release and byte-exact Undo/Redo. See
[execution evidence](../evidence/T-245-2026-11-22-atlas-commit-reentrancy.md).

**Scope:** Atlas timeline entry-point reentrancy during Drawing publication;
this does not freeze arbitrary direct writes to campaign/model objects, replace
host-owned history with a native-only timeline, or approve manual/hardware
acceptance. T-148 remains In Progress and T-149 remains Blocked.
