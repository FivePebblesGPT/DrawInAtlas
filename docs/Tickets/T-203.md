# Restore T-087 required-native image-frame, clip-policy and camera regressions

## Bounded cause and scope

The historical T-087 standalone headless and real X11 pointer/framebuffer
fixtures still tested **1px, stationary Legacy Brush dabs** after T-153 made
Hokusai mandatory. Such dabs do not guarantee a changed native pixel or a
history entry. The fast-desktop model failed 5/78 checks; the on-demand native
framebuffer fixture failed 17/104. No application clipping or camera regression
was established by those failures. This ticket repairs the **test oracles**,
not the T-087 product/hardware acceptance gate.

## Acceptance

- [x] Reproduce both unmodified fixture failures in actual Godot 4.8 beta3,
      with real required-native extension and X11 framebuffer where needed.
- [x] Replace zero-change stationary click expectations with real swept,
      native Hokusai Brush input; keep real viewport mouse events in the
      graphical suite. Require a committed pixel outside the guide when clip
      authorization is disabled, and require the untouched source under
      canceled policy/camera changes.
- [x] Preserve one-revision publication, atomic Undo/Redo, grid-snap source
      mapping, signed clip boundary and opaque checkerboard/frame behavior.
      Eraser asserts exact **straight RGBA8** hidden-RGB retention when alpha
      is zero; no longer conflates transparent source with an integer-zero
      pixel. Capture pre-existing pixels rather than assuming a previously
      painted frame boundary is empty.
- [x] For headless native gestures, await bounded session completion before
      inspecting history. A no-change gesture must **not** pass merely because
      its session ended: check the changed pixel and native batch stats.
- [x] Run both tests repeatedly; preserve unrelated CI and manual gates.

## Delivery

`drawing/tests/image_frame_smoke.gd` now passes **82/82** across six real
headless runs. `drawing/tests/image_frame_native.gd` passes **104/104** in
four software-X11/Mesa runs. Both required markers remain unchanged, including
the on-demand CI pin for native check count. The model now verifies a swept
native Brush outside the image guide and Undo/Redo through a camera-stable
stroke. The native framebuffer path verifies cancellation, real preview and
input restoration after grid, clip-policy and camera changes; native Eraser
clears alpha but preserves its exact hidden RGB and the off-frame stored pixel.
See [fail-first, exit and source-hash evidence](../evidence/T-203-2026-11-19-native-image-frame.md).

**No production renderer, native Brush, persistence, CI check ID, or frame
geometry code was changed.** T-087 and T-180 remain In Progress; T-106
requires new hosted post-consolidation CI, and T-085's distinct Legacy-oriented
fixture failures are not repaired by this ticket. No physical FPS, Windows,
owner UX or manual-review approval is claimed.
