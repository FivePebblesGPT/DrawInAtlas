# Bind asynchronous Save As results to the originating document

**Done — 2026-11-15, one bounded persistence-authorization fix.** The ordinary
file chooser and the hosted Object source-variant dialog previously dispatched
their completion using whichever tab was active *when the signal arrived*, not
the document that had opened the dialog. If the active tab changed or its
index was reused, a delayed selection could overwrite an unrelated `.drawing`
path or publish a variant from another Object session. Earlier T-125 and T-131
protected incomplete Brush content and failed Object metadata publication,
not this cross-tab callback ownership problem.

## Engineering acceptance

- [x] Capture the active tab index, exact `DrawingDocument` and exact Object
      Editor session when showing either Save As dialog. A result is valid
      only while that same tab/source is still active. An index by itself is
      insufficient because closed tabs shift their successors into its slot.
- [x] Reject obsolete FileDialog and named Object variant confirmations
      **before** modifying source paths, session metadata or destination
      bytes. Provide an actionable error and cancel a pending close-after-save.
      Clear the file-dialog authorization and local Save As mode on cancel, including a cancelled Object variant save-and-close.
- [x] Preserve normal file and Object Save As when the originating tab remains
      current. Preserve direct `_save_file(path)` for existing trusted Save
      routes, Object publisher semantics, canonical RGBA8 and Undo/Redo.
- [x] Reproduce 14 failures out of 34 assertions on the exact unmodified
      T-131 Git tree; fixed candidate passes **34/34** with strict Godot
      exit/log verification and no forbidden in-test errors. Cover existing
      file overwrite, cancelled callback, closed/reused tab index, ordinary
      Save, local Object FileDialog and named hosted Object variant publication.
- [x] Integrate headless Godot witness and Python source/CI contracts in the
      existing required T-085 workflow check (46 unique IDs unchanged), then
