# Preserve pending Brush pixels against concurrent layer and clipboard edits

**Done — bounded engineering safety follow-up (2026-11-15).** T-124–T-128
protect sequential Brush input, persistence, context switching, Undo/Redo, and
History-list navigation. The shared Drawing workspace still allowed unrelated
layer/clipboard operations to mutate the exact `DrawingDocument` while a
released or queued Brush/Eraser transaction owned a detached snapshot. Layer
visibility, locking, reorder, rename, deletion and insertion could bump source
revision and explicitly call `canvas.cancel_gesture()`, discarding delivered
paint; switching the selected Tree layer could also invalidate the queued
follow-up without changing the document revision.

## Independent acceptance

- [x] Refuse layer/group insertion, visibility/lock toggles, reorder, indent,
      outdent, rename, removal, text commit/rasterization, and clipboard
      Cut/Delete/Paste **before** any document mutation while Brush input is
      unpublished. Copy, menu/panel display and other non-mutating controls
      remain available.
- [x] Reject selection of a different paint-source layer during pending
      Brush input, restore the visible Tree selection, and keep a usable
      warning. A same-row callback cannot erase that warning.
- [x] Keep the original detached stroke and the bounded queued successor
      intact, with no unexpected revision or history transaction. After both
      commits, re-enable normal structural edits, Undo and portable Save/Open.
- [x] Verify the original T-128 source fails **17/35** new Godot assertions,
      while the corrected workspace passes **35/35** with strict Godot logs.
      Update the legacy T-089 structural witness to require a safe refusal,
      *explicit* cancellation, and then the previously supported row edit.
- [x] Run adjacent Brush/clipboard/layer/native regressions and a new fail-closed
      Python contract under the **existing** required T-085 CI step. Keep the
      46-check workflow inventory and post-exit diagnostic policy unchanged.

[Reproduction, log checksums, regression commands and limitations](../evidence/T-129-2026-11-15-pending-content-edits.md).

**Scope and gates:** This protects workspace-owned document mutations, not
arbitrary direct `DrawingDocument` callers, and does not change Brush throughput,
rendering, pixel representation or history format. Intentional Escape/cancel
continues to work. T-095 remains **In Progress**, `manual_review: true`, for
physical owner hardware responsiveness and approval. T-106/T-107 hosted CI
and owner-facing T-056/T-059 UX gates remain unapproved.
