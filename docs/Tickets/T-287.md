# Reject non-replayable workflow and job configuration in local fast-CI audits

## Defect and independently bounded scope

[T-286](T-286.md) closed the step-level configuration gap, but
`tools/replay_godot_ci.py` still accepted modified **workflow/job-level**
settings while executing the exact same Bash commands. An added root/job
`env` or `defaults`, a different runner, job-level `if`, container, strategy,
concurrency or second job could change GitHub Actions execution without
changing any of the 46 locally extracted check scripts. Local audit would
then falsely describe those commands as a faithful replay.

## Acceptance

- [x] Reproduce the old parser accepting changed root triggers/metadata,
      changed job runner/metadata, second jobs and nested configuration.
- [x] Fail closed on any change to the checked-in single-Job Ubuntu execution
      envelope the local Bash runner cannot model. Do not require a YAML
      dependency; reject unexpected indentation rather than silently skipping
      nested event/job settings.
- [x] Keep ordinary comments and cosmetic workflow renaming permissible;
      maintain step-only unit fixtures, the exact 46-step inventory and the
      existing T-286 step-level guards.
- [x] Run neighboring report, local replay, owner evidence, Godot explicit
      typing and Python lint/static checks; retain fail-first and green logs.
- [x] Preserve all manual-review and hosted-CI gates, which this test does
      not replace.

## Result — 2026-11-23

Before the fix, **14 mutated workflow envelopes** were accepted (14 failing
negative subtests). The stricter low-indentation envelope guard rejects the
mutations, including unusual indentation, while leaving the real workflow's
46 checks unchanged. The new three-test suite and **47 neighboring Python
contracts** pass, as do Ruff, Ty, explicit GDScript typing, and the ticket
store. [Full commands and retained evidence](../evidence/T-287-2026-11-23-workflow-envelope.md).

**Limits:** This is a narrow source-contract on triggers, the single named
Ubuntu job and top-level/job metadata. It does **not** reproduce GitHub's
pre-check checkout, setup actions, artifact steps or run-configuration context,
nor does it establish a hosted beta4 run. T-094/T-106/T-107/T-180 and T-250
remain under their existing independent CI/owner approval gates.
