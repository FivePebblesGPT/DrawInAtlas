# Establish authoritative sessions, commands and revisions

## Source
[[Archive/2026-10-30/IMPLEMENTATION_PLAN#Current execution milestones (1–8)|Execution milestone 8]].

## Acceptance
- Agree session/peer identity, transport, host authority and revision semantics for the accepted canvas/object model.
- Route accepted changes through authoritative validation; clients cannot directly mutate host state.
- Define conflict/rejection behavior and the relationship to local editing/history.
- Demonstrate a minimal consistent host/client edit flow before broader replication.

## Engineering checkpoint (2026-11-01)

Implemented an **isolated, GM-only in-process proof** in
`scripts/collaboration/host_session.gd` and `session_client.gd`. Requests
contain primitives and a canonical decimal-string base revision; the host
constructs `AtlasTokenEdit` from its current token records and applies it via
`AtlasEditHistory`. Two clients receive detached synchronized token snapshots.
Replayed request IDs are idempotent, stale requests are rejected, invalid
operations have no history effects, and out-of-band host edits invalidate the
session. Tests: `tests/authoritative_session_smoke.gd`; detailed protocol and
limitations: `docs/AUTHORITATIVE_SESSIONS.md`.

**Acceptance still open:** peer authentication, a real transport, complete
canvas/object command coverage, revision persistence strategy, local vs shared
undo policy, and owner agreement on these semantics. T-046 role filtering and
T-047 reconnection are deliberately not implemented. Do not close this Index
checkbox or treat a trusted local mirror as a player-visible client.

Verification: 41/41 focused authoritative-session assertions; 54/54 headless
regression suites; 33/33 native-rendering suites; Web release export;
4/4 cross-process source/export-pack save-portability checks; explicit
GDScript typing audit and `git diff --check`. Revisions are decimal strings
in requests, responses and snapshots to survive Godot's JSON numeric parsing.
No native-save schema or production editor/publication integration changed.
