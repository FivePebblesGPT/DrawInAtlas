# Retire NativeHard; use Hokusai for every Brush preset

**Owner decision (2026-11-16):** One Brush/Eraser rasterization algorithm: Hokusai/libmypaint through the existing unified Rust GDExtension. `hard_round.myb` is the hard brush; Soft, Ink, Airbrush and erasing use the same engine. NativeHard must not survive as a second implementation, backend choice, compatibility alias or hidden fallback. This replaces the two-strategy intent of completed T-147 without rewriting its historical evidence. Legacy is separately retired by T-150. The project is alpha: no migrations or backward-compatibility shims.

## Implementation — exactly five steps

1. **Inventory and freeze the sole preset contract.** Identify NativeHard entry points in Rust, GDExtension, Canvas, edit sessions, settings, test harnesses and scripts. Specify one Hokusai `begin/append/commit/abort` path with bundled `.myb` presets, including `hard_round.myb`, and define Eraser behavior through that same rasterizer.
2. **Delete NativeHard end to end.** Remove the hard-coverage Rust kernel, mode enum/dispatch, hard-only FFI functions, Canvas backend selector, settings, defaults and dead branches. No NativeHard alias, fallback, migration or second raster algorithm; preserve generic tile/history/selection infrastructure used by other tools.
3. **Revalidate native transactions and brush semantics.** Keep tile-level source authorization, masking, alpha/hidden RGB, pressure, signed coordinates, cancellation/retry, revision checks, preview/commit/save and Undo/Redo atomic under the single MyPaint path. Missing or incompatible native binaries must fail explicitly. Verify `hard_round.myb` appearance and opacity; if translucent when an opaque brush is desired, adjust the preset/settings, **not** resurrect NativeHard.
4. **Replace obsolete tests and benchmarks.** Make the 96px Hard Brush Fill Bench™️ run **Hokusai Hard Round only**: actual 100-event 512×512 gesture, native identity, complete source coverage, alpha distribution, framebuffer, preview/commit and exact same-backend Undo/Redo. Remove active NativeHard-vs-Hokusai comparison and opaque-red parity assertions; retain old benchmark numbers only as labelled historical evidence. Update native unit tests, Godot fixtures, CI scripts and backend flags accordingly.
5. **Run integration acceptance and clean documentation.** Execute Rust/unit/strict-Clippy plus standalone/root Godot Brush/Eraser, masks, cancellation, Save/Open, Object/Atlas history and graphical 96px witnesses. Record raw exits/logs, coverage and wall/CPU timings; update ABI/build docs, T-148/T-150 and `docs/Index.md`. Do not claim the T-095 physical-device 100ms target or owner approval from software tests.

## Acceptance / dependencies

## Completed 2026-11-16 — implementation and verification

All five implementation steps delivered. The owner-approved design is now a
single `.myb`/Hokusai Brush/Eraser with **no NativeHard kernel, dispatch,
selector, aliases or fallback**. The existing distinct Legacy implementation
remains for the dependency-ordered T-150 deletion, but is not selectable from
Canvas. Native alpha-aware Eraser preserves original/hidden RGB and uses the
same MyPaint dab opacity; the `hard_round.myb` preset was verified unchanged.

The release binary was rebuilt from pinned offline sources. Rust: 22 unit tests,
`cargo fmt --check`, strict `cargo clippy --all-targets -- -D warnings` all
pass. Godot standalone: `t147_native_stroke_contract` 20/20,
