# Export PNG, WebP and JPEG with format-specific settings

## Owner finding — 2026-11-25
No ability to export common image formats with respective export options.

Source: [PR #23 hands-on review](../DRAWING_UX_REVIEW_2026-11-25.md). This is a standalone Drawing correction; no dependency on the T-250 Atlas acceptance gate. Historical completed tickets remain valid for their narrower scope.

## Scope
Add File > Export (distinct from native Save/Save As) for PNG, WebP and JPEG, using the composited document at defined finite output bounds. PNG lossless with alpha; WebP lossless or lossy with applicable quality; JPEG quality and explicit opaque background/matte for alpha. Expose only real codec options, with dimensions/preview and estimated size where practical. Use bounded rendering/encoding and atomic output; preserve native file identity and dirty/savepoint/history state.

- [x] Inspect actual export dialog and run native Linux tests; record Windows/physical limits separately.
