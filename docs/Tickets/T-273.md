# Anchor the right-dock toggle at the outer edge and correct its arrow direction

## Owner correction, 2026-11-23

The owner rejected the expanded/minimized T-251 result again: the half-circle
sits at the **canvas/dock seam** rather than the **outside right edge**, its
arrow directions are reversed, and its minimized slot leaves the button inset
from the window edge. Prior T-251 tests counted button geometry as a visual
oracle and did not exercise the intended edge hit target. The approved visual
reference remains `docs/assets/drawing-ux-2026-11-22/DrawInAtlasColorPanelConcept.png`;
this is **not** approval of any implementation.

## Acceptance

- [x] Expanded and minimized control stays flush with the right-hand dock's
      **outer edge**; minimized retains the first real flow slot, so icons are
      displaced and the left document canvas is not covered.
- [x] Expanded `>` means collapse right; minimized `<` means expand left;
      actual rendered X11 captures are **opened and inspected**.
- [x] Scrollable controls cannot steal the edge click, even when the native
      ColorPicker has children extending beyond its clipped ScrollContainer.
- [x] Real input toggles correctly in standalone Drawing and embedded Atlas;
      keyboard Enter, focus recovery, flyout, floating host, narrow viewport,
      100/150/200% UI scale, restart/persistence and document-history safety
      remain regression-covered.
- [x] Change only the toggle/right gutter. **T-274** owns the separate native
      ColorPicker composition/unused space, without claiming that entire UX
      has been approved. Keep T-250 blocked pending it and owner review.

## Completion

The editor now anchors the same 30×56 vector button to the **right** of
`PanelDock`. In minimized mode the 48×56 first rail slot aligns its child to
its outer edge; expanded mode uses the non-scrolling dock-owned overlay and a
right, not left, scrolling-content gutter. Reversed the arrow sign. The
native ColorPicker contains internally clipped buttons with over-large *raw*
rects; the T-251 rectangle-only assertion was removed in favor of simulated
pointer delivery after actual scrolling, including unchanged foreground color.

See [rendered comparison, fail-first and validation](../evidence/T-273-2026-11-23-dock-edge.md).
**T-251 remains historical engineering Done**, but its previous layout does
not override the owner's second rejection. **T-250 is Blocked**, not approved.
