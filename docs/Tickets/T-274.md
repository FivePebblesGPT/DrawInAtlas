# Remove unused horizontal space and redundant chrome from the inline ColorPicker

## Owner finding, 2026-11-23

The actual expanded editor still wastes horizontal width around the picker.
In the original code, `DockPanelGutter` reserved a full-height left margin
for a top-only dock toggle, while the inline native ColorPicker used
`Control.SIZE_SHRINK_BEGIN` and exposes overlapping/redundant custom vs
native color editors. T-273 relocated the toggle/right gutter, **not** the
ColorPicker composition. Treat the owner's original screenshot/concept as the
visual target, not a passing rectangle assertion.

## Acceptance to implement next

- [x] Give the picker practical usable width without forcing giant minimum

      recents, RGBA8/hex editing, scroll-to-control and native picker features.
- [x] Keep collapse overlay and other dock controls accessible throughout
      scroll, resize, drag, keyboard and focus transitions.
- [x] Verify real pointer/keyboard interactions, focus, persistence, history,
      recent-color interruption rollback and embedded Atlas UI; use tests

- [x] Record fail-first/corrected render inspection and exact validation;
      do not self-approve T-250's final owner review.

**Scope:** One independent Drawing-only visual/interaction correction. It is
not blocked by T-250, since T-250 is the *later* owner acceptance gate.

## Engineering completion — 2026-11-23

The native picker is expanded by default inside a **390px preferred, 226px
minimum** dock, and horizontal scrolling remains available at small widths.
The right-edge toggle reserves space in the first header only; the rest of
the panel spans the dock. Six recent-color slots keep the vertical bar
proportions stable as the filtered number of visible pigments changes.

Godot's hex/RGB/HSV editors are already visible; the stricter canonical
RGBA8 controls are now behind an optional disclosure rather than adding
duplicated permanent chrome. Real X11 input, independent Drawing/embedded
Atlas, dock/floating/HiDPI screenshots **opened and inspected**, focus,
interruption rollback, persistence, unchanged document history and color
settlement were verified. See [T-274 actual rendered comparison and tests](../evidence/T-274-2026-11-23-native-picker-composition.md).

**T-250 can return to Manual Review, never automatic acceptance.** Its owner
must explicitly compare the running app to the concept and approve it.
