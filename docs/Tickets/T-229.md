# Bound detached native history transfers before source reads

**Split from T-148.** After T-156 moved historical raster replay into the
Rust tile store and T-157 guarded reentrant lazy sources, whole-tile history
still limited *count* to 128 regardless of storage stride. Six 2048px RGBA8
tiles require up to 288 MiB for source/before/after spans, above Rust's
256 MiB native storage budget. Godot prepared full-tile snapshots and could
invoke lazy providers before Rust rejected the envelope. Both GDExtension
history entry points converted provided buffers into Rust vectors before
checking this aggregate bound.

## Acceptance

- [x] Enforce a stride-dependent, overflow-safe conservative three-span cap,
  `tile_count * stride² * 4 * 3 <= 256 MiB`, in both Godot history replay and
  the independent Rust detached/tokenized history ABI before any copies,
  lazy callbacks or history token consumption; retain the 128-tile limit.
- [x] Fail closed with unchanged revisions, history/source and pending lazy
  references. Include a fail-first regression that distinguishes preflight
  `HISTORY_TARGET` rejection from later malformed-buffer/source rejection,
  and confirms the Rust-side memory-budget error independently.
- [x] Verify small signed multi-tile replay, hidden RGB at alpha zero, exact
  Rust source parity, reverse/forward detached history and `.drawing`
  Save/Open; test extreme count multiplication without allocating tiles.
- [x] Test Rust strict unit/format/check, existing native detached/tokenized,
  legacy-pixel, lazy-source, Atlas and native-X11 regressions. Add strict
  required-native CI coverage and synchronize the ABI, T-148 and Index.

## Completion — 2026-11-22

Implemented a conservative history-envelope cap before Godot lazy source
resolution and before Rust input `Vec` allocation for both history entry
points. Six 2048px tiles reject immediately; normal 64px detached Undo/Redo
still publishes canonical tile bytes and preserves the same native owner.

[Fail-first reproduction, regression matrix and limitations](../evidence/T-229-2026-11-22-history-budget.md).

**Scope boundary:** This bounds one history-replay transfer, not all live
resident memory, other raster publishers, host-owned detached timeline
migration, or universal native raster authority. T-148 remains In Progress,
T-149 remains Blocked and T-095's owner/hardware acceptance is untouched.
