# Preflight native Delete projection before lazy I/O and Brush materialization

## Defect

`clear_rect()` checked view-relative coordinates and the permissive public
±2⁶⁰ anchor range, but omitted the native ±2⁵² **global pixel** boundary
check used by T-294's other bulk operations. A Delete rectangle crossing
that boundary could load lazy source chunks and stage a dense clear, even
though the whole request was outside native publication limits. In a mixed
session it could also flatten or erase an already-accepted deferred Brush.

## Completed acceptance

- [x] Real Godot 4.8 beta4/Rust fail-first 50-check test reproduces 15 failures
      across the positive/negative X/Y boundaries and a mixed Brush gesture.
- [x] Reject an entire globally unpublishable Delete region with `COORD_RANGE`
      **before** lazy-source resolution, dense/sparse clear staging or any
      deferred Hokusai/Brush materialization, reusing the already tested
      native-publication applicability and non-native compatibility rules.
- [x] No lazy-loader callback, preview/coverage mutation or document-revision
      advance on rejected requests. Legal one-pixel boundary Delete succeeds
      in the same session with exact RGBA8, hidden-RGB Undo and Redo.
- [x] Rejected Delete preserves an accepted tile-local deferred Brush; the
      Brush still commits and replays correctly, with no unrelated source clear.
- [x] Corrected witness passes 50/50; eight neighboring Delete, fill, bulk,
      native Brush and Atlas checks pass. Strict native witness added to the
      existing T-068 fast-desktop CI step without changing its 46-check count.
