# Preflight native bulk-edit document projection before lazy reads

## Defect

T-290 rejects `fill_rect()`, `apply_region()` and `paint_polygon()` candidates
outside the view-relative ±2³⁰ coordinates. But an otherwise legal local
rectangle/polygon can cross the native ±2⁵² **global** pixel projection after
adding the session's wider signed document anchor. Previously the first
pixel could resolve a lazy tile and stage pixels, then `_publish_edit()` would
reject the edited area at commit; an invalid bulk operation could also flatten
an accepted detached Brush.

- [x] Shared exact corner/last-pixel check before source reads or deferred
      Hokusai/Brush materialization in all three bulk-edit APIs. Match
