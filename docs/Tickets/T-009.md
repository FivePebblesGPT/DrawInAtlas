# Give Search and world discovery a clear user purpose

## Source
[[ManualReview_2026-10-30#Usability testing|Usability testing]], item 7.

## Work
Investigate relevant global world-building tools, describe the tasks users expect to solve, and evaluate whether Search, an overview, spatial discovery or another presentation best supports them.

## Acceptance
- Produce concrete user scenarios and sourced reference comparisons.
- Agree feature naming, searchable objects, result context and actions before implementation.
- Demonstrate finding and locating content without requiring knowledge of internal map/link IDs.
- Fit the confirmed shared-board/LOD model rather than assuming the old descendant-document search is the accepted design.
