# Preserve native paint history across raster layer creation Undo/Redo

## Scope
Ordinary creation → Brush → Undo Brush → Undo creation must not stop at a
native-authorized blank layer. Redo the empty creation before replaying its
original native paint token; do not discard canonical bytes or other history
just to change the layer tree. An abandoned local creation branch must release
its reserved source identities and future native events.

## Acceptance
- [x] Undo and redo the empty created raster with retained native paint tokens,
  shared revision, exact signed RGBA8 and independent earlier layer history.
- [x] Reject nonempty (including hidden RGB), divergent, unresolved, incomplete,
  stale or actively edited sources before modifying the tree or cursor.
- [x] Never-imported and detached empty creations remain replayable; subsequent
  detached raster history reacquires native authority.
- [x] Abandoning a creation via a new metadata or selection-only branch releases
  only its parked blank sources, preserving unrelated tokens and active edits.
- [x] Real Hokusai replay, binary Save/Open, Rust and Atlas neighboring checks;
  ordinary Make and fast desktop CI witness.
