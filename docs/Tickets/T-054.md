# Independent Drawing transactions and one Atlas global history

**Status: PLANNED.** Owner chose a global chronological history for Atlas.

## Plan
1. Define Drawing transaction with stable document/layer IDs, before/after state or chunk diff, preview/commit/cancel phases and expected-source validation.
2. Make standalone Drawing undo/redo and dirty/savepoint work without AtlasCampaign, including stale/locked target rejection and redo branch discard.
3. Build an Atlas adapter that resolves Drawing operations through map and logical layer/floor context, then submits them to one Atlas history interleaved with map, link, grid and floor edits.
4. Decide cross-map undo camera behavior in T-051 (history is global regardless); preserve document-state correctness when active map changes or projects reload.
5. Test isolation of two workspaces, long gestures, stale edit targets, exact alpha and image snapshots, global ordered undo and fail-without-mutation.
6. Benchmark existing full-layer snapshots before adopting diff optimization; do not mix performance rewrites into boundary extraction.

## Acceptance
Drawing undo works with no Atlas code; Atlas has only one global authoritative timeline; no duplicate undo or untracked edits; no historical save migration.
