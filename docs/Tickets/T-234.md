# Preflight native Brush tile publication before lazy source callbacks

**Bounded T-148 child.** The native Brush publisher checked the 128-tile
count but not the stride-dependent three-span transfer envelope used by
external adoption and history replay. It also resolved lazy sources one at a
time before validating every later tile's buffer, coordinate, bounds and
source identity. A malformed final descriptor could therefore invoke a
previous tile's provider, or be changed by a reentrant callback.

## Acceptance

- [x] Enforce a 128-tile and conservative 256 MiB three-full-tile-span
  envelope before resolving any source for a native Brush publication.
- [x] Validate every key, projection bound, source presence, dirty rectangle
  and exact RGBA8 buffer length before a provider is called; freeze caller
  buffers and metadata for the subsequent publication.
- [x] Refuse input mutation during lazy resolution (images, dirty bounds,
  source identity or key set) without advancing revision or publishing pixels.
- [x] Preserve valid native publication, exact hidden RGB, dry-run versus
  prepared installation, native tile/history/Atlas and real-X11 Canvas paths.
- [x] Add a strict required-native CI test and document measured limitations.

## Completion — 2026-11-22

The native Brush projection now performs an allocation-bounded, whole-request
preflight and freezes all input descriptors before lazy loads. After resolving
sources, it rechecks the caller-owned input against those snapshots before
returning a prepared transaction. The initial fail-first test reproduced **10/24** failures; the expanded
fixture reproduced **13/32** against old code and passes **32/32**, including
four reentrant mutation types. Existing native publication (56/56), tile ABI
(312/312), persistent/externally adopted native history, Atlas and native-X11
Canvas (46/46) remain passing; Rust unit tests pass 36/36.

[Reproduction and validation evidence](../evidence/T-234-2026-11-22-publication-preflight.md).

**Scope boundary:** This strengthens the document-side native Brush
publication contract, not Rust's whole resident-memory budget, other raster
producers, or complete host-owned history authority. T-148 remains In
Progress; T-149 stays Blocked. Hosted CI and physical owner review are
not claimed by local tests.
