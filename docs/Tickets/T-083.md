## Engineering implementation and review evidence — 2026-11-03

**Engineering implemented; owner UX review pending.** `addons/drawing/dock_persistence.gd` persists a versioned (`schema: 1`) **workspace preference** under `user://drawing-workspace-dock-v1.json` (independently scoped by the Godot host project's `user://` root; a host may override `layout_settings_path`). It stores the existing validated `DrawingDockLayout.snapshot()` together with expanded dock width/scroll position and floating-container visibility, geometry, and child/z-order. It intentionally never contains drawing pixels, history, layer content, source assets, or document-save state. A temporary write plus replacement/rollback protects an existing settings file; state is flushed on layout changes and on clean workspace shutdown.

Startup registers the baseline T-063 Colors/Layers/History panels, plus optional `initial_extra_panels` supplied **before** the workspace enters the scene tree, then restores the layout through the same T-078 ownership validator used by drag/drop. Late peers can call `register_workspace_panel` without being hardcoded into this storage schema. Unknown panel IDs or whole empty floating hosts are removed, missing registered panels get deterministic singleton groups on the right dock, and a saved active tab absent from its group selects the first retained member. Explicit renamed IDs may be supplied via `layout_panel_aliases`; without an explicit mapping, a renamed panel is treated as removed plus a new registered panel. Corrupt, oversized, structurally invalid, or unsupported-version settings load safe T-063 defaults. Missing settings also start from the three-group T-063 configuration; there was **no older persistent T-063 dock layout** to migrate from. Invalid/offscreen/nonfinite host frames are rejected or clamped; usable frames are proportionally adapted to the current application client size and then clamped to a visible title/resize region. **Window → Reset workspace layout** clears floating UI and restores default groups without touching an open drawing or its dirty state.

**Automated evidence (Godot 4.8 beta 2):** `drawing/tests/dock_persistence_smoke.gd` passed **46/46** headless checks for disk read/write, exact validated model round-trip, grouped rail/flyout/collapse/selection, unknown and renamed plugin IDs, absent host metadata, invalid/oversized structures, corrupted JSON, interrupted-write backup recovery, and resolution scaling; added to required fast desktop CI. `drawing/tests/dock_persistence_native.gd` passed **63/63** native checks (**65/65** with the two saved screenshot checks), including actual scene destruction/relaunch; a minimized rail with two retained dock groups, a restored reordered floating two-tab group, hidden/recovered host, position/size, 420px viewport, 1.5× UI scale, offscreen recovery, redock order/separators, reset/restart, corrupted-file defaults, and unchanged document revision/dirty state. Screenshots: `screens/t083/t083-before-relaunch.png` and `screens/t083/t083-after-relaunch.png` in the test evidence bundle (not stored as source assets). The existing native dock regression witnesses also passed: T-079 **40/40**, T-080 **68/68**, T-081 **55/55**, T-082 **56/56**, T-063 **75/75**, and native keyboard **8/8**. T-078/T-080/T-081/T-082 headless regressions and standalone Drawing/Object Editor checks passed. These are engineering tests, **not** owner UX approval. Native Windows hardware, broad deferred Atlas/framebuffer suites, and Web export are not asserted as passing.
