# Restore required-native T-128 History-list pending-stroke regression

## Scope and acceptance

The historical T-128 guard implementation is already Done, but its required
`t128_history_list_pending_smoke.gd` fixture failed **8/37** assertions on
the native Hokusai engine. Both initial History candidates were stationary
3px Legacy dabs which did not publish source pixels or History rows. A later
check required deferred paint to remain pending after exactly two Canvas
frames, although the native queue may legally publish both transactions by
then. The invalid setup also caused secondary History navigation failures.

- [x] Reproduce and retain the unchanged 8/37 failing run under pinned Godot
      and the current native brush extension.
- [x] Replace each short setup dab with a moving 24px native Hokusai stroke,
      retaining its asserted source pixels and independent History entries.
- [x] At the two-frame checkpoint, accept only pending input **or** both
      ordered published history transactions (revision **and cursor**); do
      not accept cancellation or partial publication. Keep the existing
      checks for refusing backward and forward History-list navigation,
      selection restoration, visible warning, queue continuity, exact RGBA8
      Undo/Redo and portable Save/Open.
- [x] Preserve the required CI marker `T128_HISTORY_LIST_PASSED
      checks=37 failures=0` and add a Python contract prohibiting the old
      3px stationary candidate and unconditional post-frame pending assertion.
- [x] Re-run four headless and two software-X11 tests with process exits and
      strict log checks, neighboring Drawing regressions, Rust, Python,
      lint and the ticket/manual-gate validator. Retain raw output and
