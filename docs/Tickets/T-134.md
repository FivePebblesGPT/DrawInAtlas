# Bind authoring confirmations to their original document and selected layer

**Done — 2026-11-15, bounded stale-modal editing safety.** T-132 made Save As
file and Object variant choosers reject a different document or reused tab index,
but ordinary authoring `ConfirmationDialog.confirmed` signals still targeted the
**currently active tab**. A deferred layer rename, editable Text commit, Object
rename/frame, standalone image-frame, or grid confirmation could therefore
mutate a different document or view after a tab switch. A cancelled dialog's
late signal could also still publish an edit. This is an independent extension
of the document-identity fix, not a new editor architecture.

## Engineering acceptance

- [x] Freeze exact tab index, `DrawingDocument` and Object Editor session
      identities when each of the six authoring dialogs opens. Every UI
      confirmation must consume this identity *before* calling the existing
      edit action, rejecting changed tabs or replacements at a reused index.
- [x] For Text and layer rename, also pin the selected edit layer/Tree node
      and document revision. A stale rename must not retarget a different row
      within the same tab; a text draft must not publish after unrelated edits.
- [x] Cancel revokes confirmation authority; duplicate confirmations cannot
      reuse the captured authorization. An invalid attempt yields an
      actionable visible error and does not mutate either document.
- [x] Preserve direct existing editing method contracts, legitimate same-tab
      confirmations, grid/image-frame editing, source metadata and normal
      Undo/Redo. Do not add an Atlas-specific workspace branch.
- [x] Add a red/green Godot test, Python source/CI contracts, strict log
      verification within the existing T-085 required CI step, native X11
      replay and adjacent Text/Layer/Object/frame regressions.
- [x] Validate the ticket store and independent native-absent Drawing
      consumer. Keep the 46-check workflow inventory unchanged.
