# Reclaim abandoned parked text raster sources

## Scope
An undone local text conversion parks its canonical glyph pixels and any
blank authorizations from undone paint. Permanently abandoning conversion
Redo must release that residency, while retaining live semantic text and
unrelated native history. This is shared Drawing command infrastructure,
not an Atlas feature or owner approval.

## Acceptance
- [x] Fail-first metadata/selection branch witness for abandoned glyph sources.
- [x] Reclaim only a verified parked conversion after its abandoned paint
  tokens are released; no revision advance or unrelated edit cancellation.
- [x] Reject live, stale, referenced and incomplete native sources; fail closed
  on a changed retained snapshot. Keep retained conversions replayable.
- [x] Verify hidden RGB, semantic removal Undo, Save and a subsequent conversion.
- [x] Complete pinned native and adjacent verification, documentation and CI wiring.
