# Select canonical Brush publication for unsupported native tile strides

## Defect

`DrawingEditSession` defaulted to `_brush_tile_publish = true` for every
`DrawingDocument`, including synthetic 1px and 3px storage strides. The
Rust tile ABI used by direct tile publication accepts the configured native
stride range 16–2048, while these smaller strides remain valid script-only
Drawing documents. A multi-batch 3px Brush/Eraser preview matched the canonical
reference but its `commit()` failed with `NATIVE_TILES` (transfer-budget guard
or native bootstrap rejection); no exact history/Undo/Redo was published.

## Completed acceptance

- [x] Select native tile-local Brush publication only for supported 16–2048
      storage strides at session construction; use the canonical pixel-key
      edit path for smaller valid strides. Keep native fast-path behavior for
      supported documents and existing mixed-edit handling unchanged.
- [x] Strengthen the existing required on-demand T-095 source-reference test
      to exercise the **session's actual default** publisher choice, not
      force a tile publisher on unsupported strides. Check committed RGBA8,
      hidden RGB, signed tile seams, selection holes, lazy failure/retry and
      Undo/Redo against the independent canonical reference.
- [x] Update the neighboring T-095 tile-key test to distinguish canonical
      pixel-map history for strides 1/3 from Rust tile-history tokens/snapshots
      on supported strides, while keeping exact pixel/read/Undo/Redo checks.
- [x] Real beta4 + Rust fail-first after removing the guard: **10/622 failures**;
      fixed **632/632** reference checks and **33,037/33,037** tile-key checks.
      Additional native signed Brush and T-095 staging regressions pass.

[Reproduction and passing logs](../evidence/T-298-2026-11-24-brush-stride.md).

**Scope:** This restores an existing T-095 required-native on-demand workflow
witness and unsupported synthetic-stride correctness. It does **not** declare
T-095's 60px physical latency/owner review, T-068 performance evidence,
