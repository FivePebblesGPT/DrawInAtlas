# Validate exported Drawing project identity inside Godot binary PCK settings

## Problem

T-216 validates the *staged* text `project.godot` and T-217 verifies that the
*exported* `Drawing.pck` contains a `project.binary` resource. However, the PCK
checker accepted any resource starting with `ECFG`, even if the actual exported
application name and startup scene belonged to a different project. A valid
PCK index and consistent MD5 hashes were not enough to establish project identity.

## Acceptance

- [x] Reproduce twelve false-accept assertions before the fix: wrong exported
      application or main scene, spoofed/incomplete ECFG, duplicate settings,
      corrupted entry count, truncated/trailing data, non-String identity and
      noncanonical String padding. Preserve valid Drawing as positive control.
- [x] Inspect the bounded Godot 4.8 `ECFG` table, decoding the required
      `application/config/name` and `application/run/main_scene` String Variants.
      Reject duplicate settings and malformed lengths without parsing unrelated
      Variant types or accepting unaccounted trailing bytes.
- [x] Verify Linux packaging rejects an unrelated exported PCK **before**
      native `.so` publication; the export's complete file inventory stays
      byte-for-byte unchanged, with no leaked preflight directory.
- [x] Wire six new regression tests into Make and both desktop/portability CI
      workflows. Keep T-217–T-219 tests and the shared synthetic fixture valid.
- [x] Validate the **real 528-resource** beta3 PCK and isolated native ABI/app
      launches; run 101 configured Python tests, 35 Rust tests, Ruff, ty,
      formatter and ticket-store checks, retaining process logs and hashes.

## Evidence and remaining gates

[Fail-first proof, binary-layout investigation, final test matrix and raw logs](../evidence/T-220-2026-11-19-packed-project-identity.md).

This is a bounded **export identity** check, not a digital signature or complete
Godot binary Variant interpreter. The isolated launch used the supplied Godot
4.8 beta3 executable with a real exported PCK, not an official Linux release
binary. Hosted CI, Windows native runtime, physical-device performance and
owner acceptance remain open. T-105, T-106, T-180 and T-197 are unaffected;
no owner/manual-review gate was approved by this engineering-only ticket.
