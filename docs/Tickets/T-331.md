# Eliminate transitional Object-index JSON persistence

**Owner direction, 2026-11-27:** binary-only application persistence; no historical save migration.

Audit `object_library.gd`, `campaign_copy.gd`, linked-source resolution and asset-browser filtering for the transitional `.atlas-object-index.json` sidecar. Remove it if redundant after T-330, otherwise use one explicit versioned binary authority. Never keep competing durable indexes or silently discover legacy JSON.

- [ ] Verify asset create/publish/Save As, immutable revisions, stale index/source leases, nested graph authorization, collision and symlink rejection, and whole-project copy/move with exact IDs/digests. Preserve failure rollback and existing dirty/history semantics.
- [ ] Remove obsolete JSON sidecar paths, comparisons, filters and live test fixtures where superseded; update portable and registry consumers together. Run actual standalone/Atlas native and failure-injection witnesses. This is infrastructure reconciliation, not new Atlas feature acceptance.
