# Keep non-historical direct raster publication native-authoritative

**Split from T-148.** After a Hokusai gesture attaches the Rust tile store,
`DrawingDocument._publish_edit` and `_publish_tile_edit` with
`record_history=false` previously updated only the Godot tile projection.
They incremented the document revision without advancing Rust or authorizing
new source bytes. The next native gesture could trigger a history-clearing
rebase, discarding unrelated native raster authorizations. These direct APIs
are used by historical producers and no-history workflows; opting out of a
history event must not opt out of canonical source publication.

## Acceptance

- [x] If the Rust store is current, publish valid direct pixel/tile-local edits
  through an atomic native transaction **even without history recording**.
  Validate all source identities and full straight RGBA8 before modifying
  either native or Godot tiles; retain the signed bounds and 128-tile budget.
- [x] Do not invent a Rust history token for a nonhistorical edit. Invalidate
  the now-obsolete native token stacks, retain unrelated resident tile bytes,
  and advance the same shared revision once. A new untracked edit must mark
  the document dirty against its last real Save and discard abandoned Redo,
  without treating historical Undo/Redo replay as a fresh untracked edit.
  Detached document/host history remains independently validated on replay.
- [x] Verify missing and stale sources fail without dirty, revision or native
  history mutation; prove a subsequent Hokusai gesture does not rebase away
  the untracked source and Undo/Redo works for the newer gesture.
- [x] Run a fail-first control against the old publisher and a real-native
  Godot witness for positive/negative tiles, alpha-zero hidden RGB and
  standalone `.drawing` Save/Open, plus pinned Rust unit, release, strict
  Clippy, surrounding Drawing/Atlas/Object and software-X11 regressions.
- [x] Synchronize native ABI documentation, CI loop, T-148 and the Kanban
  index. Preserve all owner-review and hardware gates.

## Evidence and disposition

The real-native witness passes **25/25** checks; the identical pre-fix control
fails **11/25** as expected, and **34/34** final build/test invocations
pass. See [T-162 execution evidence](../evidence/T-162-2026-11-16-untracked-native.md).
T-148 remains In Progress for universal native source/history ownership;
T-149 is not unblocked by this limited publication fix. T-095 still needs
owner/reference-device acceptance.
