# Check native raster authority before low-level dirty snapshots

**Split from T-148.** `snapshot_for_save()` was a low-level dictionary
exporter for dirty RGBA8 and tree metadata. Unlike `export_manifest()` and
`mark_published()` after T-166, it trusted a mutable Godot projection with no
check of Rust tile bytes or native revision. A host/save caller could consume
an unauthorized alpha-zero hidden-RGB mutation as canonical source.

## Acceptance

- [x] Apply the no-lazy-source native revision and exact canonical RGBA8
  projection check *before* exposing dirty tile bytes or a save snapshot.
  Fail with `STALE_SOURCE` for mutated resident tiles or divergent native
  revision, without altering Rust source, history, dirty map or revisions.
- [x] Return `DrawingResult` rather than an unchecked dictionary; successful
  `.value` retains the existing snapshot field names, detached bytes and
  revision. Update all callers and tests in this repository, with no
  compatibility alias or unchecked fallback.
- [x] Preserve native-absent historic snapshot behavior and valid native
  snapshots; verify alpha-zero hidden RGB, detached buffer ownership,
  retry after exact restoration and native Undo/Redo history.
- [x] Fail-first against prior code and run native Rust, Godot Drawing,
  Atlas/Object, persistence and graphical regressions with raw exit logs.
- [x] Update required-native CI, parent T-148, Kanban Index, ABI docs,
  and execution evidence. Preserve T-149 and T-095 review gates.

## Evidence and boundary

See [T-167 execution evidence](../evidence/T-167-2026-11-16-checked-dirty-snapshot.md)
with raw logs and SHA-256 manifest. This closes only the low-level save
snapshot guard. Detached Atlas/host-owned history timelines and universal
native raster authority remain T-148 work; T-149 stays Blocked, and T-095
remains owner-gated. No hosted CI or hardware signoff is claimed.
