# Verify required Drawing resources in exported Godot PCK indexes

## Problem

The standalone export inspector previously checked only `Drawing.pck`'s first
four `GDPC` bytes, and its file length. Any unrelated PCK with that header
could pass structural validation alongside the required Rust `.so`. The staged
`project.godot` identity check (T-216) did not prove that the *exported pack*
actually contained the Drawing startup scene or `.gdextension` manifest.

## Acceptance

- [x] Reproduce a **false accept** with the previous inspector: an export with
      the expected ELF/native files and a structurally valid PCK containing only
      `unrelated.txt` was reported as `structure_and_required_native`. The
      corrected inspector rejects the same bytes before publication.
- [x] Parse the pinned Godot 4.8 PCK v4 directory with bounded counts, paths,
      data offsets, resource flags and checksums; reject incomplete, duplicate,
      unsafe, truncated and unsupported indexes.
- [x] Require packed `project.binary`, startup scene or valid compiled-scene
      remap, the Linux Rust `.gdextension` manifest and the native ABI smoke
      script or valid remap; inspect actual manifest ABI mappings and referenced
      remap targets. Retain Windows as a **structural-only** PCK check; do not
      require a Linux native manifest or claim Windows DLL certification.
- [x] Reject an unrelated PCK in native packaging preflight without changing
      the previously exported files or installing the `.so`.
- [x] Add a synthetic Godot-v4 pack fixture, regression tests in Make and both
      release/portability CI workflows, and verify a **real** Godot beta3 PCK
      containing 528 indexed resources through isolated native ABI and launch.

## Evidence and limitations

[Fail-first comparison, final commands, source hashes, process exits and raw
logs](../evidence/T-217-2026-11-19-pck-index.md).

This is a *bounded structural PCK inventory check*, not a full Godot pack
interpreter, code-signing check, Windows native ABI verification, or independent
certification of every resource. The isolated executable was the supplied
Godot beta3 binary with a real exported PCK, not an official release-template
binary. No Painting/Canvas/history code or saved document format changed.
Hosted CI, Windows runtime/export, physical latency and owner review remain
open under T-105/T-106/T-180 and the corresponding Drawing performance gates.
